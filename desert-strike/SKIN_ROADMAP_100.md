# 데저트 프론트 신규 100스킨 개발 로드맵

## 제작 규칙
- 기존 10종족 × 콘셉트 10개 = 100개 스킨 세트.
- 각 스킨 세트는 기본 8병종 + 저격병 + 암살자, 10병종으로 구성. 자원시설은 병종에서 제외.
- 각 병종별 4열×2행 8포즈 투명 시트: 대기·준비·이동1·이동2·공격 준비·공격 적중·스킬·사망.
- 기존 이미지 필터로 색상만 바꾸지 않고 실루엣과 장비를 교체. 전투 판정·능력치·경제 밸런스는 그대로.
- 배포에 필요한 원본 PNG와 변환 WebP 및 SHA256 기록. 커밋은 배포 코드와 이미지 에셋 모두 포함해야 완성 처리.
- 로비에서 선택 불가능한 스킨도 별도의 '스킨 확인해보기' 팝업에서 전체 병종·포즈를 미리 볼 수 있게 한다.

## 진행 상태
- 철갑연합 01 '혈철 집행군': 10병종 8포즈 RGBA PNG 생성 및 96px WebP 변환 완료. 2026-10-31 코드/문서 체크포인트 완료.
- **아직 원본 PNG 및 변환 WebP 바이너리가 GitHub에 반영되지 않았으므로 게임 배포 완성으로 표시하지 않는다.**
- 생성 원본과 변환 결과는 현재 대화의 `desert-front-blood-iron-skin-source.zip`으로 보관; GitHub 파일명과 SHA-256은 `assets/sprites/blood-iron-sources.json` 참조.
