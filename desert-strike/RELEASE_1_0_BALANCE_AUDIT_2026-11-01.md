# Desert Front — 1.0 RC 종족 밸런스 1차 검증 (2026-11-01)

대상 기준: `main` 코드 기준 10종족, 실제 `tri-lane-engine.js`(멀티) 및 `game-v2.js`(싱글)의 전투 연산. **패치 전, 수치 미조정.**

## 테스트 방식과 한계

- 10개 종족의 45개 비동일 대진을 각각 좌·우로 바꿔 2회씩 검증: 시나리오당 90회, 종족별 18회.
- 멀티 중앙 라인 실전 전투 엔진으로 웨이브 20·35·50, 싱글 전투 엔진으로 웨이브 35 검증. 전체 **360회**(멀티 270회, 싱글 90회).
- 진영당 동일 초기 예산으로 병종 비율을 맞춘 통제된 교전. 고정 시드, 영웅 합체 및 실제 피격·상성 계산 포함. 유닛이 전멸하면 승패로 판정하며 최대 90초에 도달한 미결정전은 무승부(타임아웃)로 기록.
- **실제 온라인 유저 승률이 아닙니다.** 생산 건설/경제 성장/행동 선택/3라인 기지 파괴 전체 경기/멀티 증강 조합은 검증하지 않았습니다. 웨이브 설정은 후반 상성 수치 확인용이며 실제 라운드 진행을 재생하지 않습니다.
- 승률은 동일한 고정 조합에서의 진단 지표입니다. 종족의 공정성이나 실제 이용자 밸런스를 이 값만으로 단정하면 안 됩니다.

## 출시 전 검토할 우선순위

1. **크롬 로보족**: 멀티 54회 중 43승. 포격/장갑 조합 14승·저격/암살 조합 17승의 편향이 있어, 종족 효과·기갑/대공/특수 역할별 실제 카운터 효율 추가 점검 권장.
2. **농농 페어리족과 심연군체**: 이 테스트의 공통적인 약세. 다만 힐링/부활 또는 증강 특화의 이점은 즉시 전멸형 전투에서 평가하기 어렵기 때문에 버프 전 전체 경기 검증 필요.
3. **성운결사·옥토퍼 군체**: 종족별 후반 교전 강점이 뚜렷함. 포격/장갑 밀집전 및 상성 카운터 유지 여부 재검토.
4. **해병성채·야월 퍼리족·은월 엘프족**: 병종 조합과 시점에 따른 변동이 큼. 특정 한 시나리오만 근거로 전체 종족 수치를 일괄 조정하지 말 것.
5. **1.0 릴리스 판단**: 최소한 다중 전략 AI 전체 경기, 3라인 기지 승패, 일반/증강/프리즘과 저격·암살 대공·탐지 규칙 회귀 테스트, GitHub Actions 실패 항목 점검 후 최종 확정.
