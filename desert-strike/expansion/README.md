# 저격병·암살자 추가 준비 — 2026-10-31

현재 상태는 **라이브 비활성의 준비·검증 패키지**입니다. 기존 8병종, 임파서블 AI, 인컴, 멀티 네트워크·계정·랭킹은 수정하지 않았습니다. `lab.html`에서 고정 예산 전투, 40종 애니메이션, 보상 스킨 초안을 확인할 수 있습니다.

## 병종 초안

| 항목 | 저격병 | 암살자 |
|---|---:|---:|
| 가격 | 380 CR | 330 CR |
| 공통 기초 체력 | 78 | 52 |
| 공통 기초 공격력 | 300 | 180 |
| 사거리 | 370 · 엘프 407 | 30 |
| 공격 간격 | 4.8초 | 1.45초 |
| 준비 | 조준 0.65초 | 침투 준비 0.35초 + 이동 0.45초 + 착지 회복 0.45초 |
| 역할 | 고가 단일 화력·장갑 표적 압박 | 무방비 저격·포격·지원병 후방 침투 |

기초 체력·공격력에 기존 전투 엔진과 같은 `체력×2.25`, `공격력×0.94`, `이동×0.84`와 종족 공통 보정을 적용합니다. 따라서 종족 보정 전 실제 체력은 저격 175.5, 암살 117입니다. 암살자는 기존 사격병의 약 48% 체력입니다. 숫자를 기초값과 실제 전투값 사이에서 혼용하지 않았습니다.

저격은 지상 단일 표적 무기입니다. 장갑·지상 특수 표적에 피해 1.6배, 장갑 50% 관통을 시험합니다. 일반 영웅에는 1.25배만 적용하며 20배 처형이나 장갑 보너스와의 곱연산은 없습니다. 조준 중 아군이 이미 충분한 피해를 예약한 표적을 피하도록 준비했습니다. 싸구려 사격 물량·근접 압박·진짜 비행체를 모두 해결하는 범용 병종으로 만들지 않았습니다.

암살은 전선 250 안에서 진입을 준비하고, 관측 가능한 420 범위의 후방 표적을 향해 최대 380 이동합니다. 생산된 개체당 한 번만 침투합니다. 침투 중에도 탐지되면 공격받으며, 착지 후 회복 시간이 있습니다. 첫 공격만 1.2배, 매 공격 후 1.05초간 노출됩니다. 탐지 지원병이나 근접 호위가 있는 후방으로 무조건 들어가 살아남는 설계가 아닙니다.

## 은신·탐지와 멀티 표시 규약

- 비탐지 암살자도 두 플레이어 화면에 항상 표시: 불투명도 0.58, `은신!` 표식.
- 지원병: `디텍팅!` 표식과 반경 190 원형 범위. 사망하거나 범위를 벗어나면 탐지 종료.
- 탐지된 암살자는 불투명하게 표시하고 `탐지됨`, 공격으로 드러났을 때는 `공격 노출!` 표시.
- 화면에서 보이는지와 직접 조준할 수 있는지는 별도 판정입니다. 비탐지라도 범위 피해에 면역을 주지 않습니다.
- `snapshot()`은 은신 개체의 위치·상태를 생략하지 않습니다. 이는 준비용 직렬화 규약이며, 실제 온라인 패킷과 정식 호스트 연결은 아직 하지 않았습니다.

## 생성 아트와 애니메이션

내장 imagegen으로 10종족 × 2병종 × 기본/모에화 = **40종**을 생성했습니다. 각 8개 독립 포즈로 총 **320개 도색 포즈**이며, 기존과 같은 16프레임 재생 규칙에 연결합니다. 640개를 새로 그렸다고 주장하지 않습니다.

- `assets/*-sniper.webp`, `assets/*-assassin.webp`: 768×96, 96픽셀 셀 8개.
- `assets/*-preview.png` (APNG): 각 병종의 독립 애니메이션 미리보기 40개.
- `asset-manifest.json`: 전체 경로·SHA-256·실제 원본 행 경계·포즈 개수.
- `art-prompts.json`: 실제 생성 프롬프트 세트. 첫 철갑 저격 시제품만 단일 기존 제복 이미지를 참조했고 나머지는 `research/style-reference.png`를 참조했습니다.
- `tools/pack_sprites.py`: 기존 추출 방식처럼 행 공백을 찾아 정렬하고 이웃 조각을 제외해 96픽셀 스트립으로 정리합니다. 해병 모에화 원본 2장은 기본/모에화가 함께 생성되어 아래 모에화 8포즈만 선택했습니다.

원본의 큰 공격 이펙트가 칸 경계에 닿는 경우는 `reviewIssues`에 보존했습니다. 실사용 프레임은 최대 88픽셀로 맞추고 96픽셀 칸 안에 여백을 두었습니다. 이 아트는 준비용이며 출시 전 큰 이펙트의 끝부분을 추가 다듬을 여지가 있습니다.

### 준비용 모델: 480회

`combat-model.js`는 빠른 UI·기능 검사용 별도 모델입니다. 10종족 × 2예산 × 2시드 × 12상황을 비교했습니다. 저격 단독·돌격 호위 저격은 사격 물량에 0/40, 암살 단독은 근접 물량에 0/40, 무방비 저격병에는 40/40 승리했습니다. 저격 대 장갑은 34/40입니다. 비행 비교의 16/40 승리는 비행 슬롯이 지상 특수 병종인 종족에서만 나왔습니다.

모델은 종족 발동·영웅·구조물·투사체 비행/회피 등을 단순화해 일부 탐지 혼성 편성의 승패 추세가 실제 엔진 시험과 달랐습니다. 그 결과도 `research/balance-results.json`에 그대로 보존했습니다. 모델의 승률만으로 밸런스 완료를 선언하지 않습니다.

웹 검색 서비스가 오류를 반환해 프로젝트 공식 GitHub 규칙 파일로 수치를 확인했습니다. 게임별 재화와 전투 규모가 달라 가격을 직접 환산하지 않았습니다. 다크 템플러는 사용자가 제시한 역할 참고이며 최신 패치 수치를 임의로 인용하지 않았습니다.

- [Wesnoth Elvish Sharpshooter](https://github.com/wesnoth/wesnoth/blob/master/data/core/units/elves/Sharpshooter.cfg): 가격 55, 체력 47, 원거리 10×5와 marksman, 근접 7×2. 정밀 원거리 특화와 약한 근접의 분리를 참고했습니다.
- [Wesnoth Elvish Ranger](https://github.com/wesnoth/wesnoth/blob/master/data/core/units/elves/Ranger.cfg): 가격 31, 체력 42와 ambush 능력. 은신을 명시적인 규칙으로 다루는 참고입니다.
