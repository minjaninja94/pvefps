# 계정 스킨 포인트 / 크로마 (2026-10-31)

- 레벨 해금을 포인트 구매로 교체했다. 기본 제복·모에 외형은 무료다.
- 등록된 로그인 계정은 최초 3,000P, 이후 한국 시간 날짜가 바뀐 첫 로그인에 300P를 받는다. 첫날은 총 3,000P다. 중복 조회·새로고침은 추가 지급하지 않는다.
- 스킨 1,000P, 스킨별 크로마 200P. 유료 스킨은 원본 해금 후 원하는 크로마를 추가 구매한다. 원본/황혼/오로라/황금 근위 아이콘을 각 카드 아래에 배치했다.
- 102개 기본 외형(기본 제복·모에 포함) × 4색 = 408개 선택 ID. 색상은 같은 원본에 필터로 적용한다. 신규 이미지 생성은 없다.
- Supabase desert_skin_points_and_chromas 마이그레이션 배포 완료. 재현 SQL: sql/desert_skin_shop_v1.sql.
- 서버 카탈로그·계정 지갑·해금 테이블을 분리했다. 지갑 및 해금 데이터는 소유 계정의 읽기만 허용하고 지급·차감은 인증된 등록 회원 RPC와 행 잠금 트랜잭션으로 처리한다.
- selected_skin은 해금과 종족을 검증하는 트리거로 보호한다. 기존 선택된 3종 팔레트 ID는 default~색상으로 이관했다. 일반 프로필 저장은 포인트·해금 목록을 수정하지 않는다.
- 싱글·멀티·미리보기·생산 아이콘에 크로마를 연결했다. Firestore 방/프로필 문서에는 기존 허용 ID만 기록하고 전체 외형은 기존 WebRTC appearance 경로로 전달한다.
- 서버 롤백 테스트 통과: 최초·일일 중복 지급, 중복 구매, 포인트 부족, 원본 선구매 조건, 지갑·보유 내역 직접 수정 차단, 미해금 선택 차단, 계정 RLS. 실제 계정 변경은 모두 rollback했다.
- 브라우저 테스트 통과: 로그인 지급, XP로 유료 스킨 해금 불가, 크로마 실제 픽셀 변화, 원본/크로마 구매, 중복 클릭, 새로고침 계정 복원, 종족 제한, 로그아웃 격리, 모바일 카드 폭.
