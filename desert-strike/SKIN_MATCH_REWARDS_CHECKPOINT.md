# 경기 포인트 보상 / 크로마 10종 (2026-10-31)

- 로그인 AI 승리: 쉬움 50P, 보통 100P, 어려움 150P, 아주 어려움 200P, 임파서블 250P. 싱글 및 로컬 1:1/3라인 AI 연습에 적용한다. AI 패배는 0P다.
- 온라인 대전(classic/pvp)은 서버에서 승패가 확정되면 승자 500P, 패자 200P를 자동 지급한다. 중도 포기로 확정되는 승패도 같은 규칙이며 중복 지급하지 않는다. 무승부 및 협동전에는 PvP 보상을 지급하지 않는다.
- 최초 3,000P 및 일일 첫 로그인 300P는 유지한다. 지급은 계정 지갑에 합산하며 공개 프로필 저장으로 포인트를 변경할 수 없다.
- AI 출격 시 서버에 UUID와 난이도를 등록하고, 최초 출격 대기 10초 이전의 승리·다른 계정의 기록·취소된 경기·이미 패배 처리한 경기의 승리 변경을 거절한다. 동일 경기 재전송은 기존 지급 내역을 반환한다. 연결 실패한 완료 요청은 계정별 로컬 큐에 보관하여 재접속/온라인 복구/로비 복귀 시 재시도한다.
- AI 승패 자체는 기존 로컬 시뮬레이션이 보고한다. 서버는 경기 등록·소유자·난이도·시간·지급 이력을 검증하며 전체 전투를 재연산하는 치트 방지 서버는 아니다. 온라인 대전은 기존 서버의 참가자 합의/탈주 판정과 확정 결과를 사용한다.
- private 보상 함수와 DB 경기 종료 트리거가 새 desert_skin_match_rewards 원장을 관리한다. (user_id,source_kind,match_key) PK로 재지급을 막고, 멀티는 room code 재사용에도 구분되도록 고유 reward UUID를 둔다. 원장·AI 세션 테이블은 본인 읽기만 허용한다.
- 배포 SQL: sql/desert_skin_match_rewards_v1.sql. Supabase 마이그레이션 desert_skin_match_rewards_and_ten_chromas 적용 완료.
- 모든 102개 기본 외형에 유료 크로마 10종(기존 3종 + 추가 7종)을 등록했다. 기본 색상 포함 1,122개 ID. 기존 구매 ID와 200P 가격을 유지한다. 원본 버튼 아래 5열×2줄로 10종을 표시한다.
- 선택 팝업 최대 폭을 1,180px에서 2,360px로 확대하되 화면 폭의 96% 이내로 제한했다. 기존 전역 help dialog의 550px max-width 제한도 선택창에서 별도로 해제했다. 종족 미리보기 최대 320px, 스킨 미리보기 192px(기존 96px)로 확대했다. 작은 화면은 2열 카드와 144px 미리보기로 맞춘다.
