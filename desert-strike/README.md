# DESERT FRONT — V2

고전 데저트 스트라이크 / Direct Strike의 자동 출격식 전략 규칙에서 영감을 받은 **독립 창작** 무료 브라우저 게임입니다. 원작 그래픽·사운드·모델 및 유닛 명칭을 사용하지 않습니다.

**Play:** \`https://minjaninja94.github.io/pvefps/desert-strike/\`

## 3개의 게임 화면

1. **내 기지 · 건설**: 생산 유닛 카드 / 상성 / 5×3 슬롯 / 기지 모형 / 적군 침공·방어 포탑 실시간 표시
2. **전장**: 두 진영의 병력이 자동 교전하는 픽셀 전략 전장 / 유닛 머리 위에 공통 역할 마크 / 유닛 클릭 시 강점·약점 / 1×·2× / 일시정지
3. **특수 기능**: 비상 핵폭탄(한 판에 1회, 본진 위기 시) / 궤도 폭격(260 CR, 32초) / 경제·무기·장갑 업그레이드 / 포탑 수리 / 역할별 상성표

## 진영과 유닛

| 진영 | 특징 | 밸런스 |
|---|---|---|
| 철갑연합 (FORGE UNION) | 총기·탱크와 강철 장갑 | 유닛 HP +9%, 속도 -4% |
| 심연군체 (DUSK BROOD) | 생체 갑각, 괴수·포자 병력 | 유닛 HP -8%, 속도 +12% |
| 성운결사 (ASTRAL ORDER) | 수정체, 에너지 무기와 수호병 | 유닛 HP -5%, 피해/치유 +8% |

각 진영에 8개 고유 이름과 **자체 생성 픽셀 실루엣**을 제공합니다. 총 **3진영 × 8역할 = 24종**입니다. 같은 역할이라면 외형과 진영이 달라도 **머리 위 역할 마크는 동일**합니다.

| 역할 | 마크 | 강점 | 약점 |
|---|---|---|---|
| 돌격 | ⚔ | 포격·지원 | 장갑·사격 |
| 사격 | ⌖ | 돌격·지원 | 장갑·포격 |
| 대장갑 | ◆ | 장갑·대공 | 돌격·사격 |
| 장갑 | ▣ | 사격·대공 | 대장갑·비행 |
| 대공 | ✣ | 비행 | 장갑·대장갑 |
| 포격 | ✹ | 사격·대공 | 돌격·비행 |
| 비행 | ◇ | 돌격·장갑 | 대공·사격 |
| 지원 | ✚ | 장갑·사격 **아군과 조합 시너지** | 돌격·포격에 취약 |

직접적인 공격 상성은 목표 역할에 따라 1.55배 또는 0.7배가 되며, 방어도도 고려됩니다. 지원 유닛은 공격하지 않고 치유합니다. 공중 유닛에는 대공 가능한 유닛만 공격할 수 있습니다.

이 수치는 **초기 테스트용 밸런스**로 장기간 대전 통계에 따른 검증 밸런스는 아닙니다.

## 원작 참고: 건물 파괴 규칙

- 초기 스타1 데저트 스트라이크 유즈맵 일부는 생산 건물이 공격받는 경우가 있었고, 후대형과 SC2 Direct Strike 계열은 분리된 생산 지대와 최종 기지/요새 파괴를 중심으로 설계되었습니다.
- 여기서는 **생산 구역 보호**를 선택했습니다. ① 화면에는 적이 침투하면 침공 부대를 그려 주지만 건설 슬롯을 파괴하지 않습니다. 적은 **방어 포탑 (520 HP)** 을 무너뜨린 뒤 **핵심 기지 (2,000 HP)** 를 공격합니다. 이 규칙을 전장에서도 같은 판정으로 사용합니다.

## 기본 규칙

- 시작 자금 600 CR; 20초마다 건물당 해당 유닛 1기 출격.
- 초당 수입 4 CR. 경제 강화 시 단계마다 +2 CR.
- 병력 생산 슬롯 15개. 철거는 원가의 55% 반환.
- 적 AI는 현재 플레이어의 생산 조합을 참고해 카운터 유닛 비중을 높입니다.
- 게임 재시작 시 진영을 다시 선택합니다.

## 실행과 테스트

별도 빌드 없이 \`desert-strike/index.html\`을 브라우저에서 엽니다.

\`\`\`bash
node --check desert-strike/game-v2.js
node desert-strike/smoke-v2.test.cjs
\`\`\`

GitHub Actions가 V1 레거시 엔진 검사와 V2 핵심 플레이 스모크 테스트를 모두 실행합니다. 기존 버전은 \`game.js\`와 \`style.css\`로 백업 유지됩니다.

모바일에서 화면 상단의 탭으로 화면 전환, 카드 터치 → 슬롯 터치로 건설합니다. PC에서는 Alt+1/2/3 탭 전환, 숫자 1~8 유닛 선택, Space 일시정지, 우클릭 슬롯 철거를 지원합니다.

## 현재 범위

- 1인 vs AI 2D 픽셀 자동 전투, 인터넷 연결 없이 실행.
- 실시간 멀티플레이, 고해상도 외부 도트 애셋 및 실제 통계 기반 정교한 밸런싱은 아직 미구현.


## 픽셀 그래픽 및 16프레임 모션 (V2 아트 업데이트)

- 별도의 블리자드/스타크래프트 리소스를 복사하지 않고 자체 제작한 **48×48 투명 픽셀 스프라이트**를 사용합니다.
- 모든 3진영 × 8병종 = 24종의 모델에 대해 **대기 / 이동 / 유닛 공격 / 건물 타격(공성) / 사망** 각각 16프레임을 생성합니다. 총 **1,920개 독립 이미지 프레임**이며 브라우저에서 필요할 때 생성하고 캐시합니다.
- 철갑연합: 장갑판·기계식 관절·총기·포탑·VTOL 및 강철 기지. 심연군체: 갑각·가시·발톱·막날개·산성기관 및 살아있는 둥지. 성운결사: 수정체·발광 코어·비행 결정·에너지 무기 및 공명 수정탑.
- 공격은 각 유닛의 16프레임 동작 중 **중간 타격 프레임**에서 실제 타격·발사·회복 판정이 일어납니다. 건물 공격은 유닛 공격과 별도의 16프레임 공성 모션입니다.
- 사망 시 유닛이 곧바로 없어지지 않고 16프레임 분해·전도 모션을 완료합니다. 방어 시설 피격·파괴도 16단계 파편/충격파 효과를 보여 줍니다.
- **[스프라이트·모션 도감](./sprite-gallery.html)** 에서 24종, 각 5개 동작의 16개 프레임을 전부 관찰할 수 있습니다. 한 줄 프레임 스트립, 개별 프레임 슬라이더, 16프레임 투명 PNG 저장 버튼을 제공합니다.
- 모션은 16단계로 샘플링한 **절차적 픽셀 애니메이션**입니다. 수작업 1,920장 고해상도 원화나 자연스러운 8방향 회전 모션, 전용 PNG 애셋 제작까지 완료한 것은 아닙니다.
