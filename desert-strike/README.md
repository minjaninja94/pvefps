# DESERT FRONT

건물을 배치해 병력을 자동 생산하고, 적 AI가 설계한 군대와 맞붙는 1인용 오리지널 브라우저 전략 게임입니다. 고전 자동 출격 전략 유즈맵의 플레이 구조에서 영감을 얻었으며, 원본 게임의 아트·사운드·유닛 데이터를 사용하지 않습니다.

## 실행

- GitHub Pages가 저장소 루트를 게시한다면 **/desert-strike/** 를 엽니다.
- 로컬에서는 \`desert-strike/index.html\`을 브라우저에서 열면 됩니다. 빌드나 외부 라이브러리가 필요하지 않습니다.
- 별도 서버, 계정, Firebase 연결이 없는 1인용 시제품입니다.

## 게임 규칙

1. 초기 자금 600 CR로 생산 시설을 건설합니다.
2. 16초마다 설치된 각 시설에서 유닛 1기가 자동 출격합니다.
3. 전투는 자동으로 진행되며 양쪽 기지는 각각 1800 HP를 보유합니다.
4. 적 AI는 아군 조합을 참고해 카운터 유닛을 우선적으로 생산합니다.
5. 경제 업그레이드는 초당 자금 수입을 높이며 최대 7단계까지 구매할 수 있습니다.
6. 시설 철거 시 건설비의 55%를 반환합니다.
7. 먼저 상대 기지 체력을 0으로 만든 진영이 승리합니다.

## 병력

| 유닛 | 생산비 | 특징 |
|---|---:|---|
| 돌격병 | 65 CR | 근접 돌격 및 포병 견제 |
| 소총병 | 100 CR | 범용 지상/공중 대응 |
| 로켓병 | 150 CR | 대장갑 공격 |
| 강습 전차 | 205 CR | 높은 체력과 방어력 |
| 대공포 | 165 CR | 비행 유닛 특화 |
| 야전 포병 | 245 CR | 장거리 범위 공격 |
| 전투 드론 | 210 CR | 근접 공격이 통하지 않는 공중 유닛 |
| 의무병 | 145 CR | 부상 아군 치료 |

## 조작

- **PC:** 카드 클릭 + 격자 클릭으로 건설, 숫자키 1–8 선택, ESC 선택 해제, 스페이스 일시정지, 격자 우클릭 철거.
- **모바일:** 생산 카드 터치 + 격자 터치. 철거 모드와 배속은 화면 버튼으로 조작합니다.
- **게임 속도:** 1× / 2× 지원.

## 검증

\`\`\`bash
node --check desert-strike/game.js
node desert-strike/smoke.test.cjs
\`\`\`

GitHub Actions의 \`Desert Front smoke test\` 워크플로는 코드 변경 시 문법 및 헤드리스 핵심 플레이 테스트를 실행합니다.

## 현 버전의 범위

- 1인 vs AI, 2D Canvas 전장, 하나의 생산 격자와 8개 병종을 포함한 플레이 가능 초기 버전.
- 네트워크 멀티플레이/종족 추가/3D 모델/랭킹은 구현하지 않았습니다.
- 테스트는 JavaScript 문법과 주요 게임 흐름을 확인하며 실기기 브라우저의 렌더링을 보증하지는 않습니다.
