# DESERT FRONT — V2

고전 데저트 스트라이크 / Direct Strike의 자동 출격식 전략 규칙에서 영감을 받은 브라우저 팬 프로토타입입니다. 블리자드 게임의 원본 그래픽·사운드·모델은 사용하지 않으며, 해병성채는 해병문학 팬 캐릭터 이름과 설정을 참고한 패러디 진영입니다.

**Play:** \`https://minjaninja94.github.io/pvefps/desert-strike/\`

## 3개의 게임 화면

1. **내 기지 · 건설**: 생산 유닛 카드 / 상성 / 15×5 슬롯 / 기지 모형 / 적군 침공·방어 포탑 실시간 표시
2. **전장**: 두 진영의 병력이 자동 교전하는 픽셀 전략 전장 / 유닛 머리 위에 공통 역할 마크 / 유닛 클릭 시 강점·약점 / 1×·2× / 일시정지
3. **특수 기능**: 비상 핵폭탄(한 판에 1회, 본진 위기 시) / 궤도 폭격(260 CR, 32초) / 경제·무기·장갑 업그레이드 / 포탑 수리 / 역할별 상성표

## 진영과 유닛

| 진영 | 특징 | 밸런스 |
|---|---|---|
| 철갑연합 (FORGE UNION) | 총기·탱크와 강철 장갑 | 유닛 HP +9%, 속도 -4% |
| 심연군체 (DUSK BROOD) | 생체 갑각, 괴수·포자 병력 | 유닛 HP -8%, 속도 +12% |
| 성운결사 (ASTRAL ORDER) | 수정체, 에너지 무기와 수호병 | 유닛 HP -5%, 피해/치유 +8% |
| 해병성채 (MARINE FORTRESS) | 해병문학 패러디, 8개 인물과 황룡 특수 회복 | HP +4%, 공격 +2%, 이동 +1% |

각 진영에 8개 고유 이름과 **자체 생성 픽셀 실루엣**을 제공합니다. 총 **4진영 × 8역할 = 32종**입니다. 같은 역할이라면 외형과 진영이 달라도 **머리 위 역할 마크는 동일**합니다.

| 역할 | 마크 | 강점 | 약점 |
|---|---|---|---|
| 돌격 | ⚔ | 포격·지원 | 장갑·사격 |
| 사격 | ⌖ | 돌격·지원 | 장갑·포격 |
| 대장갑 | ◆ | 장갑·대공 | 돌격·사격 |
| 장갑 | ▣ | 사격·대공 | 대장갑·비행 |
| 대공 | ✣ | 비행 | 장갑·대장갑 |
| 포격 | ✹ | 사격·대공 | 돌격·비행 |
| 비행 | ◇ | 돌격·장갑 | 대공·사격 |
| 지원 | ✚ | 장갑·사격 **아군과 조합 시너지** | 돌격·포격에 취약 |

직접적인 공격 상성은 목표 역할에 따라 1.55배 또는 0.7배가 되며, 방어도도 고려됩니다. 지원 유닛은 공격하지 않고 치유합니다. 공중 유닛에는 대공 가능한 유닛만 공격할 수 있습니다.

이 수치는 **초기 테스트용 밸런스**로 장기간 대전 통계에 따른 검증 밸런스는 아닙니다.

## 원작 참고: 건물 파괴 규칙

- 초기 스타1 데저트 스트라이크 유즈맵 일부는 생산 건물이 공격받는 경우가 있었고, 후대형과 SC2 Direct Strike 계열은 분리된 생산 지대와 최종 기지/요새 파괴를 중심으로 설계되었습니다.
- 여기서는 **생산 구역 보호**를 선택했습니다. ① 화면에는 적이 침투하면 침공 부대를 그려 주지만 건설 슬롯을 파괴하지 않습니다. 적은 **방어 포탑 (1,700 HP)** 을 무너뜨린 뒤 **핵심 기지 (7,200 HP)** 를 공격합니다. 이 규칙을 전장에서도 같은 판정으로 사용합니다.

## 기본 규칙

- 시작 자금 360 CR; 24초마다 건물당 해당 유닛 1기 출격.
- 기본 수입은 0.5초마다 1 CR(초당 2 CR)로 시작합니다. 경제 강화 시 0.5초당 수입이 단계마다 +1 CR 증가합니다.
- 병력 생산 슬롯 75개. 철거는 원가의 55% 반환.
- 적 AI는 현재 플레이어의 생산 조합을 참고해 카운터 유닛 비중을 높입니다.
- 게임 재시작 시 진영을 다시 선택합니다.

별도 빌드 없이 \`desert-strike/index.html\`을 브라우저에서 엽니다.

\`\`\`bash

node desert-strike/smoke-v2.test.cjs
\`\`\`

GitHub Actions가 V1 레거시 엔진 검사와 V2 핵심 플레이 스모크 테스트를 모두 실행합니다. 기존 버전은 \`game.js\`와 \`style.css\`로 백업 유지됩니다.

모바일에서 화면 상단의 탭으로 화면 전환, 카드 터치 → 슬롯 터치로 건설합니다. PC에서는 Alt+1/2/3 탭 전환, 숫자 1~8 유닛 선택, Space 일시정지, 우클릭 슬롯 철거를 지원합니다.

## 픽셀 그래픽 및 16프레임 모션 (V2 아트 업데이트)

- 별도의 블리자드/스타크래프트 리소스를 복사하지 않고 자체 제작한 **48×48 투명 픽셀 스프라이트**를 사용합니다.
- 모든 4진영 × 8병종 = 32종의 모델에 대해 **대기 / 이동 / 유닛 공격 / 건물 타격(공성) / 사망** 각각 16프레임을 생성합니다. 총 **2,560개 캐시 프레임**이며 브라우저에서 필요할 때 생성하고 캐시합니다.
- 철갑연합: 장갑판·기계식 관절·총기·포탑·VTOL 및 강철 기지. 심연군체: 갑각·가시·발톱·막날개·산성기관 및 살아있는 둥지. 성운결사: 수정체·발광 코어·비행 결정·에너지 무기 및 공명 수정탑.
- 공격은 각 유닛의 16프레임 동작 중 **중간 타격 프레임**에서 실제 타격·발사·회복 판정이 일어납니다. 건물 공격은 유닛 공격과 별도의 16프레임 공성 모션입니다.
- 사망 시 유닛이 곧바로 없어지지 않고 16프레임 분해·전도 모션을 완료합니다. 방어 시설 피격·파괴도 16단계 파편/충격파 효과를 보여 줍니다.
- **[스프라이트·모션 도감](./sprite-gallery.html)** 에서 32종, 각 5개 동작의 16개 프레임을 전부 관찰할 수 있습니다. 한 줄 프레임 스트립, 개별 프레임 슬라이더, 16프레임 투명 PNG 저장 버튼을 제공합니다.
- 모션은 16단계로 샘플링한 **절차적 픽셀 애니메이션**입니다. 수작업 1,920장 고해상도 원화나 자연스러운 8방향 회전 모션, 해병성채는 새로 생성한 2.5D 인물 아트 아틀라스를 16단계 변형 애니메이션에 결합합니다. 전체 2,560장이 각각 수작업으로 그려진 애셋이라는 뜻은 아닙니다.

검증:

\`\`\`bash
node --check desert-strike/sprite-animations.js
node desert-strike/smoke-animations.test.cjs
node desert-strike/smoke-v2.test.cjs
\`\`\`


## 확장 전장 · 경제 · 장기전 밸런스 (V3 조정)

- 전장 월드 길이 1,100 → **3,300**으로 확장. 보이는 카메라 영역은 1,100이며 **전선 자동 추적 / 좌우 이동 / 드래그 / 클릭형 미니맵**으로 탐색합니다.
- **생산 건설 공간 75개 (15열 × 5행)**: 모바일에서는 격자 영역을 좌우로 스크롤합니다. 각 행은 전장의 5개 출격 통로 중 하나에 대응합니다.
- **시작 자원 360 CR**, **기본 수입 0.5초당 1 CR**, 경제 레벨별 0.5초당 +1 CR. 0.5초 주기로 정산하며 웨이브는 24초 간격입니다.
- 초기 경제를 강화하지 않는 전략이 무조건 유리하지 않도록 적 AI의 웨이브 보급·확장 속도를 강화했습니다. 이 밸런스는 **테스트용**이며 실제 플레이 데이터에 기반한 승률 검증은 아닙니다.
- 기본 유닛 HP를 2.25배로 올리고 피해와 이동 속도를 소폭 하향해 교전 시간을 늘렸습니다. 기지 본체 7,200 HP, 방어 시설 1,700 HP입니다.
- 대량 건물 운용 시 성능을 위해 **진영당 동시 출전 병력 최대 220기**를 적용했습니다. 병력이 가득 찬 웨이브에서는 추가 출격이 보류됩니다. 생산 건물 자체는 유지됩니다.
- 다수 병력의 적 탐색은 x 좌표 순 정렬된 부대 목록과 이진 검색으로 최적화하고, 카메라 밖 유닛 렌더링은 생략합니다.

### 시각 스타일의 현재 한계

절차적으로 생성하는 48×48 도트에 상단-좌측 방향광·재질별 디더링·입자 질감을 추가했습니다. 기계(금속), 생체(갑각), 수정(발광) 계열로 재질을 구분합니다. 다만 **스타크래프트·디아블로 II의 정교한 실사풍 도트와 동등한 아트로 교체 완료된 것은 아닙니다.** 새로 제작한 2.5D 원화 시안과 실제 게임 스프라이트의 통합은 별도 작업이 필요합니다.


## 해병성채 패러디 진영 (V4)

네 번째 선택 진영 **해병성채 (MARINE FORTRESS)** 는 나무위키의 [해병문학 등장인물](https://namu.moe/w/%ED%95%B4%EB%B3%91%EB%AC%B8%ED%95%99/%EB%93%B1%EC%9E%A5%EC%9D%B8%EB%AC%BC)을 참고해 각 역할에 캐릭터를 배정한 팬메이드 콘텐츠입니다. 원본 팬아트 이미지는 복사하지 않고, 신규 생성 이미지로 새로 제작했습니다.

| 공통 역할 | 해병성채 유닛 | 시각적 특징 |
|---|---|---|
| 돌격 ⚔ | 무모칠 | 붉은 모히칸, 장갑과 칼 |
| 사격 ⌖ | 박철곤 | 녹색 위장복과 기관총 |
| 대장갑 ◆ | 조조팔 | 거대한 휴대식 대전차 로켓포 |
| 장갑 ▣ | 황근출 | 얼굴 그림자와 붉은 눈, 거대한 적색 배틀액스 |
| 대공 ✣ | 톤톤정 | 쌍열 회전포와 중장갑 |
| 포격 ✹ | 마철두 | 중포와 탄띠 장비 |
| 비행 ◇ | 쾌흥태 | 장착식 비행장치와 정찰 장비 |
| 지원 ✚ | 황룡 | 위장 군모와 해병수육 조리 솥 |

**황룡 — 해병수육(특수 지원)**: 자신 이외의 부상 아군이 가까이 있을 때 16프레임 치유 동작을 시전합니다. 동작의 중간 판정 시 반경 175 내 부상 아군 여러 명을 각각 최소 115 HP 또는 자신의 최대 HP의 28%만큼(대상 기준) 회복하고, 황룡 자신은 소모되어 사망 애니메이션으로 전환됩니다. 단일 웨이브에 생산되는 유닛당 한 번만 사용할 수 있으며 다음 웨이브에 해당 생산 시설이 다시 황룡을 소환합니다. 초과 회복은 적용되지 않습니다. 역할 아이콘 ✚를 공유하지만 일반 힐러와 다른 특수 규칙입니다.

**아트 데이터:** `marine-art-data.js`에 저장된 게임 전용 WebP 투명 인물 아틀라스(4열 × 2행, 448 × 224px)를 브라우저에서 로드하고, `sprite-animations.js`에서 이동·공격·건물 공격·사망 동작의 16프레임 변형을 적용합니다. 각 프레임이 따로 그려진 2.5D 원화가 아닌 원본 그림의 동작 변형이므로 후속 수작업 모션 정교화의 여지가 있습니다. 그림 로딩 실패 시 각 유닛에 고유한 캔버스 기반 대체 도트를 표시합니다.

**게임 홈페이지:** 저장소 루트 `index.html`에 데저트 프런트 바로가기 카드를 추가했습니다. 메인 화면에서 바로 게임을 실행할 수 있습니다.


## 장기전·경제 밸런스 업데이트 (2026-10-27)

- **AI와 플레이어 동일 경제:** 360 CR로 시작하고 0.5초마다 기본 1 CR, 각 웨이브마다 추가 24 CR을 받습니다. 더 이상 AI 전용 추가 자원·웨이브별 자동 보정이 없습니다.
- **AI가 건물을 실제로 구매:** 기존 3개 무료 초기 건물을 제거했습니다. 상대는 시작 360 CR에서 돌격·사격 생산 시설 2개를 정상 구매해 200 CR을 남깁니다. 플레이어는 360 CR을 원하는 대로 투자할 수 있습니다.
- **인컴 업그레이드 비용 양측 동일:** \`Math.round(70 * 1.36 ** 경제레벨)\`. Lv.1 70 CR / Lv.2 95 CR / Lv.3 129 CR / Lv.4 176 CR. 단계마다 0.5초당 수입 +1 CR = 초당 +2 CR 증가, 각각 약 35 / 48 / 65 / 88초에 해당 단계의 원금을 회수합니다. 체감 이득은 매 업그레이드 시점과 보유 생산 시설 수에 따라 다릅니다.
- **AI 생산 성장 완화:** 초기 2시설 이후 원칙적으로 2웨이브당 생산 시설 최대 1개씩 추가해 75개까지 서서히 성장합니다. 경제 강화도 웨이브 2 이후, 짝수 웨이브마다만 동일한 비용을 지불하고 진행할 수 있습니다. 침공을 받는 경우에만 방어 목적의 추가 구매를 허용합니다.
- **일반 킬 보너스 폐지:** 이전에는 적이 죽으면 플레이어만 +5 CR을 받았습니다. 이 비대칭을 없애고 양측 모두 전투 외 경제·건설로 자원을 확보하도록 변경했습니다.
- **상단 정보 고정:** 페이지를 아래로 스크롤하거나 건설/전장/특수 기능을 전환해도 상단의 현재 자원, 0.5초당 수입, 웨이브 번호, 다음 웨이브 카운트다운을 볼 수 있습니다. 모달이 열리면 모달이 상단 정보 위에 표시됩니다.

이 조정은 AI를 플레이어보다 더 신중하게 확장하도록 만든 **프로토타입 밸런스**이며, 대규모 자동 대전 통계나 모든 진영의 장시간 매치업에 대한 승률 검증을 완료한 것은 아닙니다.


## 2.5D 픽셀 아트 전면 개편 (V3)

게임 아트 시스템을 평면 프레임/격자에서 **3/4 쿼터뷰**로 다시 작업했습니다.

- **맵:** 높낮이가 있는 암벽, 경사진 마름모 돌바닥 타일, 박리된 측면과 그림자가 보이는 참호·교량, 크레이터·돌무더기·노후 노면 표시. 3,300 월드 폭 유지 및 카메라/미니맵 유지.
- **기지:** 철갑연합·심연군체·성운결사·해병성채 4진영의 본진 및 포탑을 양측 높이가 표현된 건물 형태로 렌더링. 건물 파괴·방어 논리는 기존과 동일.
- **생산 구역:** 75개 생산 시설을 5단 경사진 배치로 재구성. 각 시설 역시 2.5D의 입체형 공장으로 출력.
- **전투 캐릭터:** 전체 **4진영 × 8직업 = 32종**. 기존 제작된 사실적 2.5D 도트 캐릭터를 작은 투명 WebP 아틀라스로 내장(기본 세 진영 24종), 해병성채 8종 전용 인물 아트와 결합. 각 캐릭터의 이동·공격·건물 타격·사망·대기 상태를 기존 16프레임 전투 애니메이션과 동기화하여 렌더링. 래스터 원화 위 이동/회전/반동/타격 효과를 단계적으로 합성하는 방식이며, 모든 16프레임이 독립적으로 수작업 도트화된 것은 아닙니다.
- **사선 투영:** 전투 위치·마우스 유닛 선택·포탄/투사체·이펙트·체력바·공격 역할 아이콘의 위치가 같은 2.5D 투영을 사용합니다. 전투 판정과 경제/상성은 원래 세계 좌표계를 계속 쓰므로 밸런스 수치에는 영향이 없습니다.
- **갤러리:** \`sprite-gallery.html\`에서 실제 새 캐릭터의 72픽셀 모션과 16프레임 PNG 스트립을 볼 수 있습니다.

아트 리소스는 프로젝트에서 자체 제작한 새로운 이미지이며, 원작 스타크래프트나 디아블로 2의 스프라이트/텍스처를 추출한 것은 아닙니다. **원작과 같은 수준의 수작업 다방향/고해상도 아트로 완성했다고 주장하지 않습니다.** 저비용 웹게임에서의 스타일 방향을 우선 통일한 1차 리뉴얼입니다.
