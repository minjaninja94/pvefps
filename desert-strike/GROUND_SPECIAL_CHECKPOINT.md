# 지상 특수병 및 사령부 선택 팝업 (2026-10-31)

- Imagegen 기본 도구로 오도봉고·흑표 돌격기수·알파 늑대 기수·전술 변형 메카를 지상형으로 재생성했다. 기본/모에/종족별 10스킨, 총 48세트 × 8포즈 = 384포즈다.
- 원본 RGBA PNG 4장, 실제 생성 프롬프트, 12행×8열 추출 좌표와 SHA-256은 assets/sprites/sources/ground-special/ 에 보존했다. 처리 스크립트는 tools/import-ground-specials.py 이다.
- 4종족의 기본 role 6 스트립과 모에 아틀라스 해당 행, 40개 스킨의 role 6 런타임 시트를 교체했다. 다른 병종은 유지했다. ground-special-manifest.json은 48개 결과의 해시와 지상 분류를 기록한다.
- 생성 시트 전체 384포즈를 조합한 검수 이미지에서 바퀴·발·다리 접지 형태를 확인했다. 공중형이 남지 않도록 메카는 보행/차륜 변형, 기병은 사족 동물 탑승으로 고정했다. 텍스처 캐시 버전도 올렸다.
- 상성 누락 수정: 오도봉고/흑표/늑대 기수가 장갑병의 상성 추가 피해를 받지 않던 문제와 변형 메카가 포격 상성 추가 피해를 받지 않던 문제를 싱글/멀티 공통 수정했다. 기존 대장갑 특수 배율, 대공 피해 보정, 근접 저항과 저격 정밀 피해는 유지했다.
- 나머지 6종족 특수병은 실제 공중 분류, 근접 표적 불가, 대공 추가 피해와 싱글·멀티 피격 일치를 추가 확인했다.
- 실제 피격 검증: 4종족 × 3웨이브 구간 × 7공격 병종에서 싱글·호스트 피해량 일치. 대장갑, 장갑/포격, 대공, 돌격, 저격의 의도된 배율 관계를 확인했다. 기존 돌진 광역·비행 제외·단가·AI 구매 회귀 검사를 통과했다. 메카 상대 AI 보조 추천은 대장갑/포격으로 맞췄다.
- 사령부 이미지 옆에 종족 선택/스킨 선택 버튼과 현재 선택 표시를 배치했다. 각각 native dialog 레이어로 열리며 종족 선택 시 닫힘, Escape/닫기/배경 클릭 및 포커스 복귀를 지원한다.
- 스킨 팝업 안에서 기존 포인트/크로마 구매를 유지했다. 병종 미리보기 레이어는 열린 스킨 dialog 내부에 배치해 inert 차단 없이 동작한다. 미리보기의 Escape는 상위 스킨 메뉴를 닫지 않는다.
- 검증: 100세트/1,000시트/8,000포즈 파일 및 실제 Chromium 픽셀 검사, 48개 원본/결과 해시 검사, 구매/잔액/재로그인/종족 팝업/모바일 폭/중첩 미리보기 브라우저 검사, 관련 Node 회귀 검사 통과.
- 포인트 서버 마이그레이션은 앞선 SKIN_SHOP_CHECKPOINT.md 참조. 이 변경은 추가 DB 변경이 없다.
