# Desert Front lobby music

Place the supplied **lobby-theme.mp3** file in this directory.

The lobby audio controller loads `./assets/audio/lobby-theme.mp3`, loops it at 30% volume, pauses it during battles, and resumes on return to the lobby. Browsers may require the first user interaction before allowing playback. The lobby BGM toggle persists the visitor's choice.

The MP3 is extracted from the video supplied by the project owner; it is not included in this code-only commit.
