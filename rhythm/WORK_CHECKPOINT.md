## 사용 흐름
- CHARACTER STUDIO → **AI 일러스트 옷입히기**가 기본 모드.
- 얼굴·헤어는 한 세트다. 의상은 독립적으로 선택하며 교체해도 얼굴 선택을 유지한다.
- 의상별 대기3 / 공격3 / 피격3, 머리별 평상시/눈깜박임/공격/피격 표정4를 재생한다.
- 보조 움직임 강도 0이면 호흡·의상·충격 감쇠 움직임을 끈다. 전투에서는 이펙트 줄이기 옵션도 적용한다.
- 예전 현재 캐릭터는 새 옷입히기 모드로 전환하고 이름/의상 선택을 유지한다. 직접 가져온 이미지는 유지한다. 이전 벡터/전신 일러스트는 선택 가능한 호환 모드로 남겼다.

## 핵심 파일 / 재개 시 주의
- `doll-renderer.js`: 시트 로딩, 포즈/표정 타임라인, 래스터 합성, 색/체형/보조 움직임.
- `assets/doll/ASSETS.json`: 실제 사용한 image_gen 프롬프트·원본 파일명·그리드·프레임 순서.
- `studio.js`: 프로필 검증, palette/motion 저장, 옷입히기 렌더러 연결.
- `game.js`: 카드/프리뷰/저장, 실제 전투의 action/actionTime 전달.
- **목 위를 가로로 잘라내지 말 것.** 팔·어깨가 잘린다. 원본 몸 그림을 유지하고 각 포즈의 얼굴 특징점에 독립 머리를 연결한다. 고정 목 기준은 기울어진 피격 자세에서 머리 중첩/목 틈을 만들었다. 최종 방식은 포즈별 얼굴 특징점 기준이다.
- JS 캐시 버전: `doll-20261018-3`. 다음 변경 시 갱신한다.
- 범위는 rhythm/ 및 tests/rhythm*.cjs. 기존 FPS 등 다른 게임·Firebase 규칙·네트워크·랭킹은 변경하지 않았다.
