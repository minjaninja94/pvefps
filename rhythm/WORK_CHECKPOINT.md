## 사용 흐름
- CHARACTER STUDIO → **AI 일러스트 옷입히기**가 기본 모드.
- 얼굴·헤어는 한 세트다. 의상은 독립적으로 선택하며 교체해도 얼굴 선택을 유지한다.
- 생성 시트에는 의상별 대기3 / 공격3 / 피격3, 머리별 표정4가 들어 있다. 현재 대기는 기본 몸/머리 1포즈로 안정화했고 공격/피격만 포즈와 표정을 전환한다.
- 보조 움직임 강도 0이면 호흡·머리·의상 움직임을 끈다. 가슴 움직임은 별도 강도로 조절한다. 전투에서는 이펙트 줄이기 옵션도 적용한다.
- 예전 현재 캐릭터는 새 옷입히기 모드로 전환하고 이름/의상 선택을 유지한다. 직접 가져온 이미지는 유지한다. 이전 벡터/전신 일러스트는 선택 가능한 호환 모드로 남겼다.

- 범위는 rhythm/ 및 tests/rhythm*.cjs. 기존 FPS 등 다른 게임·Firebase 규칙·네트워크·랭킹은 변경하지 않았다.

- **공식 Cubism SDK 적용이 아니다.** 저장소에는 WebP 시트만 있고 `.moc3`/`.model3.json` 모델이 없다. `live-rig.js`는 프로젝트 소유 그림에 대한 자체 WebGL 메시 리깅이다. 이 차이를 다음 세션/사용자에게 숨기거나 공식 Live2D 모델 적용이라고 설명하지 말 것.
