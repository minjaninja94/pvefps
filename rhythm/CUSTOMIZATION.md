# NEON CLASH — Character Studio V2

최신 기획/코드 반영: 기존 개인 아바타, 온라인 커스터마이징, 유튜브 채보 기능은 유지합니다.

## 꾸미기

1. 리듬게임 홈의 **캐릭터 꾸미기**를 엽니다.
2. **테마 디자인**에서 8가지 테마와 **16종 프리셋** 중 선택합니다. 이름/색/스타일 조합을 기존 일러스트에서 생성하며, 외부 AI API나 유료 서버를 호출하지 않습니다.
3. 마음에 드는 요소(기본 캐릭터, 얼굴, 헤어, 체형, 의상, 모션)에 **고정**을 체크합니다. 선택 조건으로 생성하거나 기존 랜덤 버튼을 눌러 고정하지 않은 요소만 다시 만듭니다.
4. **얼굴 / 헤어 / 체형 / 의상 / 움직임 / 기타** 탭에서 수치를 미세 조정합니다. 1P와 상대 파이터를 별도로 편집할 수 있습니다.
5. **저장**을 누르면 브라우저 보관함에 저장됩니다. JSON으로 내보내고 불러오기도 지원합니다.

## 모션과 생성되는 프레임

- 모션 라이브러리 \`rhythm/motion-library.js\`는 총 **20종 모션**을 지원하며, 키프레임 보간을 24fps로 계산합니다.
- 추가 상태: 대기 3종, 준비, 전진, 회피, 가드, 공격 3종, 경/강피격, 무승부 충돌·힘겨루기·후퇴, 필살기 준비·발사, 등장·승리·패배.
- **모션 재생**: 커스터마이징 미리보기에서 선택한 동작을 재생합니다.
- **PNG 추출**: 선택 동작의 24 또는 48장 프레임을 하나의 PNG 스프라이트 시트로 생성합니다. 6열 그리드이며, 셀 크기는 260×380입니다. 24프레임 시트는 1560×1520, 48프레임 시트는 1560×3040입니다.
- 이 프레임은 기존 일러스트 원본의 포즈, 몸통 리그, 위치·각도 보간으로 **브라우저에서 렌더링한 새로운 프레임 이미지**입니다. 각각 새로 그린 AI 원화 48장이 아닙니다.
- **안면 왜곡 방지:** 눈과 입이 포함된 얼굴 이미지에는 메시 변형을 적용하지 않습니다. 목 위치만 모션 구간 사이에서 연속적으로 보간합니다.
- PNG 프레임 생성에는 캐릭터의 **일러스트 파츠** 표현 모드가 필요합니다. 단일 업로드 이미지에는 별도의 분리 리그가 없기 때문입니다.

## 코드 구성

- \`wardrobe-generator.js\`: 8 테마, 조화 팔레트, 결정적 랜덤 시드, 잠금 기능
- \`studio-ui.js\`: 탭·프리셋·썸네일·프레임 수 선택·동작 미리보기
- \`studio.js\`: 캐릭터 검증, 저장, 내보내기, 실시간 그리기
- \`motion-library.js\`: 20종 모션의 프레임 보간
- \`doll-renderer.js\`: 기존 얼굴/의상 아틀라스를 출력·변형하며 목 연결 보정
- \`frame-export.js\`: PNG 스프라이트 시트 생성
- \`game.js\`: 모션·프로필·리듬 대전 연결

## 확인할 점

브라우저의 WebGL/Canvas 이용 가능 여부에 따라 애니메이션 표현과 처리량이 달라집니다. 자산 이미지가 모두 로드돼야 스프라이트 시트를 생성할 수 있습니다. 이미지가 섞여 보이거나 PNG 파일이 다운로드되지 않는다면 브라우저, 사용한 캐릭터 모드, 화면 크기, 발생한 오류 메시지를 기록하세요.

새롭게 그린 눈꺼풀·입·앞머리 등 **독립 원화 파츠**를 추가하는 작업은 이번 코드 개편과 별개입니다. 개별 파츠가 확보되기 전까지는 안면을 눌러 가짜 깜빡임을 만들지 않습니다.
