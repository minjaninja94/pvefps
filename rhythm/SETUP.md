# NEON DUEL — 5분 오디오 채보 & YouTube / 2인 VS

## 새 진행 방식
- **5분(300초) 이하** 보유 음원만 파형 분석에 사용합니다. 파일은 사용자의 기기에서 브라우저 Web Audio API로 분석하고, 파일 바이트를 외부 서버나 상대에게 전송하지 않습니다. 메타데이터를 해석하기 전에는 길이를 알 수 없으므로 디코딩 직후 검사합니다. 파일 크기는 최대 80MB입니다.
- 업로드 → 파일 해시 계산 → 오디오 디코딩 → 소리 강세(onset) 및 BPM 분석 → 채보 생성 → 플레이 시작.
- 채보는 감지한 강세 위치에 배치됩니다. 완전한 악보/보컬 분석은 아닙니다. 원곡과 오디오 인트로 및 박자 위치가 다르면 오프셋 보정이 필요할 수 있습니다.
- YouTube 링크는 **공식 IFrame Player API만** 사용합니다. 브라우저 보안 및 YouTube API 규약상 음성을 추출하거나 영상/음원을 내려받지 않습니다. 자동 비트 감지 채보를 원하면 권리를 보유한 음원 파일을 같은 화면에서 선택해야 합니다.
- YouTube URL + 보유 음원 선택 → 해당 음원을 분석해 채보 생성 → 분석된 채보를 이 브라우저의 localStorage에 **노트 타임스탬프만** 저장. 같은 YouTube URL로 재접속하면 기존 채보를 자동 활용할 수 있습니다. 비디오/오디오는 저장되지 않습니다.
- 음원 없이 YouTube 링크만 사용할 경우 기존 **수동 BPM 기반 채보**가 제공됩니다. 이는 실제 스트림 분석 결과가 아닙니다.
- YouTube **영상 길이 5분 초과를 차단**합니다. IFrame API의 getDuration()은 영상 메타데이터를 얻기 전엔 0이므로, 대부분 **최초 재생 순간에 길이를 확인**하고 300초를 넘으면 즉시 중단합니다. 실시간 라이브 등 길이를 확인할 수 없는 경우 채보를 진행하지 않습니다.
- 저작권과 콘텐츠 이용 허락은 개별적으로 확인해야 합니다. 공식 플레이어로 재생한다고 음악 이용에 관한 모든 권리 문제가 사라지지는 않습니다.

## 2인 파일 배틀
1. 호스트가 `TRACK = 보유 음원 분석` 선택 후 방 생성.
2. 친구가 방 코드로 입장하여 **각자 동일한 음원 파일**을 선택합니다(파일 전송 없음).
3. 양쪽이 **준비** 클릭 → 실제 오디오 분석/채보 생성 → 각 파일의 SHA-256 지문을 P2P로 비교.
4. 호스트가 시작을 누르면 **호스트의 채보만** WebRTC로 공유합니다(타임스탬프/레인/구간, 오디오 원본은 미전송).
5. 친구의 채보 검증/로딩 완료 응답 후 약 6.5초 뒤 경기 시작. 화면 왼쪽은 나, 오른쪽은 상대. 방향키 `← ↓ ↑ →`.

YouTube + 분석 채보 온라인 배틀도 가능합니다. 이 경우 호스트만 보유 오디오를 분석하여 채보를 공유해도 되고, 양쪽의 원본 YouTube IFrame 플레이어에서 음악을 재생합니다. YouTube 영상은 자동재생 차단, 광고, 네트워크 버퍼링으로 정확한 동시재생을 보장하지 않습니다.

## Firebase 설정 (추가 작업 필요)
기존 pvefps Firebase Auth 익명 인증 및 Firestore를 재사용합니다. 새 저장소/유료 API/Cloud Functions가 필요하지 않습니다.
- **GitHub의 `firestore.rules` 업데이트만으로 Firebase에 자동 반영되지 않습니다.** Firebase 콘솔 → Firestore → Rules에서 기존 FPS 규칙과 함께 최신 규칙을 게시해야 합니다.
- 신규 `rhythmRooms`의 로비/시그널링만 Firestore에 저장합니다. 채보와 플레이 입력은 WebRTC DataChannel로 전달합니다.
- TURN 중계 서버 미설정: 일부 기업/모바일망에서 연결이 실패할 수 있습니다. 웹페이지를 서로 다른 두 브라우저에서 테스트하세요.
- 서버 검증/안티치트/완전한 네트워크 시계 동기화는 아직 구현하지 않은 캐주얼 대전입니다.

## 개발 체크
- `/rhythm/`에서 데모/파일/YouTube 세 소스 모두 확인.
- 5분 초과 파일과 영상 차단, 음원 오디오 채보 노트 개수/턴 교대 확인.
- 브라우저 A/B를 각각 로그인하고 코드 입장 → 파일 해시가 다르면 거부 → 같은 파일이면 준비/로드/시작 → 점수/체력 전송.
- 유튜브 광고, 임베드 불가 영상, 모바일 기기의 자동재생 제한 점검.
- 브라우저 간 실제 Firebase 접속·게임플레이는 아직 별도 실기 테스트가 필요합니다.

공식 참고: [YouTube IFrame API](https://developers.google.com/youtube/iframe_api_reference), [YouTube 개발자 정책](https://developers.google.com/youtube/terms/developer-policies).


## 직접 MP3 파일 URL 가져오기
- 소유하거나 이용 허락을 받은 **원본 오디오 파일의 HTTPS 주소**를 입력하고 **URL 음원 가져오기 · 채보 분석**을 클릭합니다.
- 오디오 서버가 브라우저의 **CORS** 다운로드를 허용해야 합니다. 별도 서버 프록시 또는 유튜브 변환 우회는 사용하지 않습니다.
- 브라우저에서 최대 80MB의 오디오를 읽어 음원 길이(최대 5분), SHA-256, BPM 및 강세 시점으로 채보를 분석합니다. 외부 서버로 오디오 파일을 업로드하지 않습니다.
- **YouTube/watch 주소나 ss.youtube·ssyoutube 링크를 MP3로 변환하는 기능은 제공하지 않습니다.** YouTube API 정책은 승인 없는 다운로드·분리·저장을 금지합니다. 공식 YouTube 임베드는 계속 지원하며, 해당 음악에 대한 권리가 있는 원본 파일은 직접 선택하거나 권한 있는 파일 URL로 가져와 채보화할 수 있습니다.
- 온라인 2인 파일 배틀에선 양측이 같은 오디오 파일을 로드해야 합니다. 직접 URL이어도 SHA-256 일치 여부를 확인하며, 실제 오디오 데이터는 서로 공유하지 않습니다.


## URL만으로 실시간 채보 제작하기: YouTube Beat Lab

게임 \`/rhythm/\` 시작 화면에서 **유튜브 링크만으로 실제 리듬 채보 제작**을 누르거나 \`/rhythm/chart-maker.html\`을 엽니다.

1. 이용할 권한이 있는 **5분 이하 YouTube 영상** 주소를 붙여넣고 **① 영상 불러오기**를 누릅니다.
2. **② 이 탭 오디오 공유**를 누릅니다. Chrome/Edge 데스크톱의 공유 창에서 **현재 탭**과 **탭 오디오 공유**를 선택해야 합니다. 화면 공유는 분석 작업용이며 녹화 화면, 동영상, 오디오 데이터는 저장하지 않습니다.
3. 화면에 있는 정식 YouTube 플레이어에서 **▶**를 눌러 처음부터 음악을 재생합니다. 브라우저가 탭의 소리 강세를 실시간 분석합니다.
4. 재생 완료 후 자동으로, 또는 **③ 분석 종료**를 눌러 채보를 생성합니다.
5. **④ 게임에 채보 저장**을 누른 다음 게임에서 같은 YouTube URL을 선택합니다. 같은 브라우저·같은 사이트 origin의 localStorage에 저장된 노트 타임스탬프를 읽습니다.
6. 별도 내보내기가 필요하면 **채보 JSON 내보내기**를 사용합니다. 파일에는 원본 오디오가 포함되지 않습니다.

**중요:** 링크만 입력한 즉시 YouTube의 원본 파형을 분석할 수 있는 것은 아닙니다. YouTube IFrame API에서 제공하는 재생 시간과 길이는 있지만, 오디오 PCM을 직접 제공하지 않습니다. 이 제작기는 사용자가 명시적으로 공유를 허용한 **탭 오디오 스트림**의 주파수 강세를 분석합니다. 브라우저 별 오디오 캡처 지원 여부가 다르며 사용자 승인 후 음악을 **실제로 재생하는 시간**이 필요합니다. 비트를 일정 간격으로 아무렇게나 배치하는 것이 아니라 실시간 주파수 상승 지점(onset)을 검출하지만 완성된 채보 품질은 음악 장르/반주/정확도 등에 따라 달라질 수 있습니다. 영상 재생/오디오 공유가 제한되면 분석할 수 없습니다. 이 흐름은 소유하거나 관련 이용 권한을 확보한 콘텐츠에서만 사용하세요.

## AI 그림체 옷입히기 (2026-10-18 후속)

- `CHARACTER STUDIO → AI 일러스트 옷입히기`를 사용한다. 이전에 저장한 양쪽 현재 캐릭터도 새 모드로 전환되며 이름/의상/외형 선택은 유지한다. 직접 가져온 이미지는 유지한다.
- 얼굴·헤어 4세트와 의상 5종을 그림 카드 또는 선택 메뉴로 조합한다. 얼굴과 헤어는 한 세트이며, 의상 교체와 독립적이다. 머리 색/피부 색·체형·상체 실루엣·의상 팔레트·보조 움직임 강도를 조정한다.
- 대기/공격/피격 미리보기 버튼. 의상별 생성 프레임 9개(3/3/3), 머리별 표정 4개. 실제 전투에서도 공격 시점과 피격 시점에 해당 프레임을 재생한다. 보조 움직임은 호흡·머리·의상에 적용한다. **가슴 움직임 강도**는 별도 슬라이더로 0~1을 조절하며, 옷을 입은 성인 캐릭터의 호흡과 공격·피격 관성에 따라 지연·반동·감쇠한다. 갑옷은 작게, 천 의상은 더 유연하게 반응한다. 0으로 끌 수 있고 보관함·JSON에도 저장된다. 플레이 설정의 이펙트 줄이기는 전투 중 가슴 물리를 포함한 보조 움직임도 끈다.
- 저장된 의상 시트는 신체를 덮는 성인 전투 의상이다. 자연스러운 보조 물리는 렌더러에서 계산하며 AI 이미지를 다시 생성하지 않는다.
- 자산·실제 생성 프롬프트: `assets/doll/ASSETS.json`. `doll-renderer.js`는 이미 저장된 시트를 합성/재생하며 실시간 AI 호출을 하지 않는다.
- 의상 시트는 기존 머리가 있는 전체 몸 그림을 언더페인트로 유지하고, 포즈별 얼굴 특징점에 독립적인 큰 머리 레이어를 합성한다. 목선 위 전체를 가로로 잘라내면 팔/어깨가 잘리므로 그렇게 수정하지 않는다.
