# NEON DUEL — YouTube / Local Audio / 1v1

## 실행
- 기본 게임: `/rhythm/` → **혼자 vs 봇**.
- 유튜브: TRACK = **YouTube 공식 임베드**, URL + BPM + 채보 시작 지연을 입력하고 시작. 가운데 원본 유튜브 플레이어의 ▶를 눌러 재생하면 `YT.Player.getCurrentTime()`에 맞춰 채보가 진행됩니다. 영상이 일시정지되거나 버퍼링하면 게임도 진행되지 않습니다.
- TAP BPM: 영상 음악의 박자에 맞춰 버튼을 반복 클릭해서 BPM을 추정할 수 있습니다.
- 직접 보유한 MP3/WAV/OGG 파일: **로컬 오디오 파일** 선택 시 브라우저의 Web Audio API로 디코딩하고 강세(onset) 및 대략적인 BPM을 분석합니다. 파일은 Firebase/서버로 업로드하지 않습니다. 현재는 **솔로 전용**이며 정확한 악보 제작/복잡한 리듬 채보와는 차이가 있습니다.
- 두 플레이어 모두 방향키 `← ↓ ↑ →`; PC Chrome/Edge 권장.

## YouTube 관련 한계와 저작권
유튜브 스트림의 오디오 데이터를 직접 다운로드, 분리, 녹음 또는 분석하지 않습니다. 공식 IFrame Player API로 **유튜브가 직접 제공하는 영상 및 음원**을 재생하며, 유튜브 영상 URL이나 비트맵을 우리 서버에 보관하지 않습니다.

**유튜브 채보는 실제 오디오를 분석한 결과가 아닙니다.** 사용자가 입력한 BPM 및 지연 값을 바탕으로 리듬 패턴을 생성합니다. 영상마다 템포가 바뀌거나 박자 위치가 부정확하면 채보와 음악이 맞지 않을 수 있습니다. 일부 영상은 삽입 재생이 금지되거나 광고·연령·지역 제한이 적용될 수 있습니다.

공식 임베드를 사용해도 모든 음악 이용에 관한 저작권 문제가 자동으로 사라지는 것은 아닙니다. 콘텐츠 권리자의 허락 및 YouTube 이용조건을 준수해야 합니다. 유튜브 플레이어의 컨트롤/광고를 우회하거나 변경하지 않습니다.

참고: https://developers.google.com/youtube/iframe_api_reference
정책: https://developers.google.com/youtube/terms/developer-policies

## 온라인 2인 리듬 배틀
1. 양쪽이 **온라인 2인 VS** 모드를 선택합니다.
2. 첫 번째 플레이어가 트랙·BPM 설정 후 **방 만들기** → 5자리 코드 공유.
3. 두 번째 플레이어가 코드를 입력해 **입장**.
4. WebRTC P2P 연결이 완료되면 각자 **준비** 클릭.
5. 방장이 **HOST START**. 양쪽에서 같은 음원·동일한 시드의 턴별 채보를 생성합니다. 왼쪽이 본인, 오른쪽이 상대방으로 보입니다.
6. 유튜브 모드는 **두 플레이어 각각 자신의 공식 유튜브 플레이어에서 재생**해야 합니다. 자동 재생 차단과 버퍼링 때문에 현재 유튜브 2인 재생은 **최선의 노력 동기화(best-effort)**이며 완벽한 동시 재생·공정한 경쟁 판정을 보장하지 않습니다.
7. 입력 결과/노트 ID/판정은 WebRTC DataChannel로 전달됩니다. Firebase에는 방·ICE 연결을 위한 SDP만 기록하며 게임의 노트마다 Firestore 쓰기하지 않습니다.

### 반드시 필요한 Firebase 설정
기존 FPS 게임이 사용하는 **같은 Firebase 프로젝트**의 익명 인증을 사용합니다. 콘솔에 아직 적용하지 않았다면:
- Firebase Authentication → 익명 로그인 사용.
- Firebase 콘솔 → Firestore → Rules에 **저장소 루트의 최신 `firestore.rules`를 검토 후 게시**. 이번에 추가된 `rhythmRooms` 및 `signals` 블록이 필요합니다. GitHub에 커밋한 것만으로 콘솔의 규칙이 자동 게시되지는 않습니다.
- 기존 `mpRooms`, `rankings` 규칙은 유지합니다.
- RTCPeerConnection은 공개 STUN만 사용합니다. 회사망·CGNAT 등에서는 연결 실패할 수 있으며 TURN 릴레이 서비스는 설정되어 있지 않습니다.
- 본 구현은 **친구 간 캐주얼 배틀**입니다. 서버 판정 및 부정행위 방지, 고정밀 오디오 동기화는 구현하지 않았습니다.

### 점검 항목
- 솔로 데모곡과 방향키 판정 작동.
- 유튜브 URL, 공식 플레이어 로드, 재생·일시정지와 노트 시계가 함께 움직이는지 확인.
- 파일 업로드 후 WAV/MP3 디코딩, 감지된 BPM과 채보 확인.
- Chrome 프로필 또는 별도 기기 2개로 방 코드/접속/상호 준비/시작/노트 판정·게이지 공유 확인.
- Firestore의 룰 오류, P2P 연결 실패(서로 다른 네트워크), 광고·버퍼링시 싱크 차이를 점검.

실제 배포 브라우저 간 연결 및 Firebase 관리 콘솔에 게시된 규칙 검증은 별도로 진행해야 합니다.
