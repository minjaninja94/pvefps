# 차원전쟁 TCG 기획서 v5.0

기준 버전은 v5.0이다. PvP 기본 규칙과 카드풀 규모는 본문의 v5.0 규격을 따른다. 카드 예시와 PvE 세부 구성은 프로토타입 사양이며, 테스트 목표와 미확정 항목은 마지막 두 절에 기록한다.

## 1. 게임 개요

서로 다른 세계가 차원 균열을 통해 맞닿는 서브컬처 판타지 TCG다. 이세계 조선의 홍련, 네온 아이돌의 루나, 성운 항해단의 루미 카이처럼 진영의 전술을 상징하는 캐릭터가 전개를 이끈다. 플레이어는 일반 전장에서 상대 생명력을 깎는 동시에 중앙 격돌존에 몬스터를 투입해 지속 압박을 건다. 진영별 강림을 준비하는 동안에도 서로의 서치, 전투, 점령에 범용 반응패로 개입할 수 있다.

## 2. PvP 기본 규칙

| 항목 | v5.0 규칙 |
| --- | --- |
| 시작 생명력·승리 | 각자 100. 상대 생명력이 0 이하가 되면 승리. |
| 덱 | 메인 덱 정확히 40장, 동일 카드 최대 3장. 강림 몬스터도 메인 덱에 포함하며 엑스트라 덱은 사용하지 않는다. |
| 진영 | 8개 중 하나를 선택한다. 선택한 진영의 전용 카드와 범용 카드로 편성한다. |
| 시작 손패 | 선공 5장, 후공 6장. 선공은 첫 턴 드로우와 공격을 건너뛴다. |
| 배치와 강림 | 손패의 하수 기본 배치는 자신의 턴당 1회. 조건 강림은 카드별 조건을 따른다. 고수는 양측 모두 각자의 첫 턴에 강림할 수 없다. |
| 자원과 위계 | 마나·에테르·CP 등 공용 지불 자원과 숫자 레벨을 사용하지 않는다. 생명력 소모, 필드 몬스터 퇴장 등 특정 강림이 요구하는 대가는 카드에 명시한다. |
| 기본 공격 | 공격력만큼 확정 피해. 몬스터끼리 싸우면 서로 공격력만큼 내구도에 피해를 주고, 누적 피해는 턴이 넘어가도 유지된다. 내구도가 0 이하인 몬스터는 데스존으로 간다. |
| 직접 공격 | 일반 몬스터는 상대 몬스터가 있어도 상대 본진을 공격할 수 있다. 상대에게 적용 가능한 `수호`가 있으면 직접 공격이 차단된다. 공격력 12의 직접 공격은 생명력 100을 88로 낮춘다. |
| 반응 | 행동 선언 → 상대 대응 → 선언자 재대응 → 결과 처리. 서치, 강림, 공격, 영역 이동 등은 카드에 적힌 시점에 반응할 수 있다. 동시 발동과 세부 우선권은 미확정이다. |

프로토타입에서는 턴을 시작·드로우 → 전개 → 전투 → 종료 순서로 검증한다. 전개 중에는 기본 배치, 강림, 전술 사용과 격돌존 진입을 처리한다. 종료에는 점령 피해를 확인한다.

```text
                      상대 생명력 100
                      상대 전술존 5칸
                    상대 몬스터존 5칸
                    상대 격돌존   1칸
                           ↕
                      내 격돌존   1칸
                    내 몬스터존   5칸
                      내 전술존   5칸
                        내 생명력 100

각 플레이어의 별도 영역: 덱 · 손패 · 데스존 · 단절된 이계
```

- **일반 몬스터존:** 5칸. 근접, 사격, 아이돌, 마법사 등 병종에 따른 배치 제한이 없다. 일반 전투에 전후열이나 사거리 계산을 요구하지 않는다. 성운의 좌표 전이처럼 카드가 지정할 때 위치를 참조한다.
- **전술존:** 5칸. 전술, 장비, 지속 효과 등 카드가 요구하는 위치를 제공한다. 격돌존을 합하면 플레이어당 일반 몬스터 5기와 격돌 몬스터 1기를 동시에 둘 수 있다.
- **데스존:** 파괴된 몬스터와 사용한 카드가 가는 영역. 회수·소생·데스존 발동 효과가 사용할 수 있다.
- **단절된 이계:** 격리·추방 영역. 복귀나 참조를 명시한 효과가 접근할 수 있다. 이계 봉인의 정보 공개와 복귀 예외는 판정 설계 항목이다.

## 3. 격돌존

각 플레이어에게 1칸씩 주어 두 몬스터가 마주 보는 전장을 만든다. 하수·중수·고수 모두 진입할 수 있다.

| 상황 | 처리 |
| --- | --- |
| 기본 진입 | 자신의 전개 단계에 일반 몬스터존의 몬스터를 빈 아군 격돌존으로 이동. 플레이어당 자신의 턴에 1회. |
| 진입한 턴 | 기본적으로 공격과 점령 피해 발동 불가. 카드로 상대 턴에 투입된 몬스터도 상대의 단독 점령을 즉시 막을 수 있다. |
| 양쪽에 몬스터가 있음 | 대치 상태. 격돌 몬스터는 상대 격돌 몬스터를 우선 공격하며, 양측 점령 피해가 막힌다. 위계나 공격력 우위만으로 점령을 결정하지 않는다. |
| 상대 격돌존이 비어 있음 | 격돌 몬스터는 적 일반 몬스터를 공격할 수 있다. 격돌존에서는 상대 본진을 직접 공격할 수 없다. |
| 단독 점령 보상 | 진입 이후 다음 자신의 턴 종료까지 격돌존을 유지하고 상대 격돌존이 비어 있으면 해당 종료 시점에 한 번 점령 피해를 준다. 이후에도 자신의 턴 종료마다 조건을 확인한다. |
| 철수 | 자신의 턴 또는 지정된 카드 효과로 빈 아군 일반 몬스터존으로 이동한다. |

고수 기본 점령 피해는 12, 대장군 홍련의 단독 점령 효과는 20이다. 홍련의 20은 기본 12를 대체한다. 하수·중수의 기본 피해량은 미확정이다. 강림 이후 재진입이나 교대, 종료 단계에서 발생한 이동의 판정은 프로토타입에서 검증한다.

**진행 예시** — 조선의 두 번째 턴에 홍련이 강림해 격돌존에 들어간다. 그 턴에는 점령 피해가 없다. 상대는 자기 턴에 `도전장`으로 하수 몬스터를 투입해 점령을 막는다. 조선의 세 번째 턴에 홍련이 대치 상대를 쓰러뜨리고 살아남았다면, 턴 종료에 상대 격돌존이 비어 있고 피해를 막는 효과가 없으면 홍련이 상대 생명력을 20 줄인다. 일반 몬스터들은 이 공방과 병행해 상대 본진을 압박할 수 있다.

## 4. 진영 위계와 고유 강림

하수는 초동과 조건 준비, 중수는 전술 사용이나 아군 전개에 따른 연계, 고수는 여러 행동과 대가를 요구하는 결정타를 담당한다. 하수·중수·고수는 공통 역할 분류이며 카드에는 진영 고유 명칭을 표기한다. 카드팩 희귀도 C/R/SR/UR는 이 위계와 독립적이다.

각 고수 카드에 허용된 출발 영역, 필요한 전투·전술·이동 기록, 소모할 카드 및 이동 목적지를 적는다. 카드에 따라 손패·필드·데스존 등에서 강림할 수 있다. 진영당 고수 3종은 각기 다른 조건을 가지며, 최소 1종은 격돌 중심으로 설계한다. 진영 특성은 턴당 1회 적용한다.

| 진영 | 하수 / 중수 / 고수 | 고유 강림과 플레이 방식 | 진영 특성 |
| --- | --- | --- | --- |
| 이세계 조선 | 초병 / 별장 / 대장군 | **어명 강림.** 서로 다른 병사와 군령을 연계하는 군진. 도깨비, 선비, 무장, 신선술이 세계관의 중심이다. | 자신의 턴에 서로 다른 조선 병사 2종을 전개하면 병사 1기 공격력 +2. |
| 네온 아이돌 | 연습생 / 정식 멤버 / 헤드라이너 | **앙코르 강림.** 보컬·댄서 등 역할이 다른 멤버와 공연 성공 기록을 활용한다. 미래형 공연과 버추얼 스타가 테마다. | 자신의 턴에 세 번째 아이돌이 등장하면 1장 드로우. |
| 철심 기계도시 | 시제품 / 실전기 / 결전기 | **도킹 강림.** 장비를 갖춘 기체를 결합하며 장비 종류로 효과를 바꾼다. | 도킹에 사용한 장비 1장을 손패로 회수. |
| 황혼 혈족 | 종복 / 귀족 / 진조 | **혈계 계승.** 데스존 혈족의 격리와 자신의 생명력 소모로 진조를 부른다. | 자신의 카드 효과로 처음 소모하는 생명력 4 감소. |
| 녹음 수호자 | 새싹 / 정령 / 세계수 | **개화.** 정령의 생존 기록과 새싹 전개로 세계수를 키우는 유지력 진영. | 아군이 상대 턴을 생존하면 아군 1기의 내구도 2 회복. |
| 심해 군체 | 유생체 / 포식체 / 심연주 | **포식 진화.** 개체를 증식시킨 뒤 먹잇감으로 소모하며 소재 종류로 능력이 달라진다. | 자기 턴 첫 군체 토큰 파괴 시 유생체 토큰 1기 생성. |
| 성운 항해단 | 탐사대 / 항행대 / 기함급 | **좌표 전이.** 빈 칸으로 이동해 콤보를 잇고 이계 장치를 복구해 기함을 호출한다. | 아군 몬스터의 첫 위치 이동 시 1장 드로우 후 1장 버림. |
| 유리 마도원 | 견습 / 집행관 / 대현자 | **공명 현현.** 서로 다른 전술을 해결하고 데스존의 전술을 봉인해 강림한다. | 자기 턴에 두 번째 서로 다른 전술을 해결하면 전술 피해 +3. |

### 성운 항해단의 공간이동

이동 효과는 출발 위치와 목적지를 명시한다. `공간항법사 루미`가 빈 인접 몬스터존으로 이동하거나 `차원 전이 장치`가 아군을 옮기면 이동 기록을 쌓는다. `좌표 탐사 드론`은 이동에 성공하면 성운 전술을 찾을 수 있다. `중력 역전 포격`은 상대를 밀어내고, `강제 격납`은 대응되는 전술존으로 상대 몬스터를 옮기는 카드 후보다. 격납 카드의 취급, 복귀와 빈 칸 판정은 미확정이다. 초공간 기함 시제품은 몬스터존 이동과 이계 복구를 결합해, 공간이동에서 격돌 압박으로 이어지는 플레이를 검증한다.

## 6. 선택적 D6 전술

일반 공격은 확정 판정이다. 워해머식 명중·엄폐·방어 굴림은 지정된 사격이나 특수 전술에서만 사용한다. 카드에 굴릴 D6 수, 성공 기준, 성공당 효과와 재굴림 가능 여부를 표시한다.

`견제 포격`은 D6 3개를 굴려 4 이상마다 격돌 몬스터에게 피해 6을 준다. 예를 들어 2·4·6이면 명중 2회, 피해 12다. 조준이나 엄폐가 개입한다면 효과에 명시된 주사위 또는 피해만 수정한다. 범용 재굴림 및 방어 굴림의 적용 순서와 공격 대상이 사라졌을 때의 처리 기준은 미확정이다.

## 7. PvE 모험과 수집 경제

PvE 모험은 기본 전투와 진영 콤보를 익히고, 원정 중 보물과 카드로 덱을 성장시키는 별도 모드다. v4.0의 진행안은 20장 진영 스타터 → 일반 전투 승리 후 후보 3개 중 카드 선택 → 특수 이벤트에서 유물 획득 → 중간 보스 뒤 카드 제거 또는 강화 → 최종 보스까지 총 8전이다. 20장과 8전은 모험의 초기 설계값이며 PvP 덱은 40장을 사용한다. 보물과 보스 전용 효과는 모험에 한정한다.

| 모험 | 전투 기믹 |
| --- | --- |
| 조선의 요괴 봉기 | 포졸을 계속 부르거나 데스존 병력을 부활시키는 보스. 왕명과 전장 정리 타이밍을 시험한다. |
| 네온 스테이지 붕괴 | 라이벌 아이돌과 무대 효과. 공연을 끊거나 상대의 앙코르 조건을 늦춘다. |
| 성운 균열 탐사 | 위치 전이, 전술존 격납, 단절된 이계 복귀를 반복하는 보스. 빈 칸과 점령 유지가 중요하다. |

모험 완료 보상 후보는 카드팩, 제작 재료, 캐릭터 스킨이다. 경쟁 카드의 성능은 희귀도와 독립적으로 설계한다. 카드팩 구성·가격·확률, 중복 처리, 제작 비용, 스타터 지급량, PvE 보상 주기, 유료 상품 범위는 미확정이다.
