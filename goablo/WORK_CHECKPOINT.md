## 저장 원칙

사용자는 공개 저장소 minjaninja94/pvefps에 GOABLO 코드, 제공 스프라이트, 재개 기록을 저장하는 것을 승인했다.

- 작은 작업 단위마다 커밋하고 GitHub 원격 반영을 확인한다.
- 사용자에게 커밋 해시와 변경 내용을 알린다. 로컬 저장만으로 백업 완료라고 보고하지 않는다.
- 이 문서에 완료 내용, 검증 결과, 다음 작업을 남긴다.
- 미완성 작업이 오래 지속되면 별도 작업 브랜치에 WIP 커밋으로 백업한다.
- 기존 FPS 및 루트 게임 선택 화면을 보존하고 GOABLO는 goablo/에서 개발한다.
