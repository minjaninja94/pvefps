# GOABLO 작업 재개 기록

갱신일: 2026-09-15

## 저장 원칙

사용자는 공개 저장소 minjaninja94/pvefps에 GOABLO 코드, 제공 스프라이트, 재개 기록을 저장하는 것을 승인했다.

- 작은 작업 단위마다 커밋하고 GitHub 원격 반영을 확인한다.
- 사용자에게 커밋 해시와 변경 내용을 알린다. 로컬 저장만으로 백업 완료라고 보고하지 않는다.
- 이 문서에 완료 내용, 검증 결과, 다음 작업을 남긴다.
- 미완성 작업이 오래 지속되면 별도 작업 브랜치에 WIP 커밋으로 백업한다.
- 기존 FPS 및 루트 게임 선택 화면을 보존하고 GOABLO는 goablo/에서 개발한다.

## 확인한 상태

- 저장소: https://github.com/minjaninja94/pvefps
- 브랜치: main
- 기존 개발 기준 커밋: 249fa506883dbb6c2a103c5ba0ea812e411da447
- 최신 구현/테스트 커밋: b6e12cb63cf8cdf098f45400ccae7c5a8f267415
- Node.js, npm, Python 정적 서버 및 Chromium/Playwright 헤드리스 실행이 정상이다.
- WebGL 2.0 렌더러, 캐릭터 선택, Act 1 던전 진입을 실제 브라우저에서 확인했다.
- 플레이어/몬스터 아틀라스가 HTTP 200으로 로드되고 문서의 `data-sprite-status`가 `ready`임을 확인했다.
- 실행 환경의 외부 도메인 제한으로 Google Fonts 요청만 실패했으며 게임 코드와 스프라이트 로드 오류는 없었다.
- 이번 작업의 변경 경로는 모두 `goablo/` 아래이며 루트 FPS 파일은 변경하지 않았다.
