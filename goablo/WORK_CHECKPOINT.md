# GOABLO 작업 재개 기록

갱신일: 2026-09-15

## 저장 원칙

사용자는 공개 저장소 minjaninja94/pvefps에 GOABLO 코드, 제공 스프라이트, 재개 기록을 저장하는 것을 승인했다.

- 작은 작업 단위마다 커밋하고 GitHub 원격 반영을 확인한다.
- 사용자에게 커밋 해시와 변경 내용을 알린다. 로컬 저장만으로 백업 완료라고 보고하지 않는다.
- 이 문서에 완료 내용, 검증 결과, 다음 작업을 남긴다.
- 미완성 작업이 오래 지속되면 별도 작업 브랜치에 WIP 커밋으로 백업한다.
- 기존 FPS 및 루트 게임 선택 화면을 보존하고 GOABLO는 goablo/에서 개발한다.

- 브랜치: main
- 기존 개발 기준 커밋: 249fa506883dbb6c2a103c5ba0ea812e411da447

- GitHub의 goablo/index.html을 읽어 기존 코드 존재를 확인했다.
- 작업 환경 연결 실패와 로컬 파일 읽기/실행 도구 부재로 첨부 파일 판독, 스프라이트 적용, 실행 검증은 수행하지 못했다.
- 이전 대화의 미커밋 변경은 복구 여부를 확인하지 못했다. 구현 완료로 간주하지 않는다.

## 이번에 구현 및 원격 저장한 기능

- 091b49958cc6226cfc3668c3db2049ecb8b26b57: 바닥 클릭 이동, 적 클릭 시 접근 및 기본 공격, Shift+좌클릭 제자리 공격. WASD로 클릭 이동을 취소하고 수동 이동. 패널 열기 및 지역 전환 시 이동 명령 초기화.
- 같은 커밋: 공격한 적과 선택한 적 머리 위 이름 및 체력바. 최근 피격 시 4초 표시, 선택 중 지속 표시, 사망/지역 전환 시 제거. 조작 안내 갱신.
- ec9d436e3ebcfbc960c47bfa55e9440e3cdf6593: 인벤토리 이름·효과 검색, 등급 및 부위 필터, 미장착만 보기, 결과 개수 및 빈 결과 안내. 장착/판매 후 필터 유지.
- 검증: 두 변경의 전체 game.js에서 import 선언을 제외하고 JavaScript 파서(new Function)로 문법 검사 통과. 원격 main 파일을 다시 읽어 작성한 내용과 정확히 일치함을 확인. CSS의 [hidden] 규칙도 확인.
- 한계: 브라우저/WebGL 실행 및 실제 조작 검증은 하지 못했다. 첨부 스프라이트는 아직 판독·적용하지 못했다. v0.2 전체와 Act 1 완성을 의미하지 않는다.
