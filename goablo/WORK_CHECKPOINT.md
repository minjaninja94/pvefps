# GOABLO 작업 재개 기록

## 2026-09-23 캐릭터 변경·새 여정 안전 흐름

- 캐릭터 변경 시 새로고침과 크롬 `confirm()`을 제거해 blur 이벤트로 설정 패널이 겹치며 강제 일시정지되던 문제 수정.
- 설정에서 캐릭터를 즉시 변경하되 막·레벨·경험치·금화·인벤토리·회복약·심연 기록·보스 순환은 유지.
- 직업 전용 스킬·분기·장착 장비만 초기화하고 현재 레벨까지 획득한 스킬 포인트를 전액 반환.
- 기존 저장을 덮는 새 여정은 브라우저 경고가 아닌 게임 내부 확인창에서만 실행하며 닫기와 기존 여정 계속하기는 저장을 변경하지 않음.

## 2026-09-23 12막 이후 보스 순환

- 캠페인 1~12막의 전용 보스 순서는 유지하고 고아심연 보스 선택을 별도 규칙으로 분리.
- 심연 일반 단계에서는 B01~B11 전체를 셔플백으로 한 번씩 소진해 특정 보스 편중과 연속 중복을 방지.
- 심연 10·20·30단계 등 10의 배수에서만 B12 고아들의왕을 확정 출현.
- 셔플백과 직전 보스를 플레이어 저장 데이터에 포함해 재접속 이후에도 균등 순환을 유지.

## 2026-09-23 액트별 오리지널 음악·생물 음성 교체

- 48초 무봉제 반복용 오리지널 OGG 배경음 5곡 생성: 역병 지하묘지, 불타는 수용소, 뼈의 왕좌, 추락한 대성당, 버림받은 왕국.
- 저음 드론·포먼트 합창·산업 타악·불규칙 노이즈를 액트별 박자와 음계로 달리 구성하고 마을에서는 같은 곡을 낮은 음량으로 재생.
- 좀비·구울·벌레·타천사·인간형의 발견/공격/사망 WAV 15개를 생성하고 이름·종족·행동에 따라 자동 선택.
- 기존 오실레이터 비프음을 런타임에서 완전히 제거하고 플레이어 피격도 인간형 숨·신음 샘플로 교체.
- 설정에 배경음악 음량 조절을 추가하고 생성기 `tools/generate-original-audio.mjs`로 모든 음원을 재현 가능하게 유지.

## 2026-09-23 스킬 이펙트 위치 분리·프레임 안정화

- 지정형 장판·낙하 스킬만 마우스 포인터 지점에 공통 바닥 이펙트를 표시하도록 변경.
- 근접 스킬은 캐릭터 전방 방향성 타격 이펙트, 투사체 스킬은 비행·충돌 아틀라스만 사용해 중복 커서 이펙트를 제거.
- 이동기는 공통 시전 이펙트를 생략하고 실제 이동 궤적만 표시하며, 버프·소환 계열은 시전자 중심 오라만 유지.
- 일시 이펙트, 동적 점광원, 발광 투사체 수에 각각 상한을 적용해 연타·다중 투사체 상황의 GPU 부하를 제한.

## 2026-09-23 샘플 기반 괴물 음성·동적 전투 조명

- 저장소의 실제 WAV 샘플을 Web Audio 버퍼로 읽어 일반 몬스터와 보스의 발견·공격·피격·특수 공격·사망 음성으로 구분해 연결.
- 같은 음성이 기계적으로 반복되지 않도록 재생 간격, 피치, 거리 음량, 화면 좌우 위치를 매번 조절하고 동시 재생 수를 제한.
- 속성 투사체에 이동 광원, 충돌·광역기·보스 페이즈·피격·사망에 짧게 감쇠하는 점광원을 추가.
- 전설·유니크·부모급 드롭은 기존 아이콘 위에 아틀라스 빛기둥과 맥동 광원을 표시하며 별도 3D 도형은 사용하지 않음.

## 2026-09-22 스킬 이펙트 상시 연결·자동 난이도

- 모든 스킬 시전 시 속성별 friendly VFX와 목표 지점 area VFX를 반드시 표시.
- 투사체·충돌·광역·지속 장판의 기존 생성 아틀라스 연결을 유지하면서 시전 순간 가시성을 강화.
- 수동 난이도 선택을 제거하고 누적 1~4층 일반, 5~12층 악몽, 13층 이후 지옥으로 자동 전환.
- 같은 난이도 구간에서도 매 층 체력·공격력·이동 속도가 증가하도록 연속 스케일링 적용.
