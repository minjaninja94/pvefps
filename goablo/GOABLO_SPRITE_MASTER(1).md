# GOABLO SPRITE MASTER V1

## 목적

Work에서 수십 종의 캐릭터/몬스터 스프라이트를 반복 제작할 때 토큰 사용을 최소화하는 공통 규격.
각 작업마다 전체 GDD를 재분석하지 말고 이 파일과 sprite\_queue.json을 우선 참조한다.

## 생성 입력 우선순위

스프라이트 생성과 통합 작업은 다음 자료를 순서대로 적용한다.

1. [GOABLO 개발 요구사항 v0.2](./GOABLO_WORK_REQUIREMENTS_V0.2.md): 최신 게임 방향, Act 생태계, 보스 정체성, 제작 큐와 완료 기준.
2. 이 Sprite Master: 반복 생성에 사용하는 공통 시각 규격과 제작 방식.
3. `GOABLO_sprite_queue(1).json`: 현재 Job의 ID, 이름, Base Family, traits, 상태, 소스와 아틀라스 행.

내용이 충돌하면 최신 요구사항 v0.2를 우선한다. 단, queue의 `integrated` 상태와 기존 완성 파일은 재생성하지 않고 실제 게임 연결 상태를 먼저 확인한다.

## 생성 전 필수 규칙

* 특정 상용 게임의 자산, 캐릭터 또는 고유 디자인을 복제하지 않고 독자적인 실루엣으로 제작한다.
* 현재 Job의 Act 테마, 이름, Base Family와 traits를 모두 반영하며 모든 적 이름에 문법상 자연스럽게 `고아`를 포함한다.
* 일반 몬스터는 Idle, Walk, Attack, Hit, Death, Corpse와 런타임 manifest까지 있어야 완료할 수 있다.
* 보스는 일반 몬스터의 단순 확대가 아니라 고유 실루엣과 전용 패턴을 읽을 수 있는 외형을 가져야 한다.
* 장비와 각인 촉매는 인벤토리 아이콘과 월드 드랍 실루엣을 구분하고, 전설 이상은 바닥에서도 등급을 식별할 수 있게 한다.
* 같은 Batch에서는 카메라 각도, 광원, 비율, 바닥 앵커, 프레임 순서와 크기를 고정한다.
* 생성 파일만 존재하는 상태는 완료가 아니다. manifest 등록, 게임 연결, death에서 corpse 전환과 실행 검증을 마친 뒤 queue를 `integrated`로 변경한다.

## 공통 스타일

* 고정 쿼터뷰 기반 2.5D ARPG, 높은 전투 가독성.
* 스타일라이즈드 약 3등신. 음울한 다크 판타지 팝업북 분위기.
* 누더기, 창백한 피부, 병든 느낌, 비정상적 신체 비율.
* 괴물은 비대칭/신체변형/뼈/갑각/살덩이/촉수를 활용하되 종별 실루엣을 명확히 구분.
* 특정 상용 게임 자산/캐릭터를 복제하지 않고 디자인 원리만 참고.
* 투명 배경 PNG. 동일 카메라 각도, 광원, 바닥 앵커, 스케일 규칙 유지.

## 일반 몬스터 애니메이션

Idle 4F / Walk 6F / Attack 6F / Hit 3F / Death 6F / Corpse 1F.
실제 특수공격이 있는 몬스터만 Special Attack 추가.
기본 4방향 제작 + 가능한 방향은 좌우 미러링.
비대칭 보스처럼 미러링이 부자연스러운 경우만 별도 제작.

## Base Family

PLAYER / HUMANOID / ZOMBIE / SKELETON / SPIDER / INSECT / DEMON / FLESH / ANGEL / KNIGHT

## 시체

모든 몬스터는 Death와 연결되는 Corpse 스프라이트를 가진다.
시체는 다음 던전 진입까지 남으며 시체폭발/부활/감염/시체먹기/혼령추출 등에 사용 가능.
해골은 뼈더미, 거미는 다리가 오므라든 형태 등 종족별 사체 실루엣 유지.

## 네임드

네임드용 신규 전체 스프라이트는 만들지 않는다.
기본 몬스터에 scale/tint/aura/horns/spikes/glowing eyes/overlay/element VFX를 런타임으로 조합한다.
모든 적 이름에는 문법상 자연스러운 위치에 '고아'가 반드시 포함된다.

## 보스

일반 몬스터 대비 화면상 약 2.5\~4배 허용. 단순 확대 금지, 고유 실루엣 필수.
거미=다리/복부, 벌레=마디/다족, 타락천사=훼손된 날개, 듀라한=목/중갑/참수,
칼날군주=칼날+육체, 육괴=신체결합, 촉수형=촉수+거대 입처럼 기괴함의 원인을 구분한다.
고아의 왕은 모든 요소들을 하나씩 가진 엄청나게 기괴한 형태로 만들어야한다.

## 플레이어

PLAYER Base를 공유하되 6개 클래스 실루엣 분리:
힘쎈고아=큰 체격/대형무기
교회고아=성직자/방패·철퇴
뼈고아=마른 체형/사령
마법고아=로브/마법도구
활고아=가벼운 체형/활·석궁
도둑고아=후드/단검·쌍수
가능하면 몸체와 무기/일부 장비를 레이어 분리해 장비 변경 때 전체 캐릭터를 재생성하지 않는다.
현재 드롭다운으로 임의로 무기를 바꿀수 없게하고 장비한 무기에 따라서 공격이 바뀌게 설정해야한다. 

기본 무기는 현재 설정된 각 캐릭터의 첫번째 대표 무기로 한다. 

## 장비/촉매

장비 슬롯마다 월드 드랍 실루엣을 구분한다.
전설/유니크/부모급은 가능한 한 고유 외형을 가진다.
이프리트의 돌, 운디네의 돌, 신성한 성서, 피의 갈망 수정, 심연의 눈물,
민첩의 룬, 힘의 각인, 지능의 눈 등 각인 촉매도 개별 스프라이트 제작.

## Work 토큰 절약 규칙

1. 이 규격을 작업마다 다시 요약/재작성하지 않는다.
2. 전체 GDD를 몬스터마다 다시 읽거나 분석하지 않는다.
3. sprite\_queue.json의 현재 Job만 읽고 순서대로 처리한다.
4. 몬스터별 장문의 설명/중간 보고를 작성하지 않는다.
5. 완료 결과 파일과 manifest만 기록한다.
6. Base Family와 기존 완성 스프라이트를 최대한 재사용한다.
7. 네임드는 신규 생성하지 않고 런타임 변형으로 처리한다.
8. 실패 Job만 재작업하고 완료 Job은 다시 생성하지 않는다.
9. Act 단위 Batch로 처리한다.
10. 첫 완성 몬스터를 Style Master로 고정하고 이후 일관성을 유지한다.
11. Batch 시작 시 요구사항 v0.2의 관련 Act와 완료 기준만 확인하고 전체 문서를 반복 재분석하지 않는다.
