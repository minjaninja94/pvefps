# GOABLO 개발 요구사항 v0.2

*Work 구현용 통합 지시서 · 기존 v0.1 GDD에 추가/우선 적용*

## 0. Work에 전달할 핵심 지시

기존 GOABLO 기획과 현재 프로토타입을 유지하되, 아래 요구사항을 우선순위가 높은 최신 사양으로 반영한다. 기존 FPS식 WASD 조작과 단순 원형 VFX는 폐기하고, 클릭 이동 기반 2.5D ARPG로 전환한다. 플레이 검증/밸런스 완전 검증보다 기능·콘텐츠 구현을 우선하되 데이터 구조는 이후 확장이 가능하게 만든다.

- GitHub 기존 GOABLO 경로/구조를 최대한 보존하며 단계적으로 수정한다.

- 모든 스킬·아이템·몬스터·함정은 DB/데이터 중심으로 관리하고 UI 설명과 실제 수치가 동일 데이터를 참조하게 한다.

- Diablo, Dead Space, Tree of Savior, Limbus Company, Overwatch 등의 자산/고유 디자인을 복제하지 않는다. 카메라·가독성·타격감·기괴함 같은 원리만 참고해 독자 디자인으로 만든다.

## 1. 아트 방향 및 스프라이트

기본 방향은 '가독성 좋은 2.5D 다크 판타지 팝업북'이다. Tree of Savior 계열의 고정 쿼터뷰·스타일라이즈드 비율·디오라마 가독성을 참고하되 훨씬 음울하고 잔혹하게 만든다. Dead Space식 신체 변형과 Diablo식 악마적 실루엣은 원리만 참고한다.

- 캐릭터: 약 3등신 기반, 헝클어진 머리·창백한 피부·누더기·낡은 신발/맨발·과장된 무기. 귀엽고 깨끗한 느낌보다 버려진 아이가 보는 악몽 같은 분위기.

- 몬스터: 각 종의 정체성이 실루엣에서 드러나야 한다. 거미는 거미답게, 벌레는 마디/다족, 악마는 뿔/뼈/갑각, 육괴는 살덩이/촉수/비대칭 변형을 사용한다.

- 몬스터 제작 세트: Idle / Walk / Attack / Hit / Death + 최종 시체 스프라이트. 시체는 다음 던전까지 맵에 남는다.

- 장비는 슬롯/아이템마다 별도 아이콘과 월드 드랍 스프라이트를 가진다. 전설 이상은 가능하면 고유 외형을 바닥에서도 식별 가능하게 한다.

- 각인 촉매(이프리트의 돌, 운디네의 돌, 신성한 성서, 피의 갈망 수정, 민첩의 룬, 힘의 각인, 지능의 눈 등)도 개별 드랍 스프라이트를 제작한다.

- 각 Act는 방/복도/대형 전투방/함정방/보상방/네임드방/보스방 모듈을 절차적으로 랜덤 조합한다.

- 단계가 높아질수록 맵 크기, 몬스터 밀도, 네임드 수, 함정 밀도, 복합 몬스터 조합이 증가한다. 보스방은 시작점에서 충분히 멀게 배치해 탐색 시간이 생기게 한다.

- 같은 랭킹 단계의 맵 총량 편차는 과도하지 않게 제한해 기록 경쟁의 운 요소를 줄인다.

- 난이도 상승에 따라 경험치, 전리품 양, 고등급 아이템 기대값도 상승한다.

## 4. 조작 및 전투

- WASD 이동을 폐기한다. 기본은 마우스 클릭 이동 + 적 클릭 시 추적/공격.

- Shift를 누른 상태에서는 이동하지 않고 현재 위치에서 커서 방향으로 공격한다. 타겟 자동 추적을 끄고 방향을 고정한다.

- 권장 키 구조: 좌클릭 이동/기본공격, 1~4 주요 스킬, Q 방어기, E 이동기, R 궁극기, Shift 제자리 공격, Space 회피.

- 근접 빌드는 기본 피해 감소 보정을 가진다. 시작 기준: 순수 근접 -25%, 혼합 -10~15%, 순수 원거리 0%. 현재 장비/빌드에 따라 판정해 원거리 악용을 막는다.

## 5. 타격감·VFX·SFX

현재의 단순 원/구형 이펙트를 전면 교체한다. 목표는 빠른 대형 검격의 화면 절단감 + 강한 히트스톱/적중음/화면반응 + 과장된 피와 육편이다. 특정 게임의 실제 자산은 사용하지 않고 타격감 구성 원리만 참고한다.

| **계열** | **형태 언어**                                 |
|----------|-----------------------------------------------|
| 검/대검  | 길고 날카로운 초승달 검격, 방향성 혈흔        |
| 단검     | 얇고 빠른 다중 잔상, 짧은 피 분출             |
| 도끼     | 두껍고 짧은 궤적, 큰 핏덩이/절단감            |
| 망치     | 저역 충격, 바닥 균열, 돌조각, 먼지, 강한 넉백 |
| 화염     | 불꽃 꼬리, 불티, 연기, 그을음                 |
| 냉기     | 얼음 파편, 서리 결정, 파쇄                    |
| 번개     | 불규칙하게 가지치는 전류                      |
| 혈마법   | 액체형 피, 혈창, 핏방울                       |
| 뼈/사령  | 실제 뼈·갈비뼈·해골 실루엣                    |
| 독       | 점성 액체, 기포, 독안개                       |
| 그림자   | 찢어진 검은 잔상                              |
| 공간     | 균열, 주변 파티클/피를 끌어당기는 왜곡        |

- 타격 한 번은 휘두름 + 육체 충격 + 저음 임팩트 + 피/살점 + 몬스터 신음 레이어를 조합한다.

- Normal \< Heavy \< Critical \< Execution/Ultimate 순으로 히트스톱, 플래시, 화면 흔들림, 혈흔 규모를 상승시킨다.

- 몬스터 음성은 종족별 Idle/발견/공격/피격/사망/특수기 풀을 두고 랜덤 변형한다. 라이선스가 명확한 공유/CC0 소스를 우선 사용한다.

## 6. 스킬 체계와 UI

24개 특화 각각에 전용 생존/방어 액티브 1개를 추가해 기존 특화당 6개에서 7개로 확장한다. 총 액티브 목표는 168개. 방어기는 단순 방어력 증가 복제가 아니라 특화 정체성과 연결한다.

| **예시 특화** | **생존 메커니즘 예시**                     |
|---------------|--------------------------------------------|
| 거병          | 무기를 세워 큰 피해 감소 + 밀림 저항       |
| 광전          | 일정 시간 HP가 1 아래로 내려가지 않는 불사 |
| 성광          | 회복 + 오버힐 보호막                       |
| 심판          | 짧은 완전 무적                             |
| 해골군단      | 소환수가 피해를 대신 받음                  |
| 좀비감염      | 주변 좀비/시체를 소비해 회복               |
| 혼령          | 영혼을 소비해 공격 횟수 무효화             |
| 냉기          | 얼음갑옷                                   |
| 공간왜곡      | 짧은 완전 회피/무적                        |
| 암살          | 은신으로 타겟팅 해제                       |
| 쌍수곡예      | 정확한 회피 후 무적/반격                   |

- 모든 스킬은 이름만 존재하면 미완성으로 취급한다. 필수: 설명, 역할, 실제 수치, 자원, 쿨타임, 태그, 연계, 동작, VFX/SFX.

- 툴팁에는 공격/방어/이동/소환/궁극 역할, 실제 피해량/범위/쿨타임/상태효과/태그와 현재 장비 적용 수치를 표시한다.

- 스킬 설명과 실제 계산은 동일 DB를 참조한다.

## 7. 아이템·인벤토리·드랍 연출

- 인벤토리 필터: 전체 / 무기 / 보조 / 투구 / 갑옷 / 장갑 / 바지 / 신발 / 목걸이 / 반지. 장비 슬롯 클릭 시 해당 슬롯 아이템만 자동 필터.

- 아이템 카드: 등급 프레임, 옵션 아이콘, 빌드 태그, 현재 장비 대비 ▲/▼, 잠금/즐겨찾기/판매 표시.

- 전설: 고정 Legendary Power + 랜덤 수치 범위. 세트/유니크/부모급은 고유 메커니즘 영역을 별도로 강조.

- 전설 이상은 바닥 드랍 시 매우 긴 수직 오라/빛기둥을 아이템 획득 전까지 유지하고 화면 밖이면 가장자리/미니맵 알림.

| **등급**  | **드랍 사운드/연출 방향**                                                                            |
|-----------|------------------------------------------------------------------------------------------------------|
| 전설      | 강한 '띵—! 띠리링!!' 계열 + 긴 빛기둥                                                                |
| 세트 전설 | 연속 차임 + 문양/입자                                                                                |
| 유니크    | 저음 충격 → 상승 차임 → 짧은 팡파르                                                                  |
| 부모급    | 전투음 덕킹/순간 감쇠 → 초대형 시그니처 차임/팡파르 + 암전/진동/초대형 기둥 + '부모가 나타났습니다.' |

## 8. 전설 이후 장비 가공: 각인 촉매

일반적인 보석 소켓 복제 대신 '각인 촉매' 시스템을 사용한다. 장비 구조는 기본 능력치 → 랜덤 옵션 → 고유/전설 효과 → 각인 촉매로 분리한다. 장비에 1~3개의 각인 슬롯을 둘 수 있으며 같은 촉매라도 장착 부위에 따라 효과가 달라질 수 있다.

| **촉매 예시**  | **핵심 효과**                             |
|----------------|-------------------------------------------|
| 이프리트의 돌  | 화염 속성 부여 + 화염 피해/화상 계열 강화 |
| 운디네의 돌    | 냉기 속성 부여 + 냉기/빙결 강화           |
| 뇌신의 파편    | 번개 부여 + 감전/연쇄 강화                |
| 신성한 성서    | 신성 피해 + 회복/보호막 강화              |
| 피의 갈망 수정 | 출혈/혈액 피해 + 회복 연계                |
| 심연의 눈물    | 암흑/그림자/저주 강화                     |
| 민첩의 룬      | 민첩 계열 능력치                          |
| 힘의 각인      | 힘 계열 능력치                            |
| 지능의 눈      | 지능 계열 능력치                          |

마을에는 별도 가공 NPC '새기는고아'를 두어 각인 장착/교체/강화를 담당하게 할 수 있다.

## 9. 시체 시스템

- 몬스터 사망 후 시체를 즉시 삭제하지 않는다. 다음 던전 진입 시 전체 초기화.

- 시체는 AI/복잡한 충돌을 제거한 경량 오브젝트로 관리: corpseId, monsterType, position, usable, age 등.

- 부활, 시체폭발, 좀비감염, 시체먹기, 혼령추출, 보스 패턴이 실제 시체를 참조할 수 있게 한다.

- 과도하게 누적되면 오래된 비필수 시체를 핏자국/잔해로 단순화하되 스킬 사용 가능한 시체는 우선 유지.

## 10. 클리어 상인과 물약

보스 클리어 후 '장사하는고아'가 등장해 던전 파밍 정리와 골드 소비를 한 자리에서 처리한다.

- 아이템 판매.

- 슬롯 지정 랜덤 장비 뽑기. 희귀 이상 중심, 전설/유니크 낮은 확률. 부모급은 일반 가챠에서 제외하거나 극도로 제한.

- 물약 영구 업그레이드.

| **물약 단계** | **회복량**                  | **쿨타임** |
|---------------|-----------------------------|------------|
| 1             | 최대 HP 25%                 | 10초       |
| 2             | 28%                         | 9초        |
| 3             | 32%                         | 8초        |
| 4             | 36%                         | 7초        |
| 5             | 40%                         | 6초        |
| MAX           | 45% + 필요 시 소량 지속회복 | 5초        |

물약 보유 개수는 완전히 제거한다. 무한 사용 가능하되 쿨타임으로만 제한하며 5초 아래로는 내려가지 않게 한다.

## 11. 난이도·드랍·네임드 증가

- 스테이지/심연 단계가 높을수록 경험치와 전리품 기대값을 증가시킨다.

- 전설 → 세트 전설 → 유니크 → 부모급으로 희귀도가 급격히 상승한다. Diablo IV의 현재/시즌별 정확한 숫자를 복제하지 말고, 구현 시 최신 공개 자료를 조사해 '체감 희귀도'만 참고하여 GOABLO 자체 확률표를 만든다.

- 부모급은 일반 몬스터에서도 이론상 가능하지만 극악 확률. 고단 네임드/보스에서 확률을 소폭 높여 사냥 의미를 유지한다.

- 고단 보상 증가는 부모급 확률만 올리지 말고 전설 개수, 유니크 기대값, 고옵션 롤 확률 등 여러 축으로 분산한다.

## 14. 스프라이트 제작 큐 규칙

Work에서 한 번에 전부 생성하려 하지 말고 Act 단위 큐를 유지한다. 첫 몬스터를 스타일 마스터로 확정한 뒤 같은 카메라 각도·광원·비율·바닥 앵커를 유지한다.

권장 순서: 플레이어 기본형 → Act 1 일반몹 → Act 1 네임드 변형 파츠 → Act 1 보스 → Act 1 장비/환경 → Act 2 … → Act 5 → 최종보스. 각 몬스터는 생존 애니메이션과 시체까지 완료해야 완료 처리한다.

## 15. 완료 기준

- 기능이 화면에 존재하는 것만으로 완료 처리하지 않는다. 스킬은 설명/실제동작/VFX/SFX까지, 아이템은 카드/드랍/효과까지 연결되어야 한다.

- 몬스터는 Act 테마, 전투 행동, 네임드 변형, 사망/시체가 연결되어야 한다.

- 보스는 일반몹 확대판이 아니라 고유 실루엣과 전용 패턴을 가져야 한다.

- 던전은 매 판 구조/몬스터/함정 배치가 달라지되 단계별 난이도와 랭킹 공정성이 유지되어야 한다.

## 16. 방어도·속성 저항·내성·면역 시스템

플레이어와 모든 몬스터의 공격 및 방어 판정을 단순 방어력 수치 하나로 처리하지 않는다. 모든 공격에는 공격 속성 및 상태이상 태그를 부여하고, 공격 대상의 방어도·속성 저항·상태이상 내성·면역 여부를 순차적으로 판정한다. 이 시스템은 플레이어와 몬스터 모두 동일한 규칙을 사용한다.

### 기본 방어 구조

피해 계산은 다음 계층을 기본으로 한다.

기본 피해 → 공격자의 속성 강화 → 방어도 판정 → 해당 속성 저항 → 기타 피해 감소 → 최종 피해

- **방어도(Armor)**: 물리 계열 피해를 주로 감소시킨다.

- **속성 저항(Resistance)**: 화염, 냉기, 번개, 독, 신성, 암흑, 혈액 등 해당 속성 피해를 감소시킨다.

- **속성 강화(Element Power)**: 공격자가 사용하는 특정 속성의 피해를 증가시킨다.

- **속성 관통(Penetration)**: 대상의 해당 속성 저항 일부를 무시한다.

- **상태이상 내성(Status Resistance)**: 출혈, 화상, 빙결, 중독, 기절 등 상태이상의 적용 확률 또는 지속시간을 감소시킨다.

- **면역(Immunity)**: 특정 피해 속성 또는 상태이상을 완전히 무효화한다.

### 공격 속성

모든 플레이어 및 몬스터 공격에는 하나 이상의 Damage Tag를 부여할 수 있다.

PHYSICAL / FIRE / COLD / LIGHTNING / POISON / HOLY / DARK / BLOOD

복합 속성 공격도 허용한다. 예를 들어 화염이 부여된 대검 공격은 PHYSICAL + FIRE, 피의 갈망 수정을 사용한 공격은 PHYSICAL + BLOOD처럼 구성할 수 있다.

공격자의 장비, 스킬, 특화, 각인 촉매에 따라 속성이 추가되거나 기존 속성이 변환될 수 있다.

예:

- 이프리트의 돌 → 공격에 FIRE 속성 추가 및 화염 강화

- 운디네의 돌 → COLD 속성 추가 및 냉기 강화

- 신성한 성서 → HOLY 계열 강화

- 피의 갈망 수정 → BLOOD/출혈 계열 강화

- 심연의 눈물 → DARK 계열 강화

### 속성 강화와 저항

공격자에게는 속성별 강화 수치를, 방어자에게는 속성별 저항 수치를 별도로 가진다.

예:

화염 강화 +35%  
냉기 강화 +20%  
화염 저항 40%  
독 저항 65%

따라서 같은 스킬이라도 어떤 적을 상대하느냐에 따라 효율이 달라져야 한다.

예를 들어 화염 공격력이 매우 높은 빌드라도 화염 저항이 높은 악마에게는 효율이 떨어지고, 냉기나 신성 등 다른 속성 빌드가 더 유리할 수 있다.

단, 일반 몬스터에게 지나치게 높은 저항을 부여해 특정 빌드가 진행 자체를 못 하는 상황은 피한다.

### 약점(Weakness)

몬스터는 특정 속성에 약점을 가질 수 있다.

예:

화염 약점 +25%  
신성 약점 +40%

약점 속성으로 공격하면 일반 공격보다 높은 피해를 줄 수 있으며, 피격 VFX와 피해 숫자에도 약점 공격임을 알 수 있는 별도 피드백을 제공한다.

이를 통해 던전 및 Act별로 유리한 속성이 달라질 수 있게 한다.

### 상태이상 내성

피해 저항과 상태이상 내성은 별개로 관리한다.

상태이상 예:

BLEED / BURN / POISON / CHILL / FREEZE / SHOCK / STUN / SLOW / FEAR / CHARM / CURSE / KNOCKBACK

예를 들어 보스가 냉기 피해 자체에는 약하더라도 FREEZE 내성이 매우 높아 완전히 얼리는 것은 어려울 수 있다.

엘리트와 보스는 일반 몬스터보다 상태이상 내성이 높게 설정한다.

보스에게 상태이상이 무조건 실패하는 구조보다는 상태이상 누적치를 사용하는 것도 허용한다.

예:

빙결 축적 37 / 100

냉기 공격을 계속 적중시키면 축적치가 증가하고 100에 도달했을 때 보스가 짧게 빙결된다. 이후 일정 시간 동안 해당 상태이상에 대한 내성이 상승하여 연속적인 무한 CC를 방지한다.

### 면역(Immunity)

특정 몬스터, 네임드, 보스는 일부 속성 또는 상태이상에 완전 면역을 가질 수 있다.

예:

화염 면역  
독 면역  
출혈 면역  
빙결 면역  
매혹 면역

하지만 일반 진행에서 완전한 속성 피해 면역은 제한적으로 사용한다. 특정 속성 빌드 하나만 사용하는 플레이어가 아무 피해도 줄 수 없는 상황이 지나치게 자주 발생하면 안 된다.

완전 면역은 주로 다음 경우에 사용한다.

- 몬스터의 생물학적/세계관적 특성이 명확한 경우

- 특수 네임드 Affix

- 특정 보스 페이즈

- 환경 오브젝트

- 고난도 고아심연 변형 규칙

상태이상 면역은 피해 면역보다 적극적으로 사용할 수 있다.

### 단계별 면역 등장 규칙

완전 면역(Immunity)은 초중반 진행에서 사용하지 않는다.

- **1~24단계:** 완전 속성 면역 몬스터 출현 금지

- 이 구간에서는 속성 저항, 상태이상 내성, 피해 감소만 사용한다.

- 특정 속성에 매우 강한 몬스터라도 최소한 피해는 들어가야 한다.

- 예: 화염 저항 70%, 빙결 내성 80%는 가능하지만 화염 면역은 불가능하다.

**25단계부터** 네임드, 엘리트, 특수 몬스터를 중심으로 완전 면역 Affix가 등장할 수 있다.

초기에는 하나의 면역만 허용한다.

예:

화염 면역  
독 면역  
빙결 면역

단계가 더욱 높아질수록 복수의 내성 및 일부 면역이 결합될 수 있지만, 한 몬스터가 지나치게 많은 피해 속성에 동시에 면역이 되는 것은 제한한다.

특히 다음 조합은 생성하지 않는다.

- 모든 주요 공격 속성 동시 면역

- 해당 클래스가 사실상 공격할 방법이 없어지는 조합

- 서로 모순되는 약점 + 동일 속성 면역 조합

완전 피해 면역보다 **상태이상 면역은 조금 더 적극적으로 사용**할 수 있다.

예를 들어 25단계 이전에도 보스가 매혹 면역, 즉사 면역, 강제이동 면역 등을 가질 수 있다. 다만 일반적인 공격 속성 피해의 완전 면역은 25단계 이후부터만 허용한다.

### 25단계 이후 난이도 상승

25단계 이후부터는 네임드 시스템에 다음 요소를 단계적으로 추가한다.

고속성 저항 → 상태이상 면역 → 단일 속성 면역 → 복수 Affix 조합

이를 통해 25단계가 단순 수치 상승이 아니라 **본격적인 고난도 빌드 대응 구간**의 시작점이 되도록 한다.

플레이어는 이 시점부터 속성 관통, 저항 감소, 보조 속성 공격, 장비 교체, 각인 촉매 등을 활용해 면역 및 고저항 몬스터에 대응하도록 설계한다.

### 네임드 적 속성 Affix

기존 네임드 시스템에 저항/약점/면역 Affix를 추가한다.

예:

**「불길 속에서 태어난 모르칸고아」**

화염 강화 / 화염 저항 / 화상 면역

**「얼어붙은 브라굴고아」**

냉기 강화 / 냉기 저항 / 빙결 면역

**「피를 마시는 발테르고아」**

혈액 강화 / 출혈 저항 / 흡혈

고아심연의 단계가 높아질수록 여러 Affix가 결합된 네임드의 출현 확률을 높인다.

단, 서로 모순되는 Affix 조합은 생성하지 않는다.

### 플레이어 방어

플레이어 역시 몬스터와 동일한 방어 시스템을 사용한다.

장비와 각인 촉매를 통해:

방어도 / 화염 저항 / 냉기 저항 / 번개 저항 / 독 저항 / 신성 저항 / 암흑 저항 / 혈액 저항 / 상태이상 내성

등을 확보할 수 있다.

근접 캐릭터의 기본 받는 피해 감소 보정은 이 시스템과 별도 계층으로 유지한다.

따라서 힘쎈고아가 기본 근접 피해 감소를 가지고 있더라도 화염 저항이 낮으면 강력한 화염 공격에는 큰 피해를 받을 수 있다.

### UI 표시

캐릭터 상세 UI에 최소한 다음 정보를 표시한다.

방어도  
물리 피해 감소  
화염 / 냉기 / 번개 / 독 / 신성 / 암흑 / 혈액 저항  
각 속성 강화  
각 속성 관통  
주요 상태이상 내성

몬스터 역시 타겟 정보 또는 체력바 주변 아이콘으로 중요한 정보를 확인할 수 있게 한다.

예:

🔥 화염 저항  
❄ 냉기 약점  
☠ 독 면역

플레이어가 실제로 공격했을 때도 저항, 약점, 면역 여부가 피해 숫자 및 간단한 텍스트/VFX로 즉시 구분되어야 한다.

### 데이터 구조

공격과 방어 데이터는 하드코딩하지 않고 DB화한다.

공격 데이터 예:

damageTypes\[\]  
physicalDamage  
elementDamage  
elementPower  
penetration  
statusEffects\[\]  
statusBuildUp  
armorBreak  
resistanceReduction

방어 데이터 예:

armor  
damageReduction  
elementResistances{}  
statusResistances{}  
immunities\[\]  
weaknesses{}  
temporaryResistanceModifiers\[\]

스킬, 장비, 전설 효과, 각인 촉매, 몬스터 Affix가 모두 이 공통 시스템을 수정하도록 설계한다.

### 핵심 설계 원칙

속성 시스템의 목적은 플레이어에게 특정 빌드를 강제로 버리게 하는 것이 아니라, **장비 세팅과 적에 따라 전투 효율이 달라지는 빌드 다양성**을 만드는 것이다.

따라서 고아심연 고단에서는 방어도만 올리는 것으로 생존할 수 없고, 등장하는 몬스터와 보스에 맞춰 저항·내성·방어기·각인 촉매를 조합할 필요가 있도록 설계한다.

반대로 공격 측에서는 단순 공격력 증가 외에도 속성 강화 / 관통 / 저항 감소 / 상태이상 축적 / 방어도 파괴가 각각 독립적인 빌드 선택지가 되도록 한다.

## 17. 적 이름·체력바·전투 정보 UI

플레이어가 공격하거나 타겟팅한 적의 정보를 즉시 확인할 수 있도록 모든 적에게 이름과 체력바 UI를 추가한다.

### 기본 표시 방식

일반 몬스터는 기본적으로 머리 위에 다음 정보를 표시한다.

몬스터 이름  
현재 HP / 최대 HP 또는 체력 게이지

예:

좀비고아  
████████░░

플레이어가 해당 적을 공격하거나 마우스를 올렸을 때 체력바와 이름을 강조 표시한다.

### 표시 조건

다음 상황에서는 적의 체력바와 이름이 반드시 보여야 한다.

- 플레이어가 적을 공격했을 때

- 적이 플레이어를 공격했을 때

- 마우스 커서가 적 위에 올라갔을 때

- 스킬의 타겟으로 지정되었을 때

- 일정 거리 이내에서 전투 상태에 진입했을 때

전투가 끝난 뒤 일정 시간이 지나면 일반 몬스터의 체력바는 다시 간소화하거나 숨길 수 있다.

### 네임드 및 엘리트

네임드와 엘리트는 일반 적보다 더 강하게 표시한다.

예:

**시체를 핥는 모르칸고아**  
흡혈 / 신속 / 독 저항

체력바 아래 또는 이름 주변에 주요 Affix 아이콘을 표시한다.

네임드 적은 일반 몬스터보다 체력바 크기와 프레임을 크게 하고, 등급을 쉽게 구분할 수 있도록 별도 장식 프레임을 사용한다.

### 보스

보스는 머리 위 체력바뿐 아니라 화면 상단에 대형 보스 체력바를 추가한다.

표시 정보:

보스 이름  
현재 페이즈  
현재 HP  
주요 상태이상 / 저항 / 면역

예:

**고아들의왕**  
Phase 3 — 왕의 변이  
HP 63%

다단계 보스는 페이즈 전환 시 체력바 연출도 함께 변경한다.

### 타겟 강조

현재 플레이어가 공격 중인 적은 다음 방법으로 구분한다.

- 이름 밝기 증가

- 체력바 강조

- 발밑에 얇은 타겟 링 또는 그림자 강조

- 원거리 타겟은 작은 조준 표시 추가 가능

단, 기존의 단순한 큰 원형 이펙트처럼 보이지 않도록 타겟 UI는 얇고 최소한으로 사용한다.

### 피해 피드백

적에게 공격이 적중하면 체력바가 즉시 감소해야 하며, 피해 종류에 따라 추가 정보를 표시할 수 있다.

예:

1,248  
CRITICAL 3,821  
약점 2,114  
저항 684  
면역

출혈, 중독, 화상 등 지속 피해는 일반 직접 공격과 시각적으로 구분한다.

### 체력바 상태 표현

체력바는 현재 상태를 간단하게 표현할 수 있다.

- 보호막 존재 시 추가 게이지

- 불사 상태

- 무적 상태

- 방어도 파괴

- 상태이상 누적

- 보스 그로기/스태거 게이지

특히 보스는 HP와 별도로 Stagger 또는 상태이상 축적 게이지를 표시할 수 있게 한다.

### 가독성 원칙

화면에 몬스터가 많을 때 모든 체력바가 겹쳐 전투를 방해하지 않도록 거리와 중요도에 따라 표시 우선순위를 둔다.

우선순위:

보스 \> 네임드 \> 엘리트 \> 현재 공격 대상 \> 일반 몬스터

일반 몬스터가 대량으로 몰릴 경우 이름은 숨기고 체력 게이지만 간소화할 수 있지만, 현재 타겟의 이름과 체력은 항상 표시해야 한다.

### 데이터 연동

체력바와 이름은 몬스터 DB를 직접 참조한다.

필수 데이터:

monsterId  
displayName  
monsterRank  
currentHp  
maxHp  
affixes\[\]  
resistances\[\]  
immunities\[\]  
statusEffects\[\]

네임드의 경우 랜덤 생성된 이름과 Affix 정보를 생성 시점에 UI 데이터에도 전달한다.

### 핵심 목표

플레이어가 전투 중 언제든지 **“지금 어떤 적을 때리고 있는지, 얼마나 남았는지, 왜 피해가 적게 들어가는지”**를 즉시 파악할 수 있어야 한다.
