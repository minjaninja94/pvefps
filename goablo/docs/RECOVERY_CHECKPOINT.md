## 앞으로의 저장 규칙 — 사용자 요청

- 의미 있는 기능 하나를 마칠 때마다 작은 커밋으로 GitHub 작업 브랜치에 저장합니다.
- 파일 한 줄을 바꿀 때마다가 아니라 검토 가능한 기능 단위로 묶어 호출 비용을 줄입니다.
- 매 체크포인트에 변경 요약, 검증 결과, 다음 할 일만 짧게 갱신합니다.
- 사용자에게 원격 저장을 확인한 커밋 해시와 링크를 알려줍니다.
- 저장 실패 시 즉시 실패 이유와 마지막 원격 저장 지점을 알립니다. 로컬 상태에만 의존해 계속 누적하지 않습니다.
- 재개 시 기록과 최근 diff부터 읽고 전체 기획서·전체 저장소 재분석은 필요한 경우에만 합니다.
