# GOABLO 환경·전투 시각 자산 묶음

## 공통 규격

- 독자적인 2.5D 쿼터뷰 다크 판타지 팝업북 화풍.
- 투명 팔레트 PNG, 셀 사이 겹침 없음, 작은 화면에서도 실루엣 우선.
- 특정 상용 게임의 고유 자산이나 디자인은 복제하지 않는다.
- 런타임은 아틀라스 셀을 분리해 사용하며 로드 실패 시 기존 도형 VFX로 폴백한다.

## 생성 파일

- `environment-atlas.png`: 8열×5행. Act 1~5별 바닥 2종, 벽, 관문, 랜드마크, 잔해, 함정, 보상 제단.
- `enemy-vfx-atlas.png`: 8열×4행. 일반 원거리 공격, 속성 공격, 보스 공격, 피격 효과 32종.
- `friendly-vfx-atlas.png`: 8열×4행. 무기·마법·신성·소환 공격과 피격 효과 32종.
- `summons-atlas.png`: 8열×8행. 해골 전사·궁수·술사·기사, 사냥고아 2종, 그림자, 감염 좀비. 열 순서는 Idle A/B, Walk, Attack A/B, Hit, Death, Corpse.

## 런타임 연결

- 분기형 던전의 모든 방은 현재 Act 행에서 바닥과 벽/관문을 사용한다.
- 함정방·보상방·네임드방·보스방은 각각 전용 셀을 배치한다.
- 적 행동과 보스 종류, 플레이어 스킬 태그와 무기 ID가 투사체 셀을 선택한다.
- 투사체 충돌 시 같은 계열의 피격 셀을 짧게 재생한다.
- 소환수는 이동·공격 상태에 따라 기존 공통 8열 애니메이션 규칙을 사용한다.
