# B04~B12 보스 스프라이트 생성 규칙

## 공통 규격

- 우선 입력: `GOABLO_WORK_REQUIREMENTS_V0.2.md` → `GOABLO_SPRITE_MASTER(1).md` → `GOABLO_sprite_queue(1).json`.
- 보스마다 투명 PNG 단일 행 × 8열 한 장을 생성한다.
- 열 순서는 `idle A / idle B / move / attack / special / hit / death / corpse`다.
- 같은 보스의 시점·크기·광원·발밑 기준을 통일하고 프레임 사이 침범을 금지한다.
- 배경, 글자, 격자, UI, 별도 머리, 잘린 신체 조각, 다른 몬스터를 금지한다.
- 일반 몬스터 확대가 아닌 고유 실루엣과 전용 공격 읽기를 우선한다.

## 프레임 지침

- 0~2열은 실루엣과 이동 방식을 명확히 구분한다.
- 3열은 기본 공격, 4열은 표의 대표 특수기를 가장 크게 표현한다.
- 5열은 피격 방향을 명확히 하고 공격 프레임과 겹치지 않는다.
- 6열은 완전히 쓰러지는 중간 상태, 7열은 바닥에 남는 온전한 시체다.
- B12의 1·2·4열에는 후광, 흉부 핵, 융합 기관의 단계적 활성화를 넣어 다단계 전투가 읽히게 한다.

## 완료 조건

- 각 PNG를 매니페스트와 보스 프로필에 등록한다.
- 해당 queue 항목을 `integrated`로 바꾸고 source·atlas·row를 기록한다.
- Act 보스층에서 이름·크기·전용 행동·death·corpse가 함께 적용되어야 한다.
- 보스별 최소 정적 테스트와 빌드 후 커밋하고 원격 `main` 반영을 확인한다.
