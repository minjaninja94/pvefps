03 / FAQ

다운로드 전 알아두세요.

스팀이 꼭 필요한가요?

아니요. 이 PC 프리뷰는 Steam을 설치하지 않아도 실행됩니다.

포트 개방이나 IP 입력이 필요한가요?

온라인 릴레이 모드는 IP 입력과 포트포워딩이 필요하지 않도록 구현했습니다. LAN 직접 연결은 별도 방식이며 IP 입력이 필요합니다.

웹 버전과 같은 게임인가요?

현재는 Godot로 새로 이식 중인 초기 버전입니다. 원본 80종 유닛 도트와 10종족 배너는 반영했지만, 전투 특성·밸런스와 전체 멀티플레이 모드는 완전 이식 전입니다.

온라인 대전이 항상 가능한가요?

아직 보장되지 않습니다. 외부 무료 베타 릴레이에 의존하며 서로 다른 네트워크의 실제 유저 접속은 추가 검증이 필요합니다.

Windows에서 경고가 나오는데요?

초기 빌드는 코드 서명이 없는 실행 파일입니다. 파일 제공처가 공식 GitHub 저장소인지 확인하고 실행 여부를 결정하세요.

오류나 개선 사항을 제보하려면?

GitHub Issues에 증상과 스크린샷을 남겨주시면 됩니다.
