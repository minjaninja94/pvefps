# simsimrpg — 7차 전직 장기 성장곡선 및 심화 직업 설계

> 기획일: 2026-11-03 KST · **3차 전직이 끝이 아닌, 7차까지 이어지는 장기 육성 체계**  
> 상태: 기획/초기 수치 제안, **게임/시뮬레이션 미구현**. 기존 [GROWTH_REWARDS_AND_GATE_EVENTS.md](./GROWTH_REWARDS_AND_GATE_EVENTS.md)의 1~3차/7일-3.5일 성장목표는 유지하고, 4~7차를 확장한다.  
> 참고 관점: 옛날 메이플의 단계별 전직이 주는 성취감 + 현대 MMORPG의 초중반 가속과 후반 장기 숙련. 메이플의 절대 레벨/실제 유저 육성 시간/명칭을 그대로 복제하지 않는다.

## 0. 이번 추가 의사결정 요약

- **추천 방향**: 1~3차 전직까지의 빠른 성장을 유지. 3차부터 성장이 끝나는 것이 아니라 4/5/6/7차로 천천히 장기간 올라가게 만든다.
- **확정 요구 취지**: 전직마다 직업의 테크가 올라가는 '메이플 감성', 기존 32진영×6기초 클래스와 깊은 분기 직업 생태계 유지, 기본 온라인 보상은 오프라인의 ×2.
- **시험 목표(확정 수치 아님)**: 7차 전직까지 오프라인 기준 약 360일, 24시간 온라인을 유지하는 경우 약 180일의 누적 기준 사냥 시간. 도중에 실제 이벤트·채널 시너지·보스·고난도 게이트 추가 보상으로 더 짧아질 수 있음.
- **기본 계보 고정**: 생성 시 진영·기초 직업(루트)·기본 외형은 변경 불가, 선택한 전직 분기 되돌리기/옆 계보 이동 금지. 부캐는 Lv.1부터 별도 육성.
- **계정당 활성 1캐릭터**만 채널 표시/온라인 또는 오프라인 자동사냥. 공용 게이트 1개/도우미 NPC 3명/채널 시너지, 자동장비교체·자동판매, 수동 1시간 보스 규칙 그대로.
- 7차를 달성해도 게임오버/최종 만렙/승천 후 리셋 없음. 7차 이후 스킬 숙련·장비·영구 골드강화·초월 랭크·희귀 칭호를 계속 키운다.

## 1. 1~7차 단계별 누적 시간 표

| 전직 | 기준 레벨 | 오프라인 기본 ×1 누적 | 온라인 기본 ×2 누적 | 핵심 보상/진화 |
|---|---:|---:|---:|---|
| 캐릭터 생성 | 1 | 0 | 0 | 고정 진영·고정 루트 직업·기본 외형 |
| 1차 | 30 | 2시간 | 1시간 | 상위직 2갈래 최초 선택, 고유 스킬 |
| 2차 | 100 | 24시간 | 12시간 | 심화직 2갈래 선택, 공격 기믹 변화 |
| 3차 | 250 | 7일(168h) | 3.5일(84h) | 극전직 2갈래 선택, 대표 스킬·영구 오라 |
| **4차** | **400** | **21일(504h)** | **10.5일(252h)** | 고유 영역/진형 영향력, 대규모 파동 스킬 |
| **5차** | **600** | **56일(1344h)** | **28일(672h)** | 클래스 핵심 능력 재구성, 전용 시그니처 연출 |
| **6차** | **850** | **140일(3360h)** | **70일(1680h)** | 고위 협동 시너지·거대 정예 제압 기술 |
| **7차** | **1100** | **360일(8640h)** | **180일(4320h)** | 최상위 직업명·희귀 오라·대형 궁극기·전설적 칭호 |

### 시간 이해를 위한 예시

- **하루 8시간 연결 유지 + 16시간 종료 상태**: 하루에 `8×2+16×1=32` 기본 사냥시간 등가량을 누적 → **7차 기준 8640/32 = 270일**.
- **하루 4시간 연결 + 20시간 종료**: 하루 `4×2+20=28` 등가시간 → **7차 기준 약 309일**.
- **24시간 온라인 접속**을 서버가 실제 인정하면 7차 기준 180일, **전혀 접속 없이 자동 방치**는 360일 상당 누적시간(전직 시련 완료 및 새 진영 선택을 제외한 *레벨 자격* 기준).
- 위 시간이 '보스/이벤트/채널 시너지 없이 안전 단계 기준'이라는 점을 유지. 실제 사용자는 공동 이벤트와 높은 안전 단계의 보너스로 더 빨리 도달할 수 있으므로 **정식 시뮬레이션에서는 중앙값/빠른 상위 10%를 모두 확인**.
- 온라인 상태가 끊기면 해당 시각부터 기본 ×1 누적. PC/모바일 절전·배터리 절약으로 연결이 종료되면 온라인 ×2를 무한 유지한다고 약속하지 않는다.
- 7차까지 360일이라는 숫자는 **밸런스 실험 시작점**이지 모든 플레이어에게 강제로 360일을 기다리도록 하는 시간 잠금이 아니다. 더 어려운 웨이브를 공략하면 성장시간 단축 가능.

## 2. 직업 트리 폭증을 막으면서 7차까지 '깊게 선택'하는 방식

기존 [CLASS_CATALOG.md](./CLASS_CATALOG.md)는 **32 진영 × 6 기본 직업군 = 192 루트**, 기초→1차(2갈래)→2차(4갈래)→3차(8갈래) = **총 2,880개 직업 노드 / 1,536개 3차 끝단**을 목표로 하고 있다.

**4차 이후에 매번 두 갈래의 '신규 직업명'을 추가하면 기초 직업당 128개의 7차 말단이 필요하며 전체 24,576개 말단 경로, 48,960개 직업 노드(192×(1+2+4+8+16+32+64+128))가 되어 처음부터 32종 진영을 완성하려는 목표와 충돌할 위험**이 크다.

따라서 **권장 절충 구조**:

```text
진영 / 기초 계보 (총 192개) ← 생성 시 영구 고정
└─ 1차: 2개 서로 다른 상위 직업 중 택1  [정식 직업 분기]
   └─ 2차: 선택 직업 아래 2개 중 택1    [정식 직업 분기]
      └─ 3차: 선택 직업 아래 2개 중 택1 [정식 직업 분기]
         └─ 4차: 해당 직업의 고유 상위 직업으로 진화 [새 이름·기술·연출]
            └─ 5차: 해당 경로의 고유 상위 직업으로 진화 [새 이름·기술·연출]
               └─ 6차: 해당 경로의 고유 상위 직업으로 진화 [새 이름·기술·연출]
                  └─ 7차: 해당 경로의 최상위 직업으로 진화 [새 이름·기술·연출]
```

- **4~7차에도 각 단계마다 2개 이상의 세부 전술/특성 중 1개를 선택하는 직업 내부의 '전문화 분기'**를 제공한다. 예: 4차 보스 제압 vs 광역 범위, 5차 방어/회복 vs 강공, 6차 파티 강화 vs 개인 숙련, 7차 궁극기 지속 vs 순간 폭발. 선택은 캐릭터 직업 경로에 영구 기록한다.
- 이것은 **새 직업명을 무한히 2배씩 만드는 대신** 이미 선택한 고정 3차 직업 계보의 깊이를 전투 메커니즘과 숙련 전문화로 늘리는 방식이다. 즉 4~7차는 **고유 신규 직업명과 고유 기술을 반드시 보유**하지만, 동시 선택 전문화는 별도 스킬/기술 하위 트리로 구성한다.
- 4~7차 고유 직업 노드 수 = **1,536 × 4 = 6,144**, 전체 직업 노드는 **2,880 + 6,144 = 9,024**. 최종 **7차 직업명 계보 1,536개**, 각 진화 단계에서도 2개씩 선택할 경우 *전술 전문화 조합*은 경로당 최대 16가지(1,536×16 = 24,576 특성 빌드), **24,576개 별도의 신규 직업명을 의미하지 않는다**.
- **전문화 선택은 되돌릴 수 없는 선택인지, 재분배 가능한 내부 스킬 특성인지 세부 운영정책 미확정**. 다만 생성 때 선택한 기초 루트와 1~3차 직업 경로는 기존과 같이 영구 고정.
- **7차 고유 직업이 모두 실질적으로 구별되게** 핵심 능력/자동 공격 우선순위/메인 스킬/시각 이펙트/채널 협력 기능 중 최소 하나 이상 진화. 단순 피해량 +X%에 '신직업' 명칭만 변경 금지.
- 실제 모든 단계의 이름·스킬은 아직 작성되지 않았으며, **기존 192 루트/32 진영 전체와 7차까지 포함하는 신규 정식 완성 기준을 문서상 선언한 것**. 개발자가 세부 직업 트리/스프라이트/스킬 데이터를 생성·검증해야 한다.
- 상위 직업 수 부담 때문에 32종 일부 진영만 정식 공개하는 방식을 승인한 것이 아님. 정식 버전 목표는 **32종 진영 전체의 7차까지**.

## 3. 전직마다 반드시 다른 '테크가 오른' 시각/게임 경험

| 단계 | 강화의 성격 | 전투·소셜 효과 설계 예시 |
|---|---|---|
| 1차 | 상위계열 첫 선택 | 단일 공격 → 다단 검기/표식/회복 기술 |
| 2차 | 전문직 정체성 확립 | 광역·관통·도발·중독·상태이상·버프 범위 차별 |
| 3차 | 극전직 고유 스킬 | 화면 내 확실한 광역/방어/분신·분열 연출 |
| 4차 | 영역 장악 | 게이트 전방 압박·진형 유지/광역 제어 능력 |
| 5차 | 클래스 정수 | 고유 스킬의 구조가 달라지고 패시브 연계가 생김 |
| 6차 | 공용 게이트 정예 제압 | 정예 특화·협동 궁극기·직업 고유 전투 패턴 |
| 7차 | 전설적인 존재 | 크지만 시야를 가리지 않는 시그니처 궁극기·오라·칭호·동료 지원 |

- 고레벨 전직 외형은 **기존 생성한 캐릭터의 기본 외형/종족 정체성 유지**. 무기 파츠·갑옷·포즈·방향·빛기둥/잔상/마법진/함성 등으로 발전.
- 초보 Lv.1과 7차 Lv.1100이 같은 화면에 서 있을 수 있으며, 고렙의 실제 전투력/범위/이펙트를 초보 수준으로 평준화하지 않음. 초보는 자기 단계의 적정 EXP/드롭·시너지 1인분 기여 보장.
- 다만 7차가 모든 잡몹을 쓸어버려 초보의 전투 기여를 0으로 만들지 않도록 공용 게이트에 일반/정예/고위 적의 혼합 구성과 개인 보상 인정.
- 도우미 NPC 3명(탱커/힐러/공격)은 채널마다 항상 있지만 유저 시너지 스택에 포함되지 않음.

## 4. 직업별 전직 이벤트 1~7차

- 모든 직업의 전직 이벤트는 **한 화면, 같은 공동 게이트**에서 발생. 별도의 퀘스트 사냥터/인스턴스/던전 화면으로 보내지 않는다.
- 각 단계에서 **'레벨 자격 달성 → 개인 시련 활성 → 시련 수행 → 상위 직업/전문화 선택 → 직업 등급·스킬·시각 이펙트 즉시 변화'**의 전직 루프.
- 1~3차는 이전 [GROWTH_REWARDS_AND_GATE_EVENTS.md](./GROWTH_REWARDS_AND_GATE_EVENTS.md)에 상세 기록한 고유 직업 분기(2→4→8). 4~7차는 신규 직업명/상위 스킬 + 고유 내부 전문화 선택 및 전직 이벤트/시련.
- 예시 시련:
  - 4차: 채널 게이트의 전방을 버티거나 상위 정예 연쇄 처치 (역할별 목표)
  - 5차: 해당 계보 고유 스킬을 특정 전투 상황에서 사용해 효과를 확인하는 숙련 시험
  - 6차: 채널 공동 게이트와 연동된 상위 직업의 연계/대형 전술 미션(힐러는 보호/강화 기여)
  - 7차: 같은 채널의 **전설급 시련 이벤트**(정식 1시간 보스와 별개의 직업 시련 정예) 성공 후 개인에게만 7차 전직/호칭/오라 개방
- 시련 실패/나중에 도전하더라도 **Lv·장비·숙련도·EXP 축적은 계속**. 레벨업이 전직 시험에 의해 강제로 막히는 상황 금지.
- 1시간 수동 공동 보스 **입장 후 60분/처치 후 60분**과 전직 시련은 완전히 별개 서버 타이머. 전직 실패/성공이 보스 쿨타임을 조작하면 안 된다.
- 전직은 자동 장비 비교/판매 흐름을 복잡하게 만들지 않아야 한다. 새 고유 직업이 부위별로 상위 장비를 드롭하면 즉시 착용, 열등 아이템은 즉시 골드로 변환.

## 5. 성장곡선 설계 및 테스트

- 기존 1~3차 기본 시간 체크포인트 `H(30)=2h, H(100)=24h, H(250)=168h`에 4차 `H(400)=504h`, 5차 `H(600)=1344h`, 6차 `H(850)=3360h`, 7차 `H(1100)=8640h`를 추가.
- 단조 보간 `H(L)` 및 현재 `R(L)`를 사용해 **서버 레벨별 요구 EXP**를 계산하되 7차 부근에 성장 벽/인위적 절벽이 없게 보간 연속성/기울기를 확인.
- 온라인 ×2는 **일반 경험치·골드·장비 드롭 롤 횟수·숙련도**에 적용. 이벤트/전직/수동 보스 고정 보상에 중복 ×2 적용하지 않음.
- 실제 게이트 시너지·높은 난이도·수동 보스·랜덤 이벤트 때문에 기본 시간보다 더 빠르게 진행하는 플레이어가 생기므로 **누적시간은 기준 캐릭터/기본 사냥의 비교 척도**.
- 세션이 끝나도 마지막 활성 캐릭터는 서버 오프라인 ×1 정산을 계속함. 다른 부캐는 정지, 여러 탭/기기로 ×2 중복 지급 금지.
