# simsimrpg — 초고레벨과 초보자가 같은 공동 게이트에서 노는 설계

> 2026-11-03 KST · 기획 추가. **요구 취지: 고레벨은 압도적 성장·권위를 즐기고, 저레벨은 소외되지 않으면서 부러움과 성장 목표를 갖게 한다.** 구체 수치는 **밸런스 시험 제안**이며 아직 확정되지 않음.  
> 최신 전투 기준: [공동 게이트·역할 진형·도우미 3명](./FORMATION_AND_GATE.md), [채널 시너지](./SOCIAL_IDLE_SYSTEM.md), [혼합 레벨 HP·보스 안전입장](./MIXED_LEVEL_HP_RAID_BALANCE.md), [300종 이벤트](./GATE_EVENTS_300.md), [메인 기획](./PLAN.md).

## 1. 핵심 디자인

- **하나의 채널, 하나의 실제 물리 게이트, 하나의 공용 몬스터 무리**에서 Lv.1과 Lv.1000+가 함께 싸운다. 별도 초보방, 숨겨진 사냥 인스턴스, 격리된 개인 몬스터 화면 금지.
- 고레벨의 실제 장비·상위전직·스킬·피해량을 **초보자 수준으로 균일하게 낮추지 않는다**. 높은 레벨의 힘을 화면에서 알아볼 수 있어야 한다.
- 고레벨이 순식간에 모든 잡몹을 처치해도 초보의 **기본 EXP/골드/일반 드롭이 0이 되지 않도록** 개인 기여도와 보상 자격을 분리한다. 보상은 개인 레벨·장비·진행 기록·유효 기여에 맞게 결정, 막타 독점 금지.
- 낮은 레벨 유저가 고레벨의 업적/계보/고유 외형/연출을 보고 '나도 오래 키우고 싶다'고 느끼되, 강제로 과금하거나 다른 유저에게 기생할 필요는 없게 한다.
- 32개 진영·192개 초기 직업 계보·다단계 상위전직 전체, 캐릭터 생성 시 진영/초기 계보/기본 외형 고정, 부캐 Lv.1부터 재육성, 계정당 채널 표시+자동사냥 활성 캐릭터 1명, 장비 자동 장착/판매, 서버 오프라인 정산 모두 변경 없음.
- 채널 도우미 **NPC 3명(방패·치유·공격)**은 항상 존재하지만 실제 유저 인원/종족/클래스 중첩 시너지에 포함시키지 않는다.

## 2. 공동 게이트 혼합 웨이브: 약한 적, 강한 적, 정예/보스가 동시에 출현

| 적 종류 | 권장 초점 | 고레벨/저레벨 경험 |
|---|---|---|
| 일반/약체 웨이브 | 저레벨, 도우미 NPC, 광역기 | 저레벨도 공격·처치 기여하며 전투 학습 |
| 강화/중급 웨이브 | 중레벨, 다수의 유저 협공 | 중간 성장단계 유저의 존재감 유지 |
| 정예/고위 위협 | 고레벨 상위전직, 탱커·힐러 | 고레벨이 전선을 구하는 시각적인 순간 |
| 수동 공동 보스 | 전원 협동 | 1시간 룰, 고레벨 큰 화력 + 초보 실질 도움/개인 자격 보상 |

- **게이트는 하나**: 몬스터의 겉모양/티어/위협도만 다를 뿐 실제 출처 및 공간은 동일.
- 역할별 자동 타깃 **우선순위**: 강한 캐릭터는 강화/정예를 먼저 노리고 약한 캐릭터는 일반/자기 적정 위협도를 먼저 공격. 그러나 고레벨의 광역기가 약한 적도 쓸어버리는 연출은 허용.
- 고레벨의 광역기·궁극기를 약하게 만들어 초보와 동등화하지 않는다. 초보에게 보여 줄 '캐리' 순간은 중요.
- 게이트 몬스터 전체 HP를 채널 **최고 레벨 1명** 기준으로 일괄 증폭하지 않는다. **활성 참가자들의 유효 전투력 분포 + 역할 구성 + 채널 웨이브**를 고려해 여러 티어 적을 섞고 무리별 위협도를 정한다.
- **연출/서버 분리**: 렌더링 혼잡을 막는 오브젝트 상한은 전투 보상량을 임의로 잘라 버리지 않도록 별도 계산. 시각적 타격감은 유지하며 수치·정산은 서버 권위.

## 3. 레벨 격차 보상: 막타가 아니라 참여도+본인 성장 기준

- 채널 일반 웨이브의 기본 보상은 **개인별 적정 사냥 단계, 클래스, 온라인 참전/유효 지원**, 공동 웨이브 기여를 기반으로 지급.
- 적정 단계에서 전투 중이었다면 고레벨의 광역기로 몬스터가 즉사했더라도 초보에게 기본 사냥 수익이 사라지지 않도록 **참여 예약/공격 큐 기여 보정** 적용. **시험값**: 타깃 확정 후 ~2초 이내에 처리될 예정이던 유효 자동공격/힐/버프가 막타 이전에 무효화된 경우 해당 처치의 기본 기여 인정. 아무 행동도 하지 않은 캐릭터에 무조건 최고급 보상을 주지는 않는다.
- 딜러의 실제 피해량, 탱커가 실질 방어한 피해, 힐러의 유효 회복량·상태이상 해제·보호막·버프 효과를 별도 점수화해 **의미 있는 행동으로 기여**.
- **원거리/힐러가 약한 적 타깃을 계속 뺏기는 문제**를 막기 위해 최소한의 유효 참여 기회 보장. 강력한 영웅이 뒤에서 약체를 몰살해도 초보가 0 EXP가 되는 구조 금지.
- 고레벨의 일반 저레벨 몹 파밍은 본인 등급의 고급 장비·최고 골드를 무한 공급하지 않음. 고레벨은 고난도 정예·보스와 개인 안정 단계 진행에서 적정 보상, 저레벨은 자기 단계 보상을 받는다.
- **고레벨 버스 악용 방지**: 초보가 상위 보스 옆에서 서 있기만 해도 전설·신화 장비를 획득하지 못함. 개인 레벨·도달 단계·유효 참여 점수 기반 장비 등급 및 보상 상한 적용.
- **체감 보상 사례(수치 시험안)**: 같은 10분 채널 전투라도 Lv.20은 본인 성장곡선 기준의 의미 있는 EXP/장비 교체, Lv.800은 본인 단계에 맞는 고티어 정예/보스 보상, 둘 다 손해 보지 않는 방향. 만약 두 유저의 기본 시간당 경험치가 '같은 숫자'여야 한다는 뜻은 아님.

## 4. 고레벨이 만족하는 연출/명예/영향력

1. **상위 전직 시각적 단계**: 생성 때 고정한 기본 외형은 보존하되 상위 전직 전용 무기 자세, 옷/장갑 파츠, 영구 오라, 공격 모션, 원형 마법진, 용족 진화 외피, 랩터 발톱 궤적, 해병 유니버스 기합 연출 같은 '성장의 흔적'이 추가.
2. **공격의 규모감**: 고레벨은 굵은 광역기/화려한 광선/연쇄 이펙트/정예 처치 연출. 단, 다른 유저 화면을 가리지 않도록 VFX 밀도/투명도 개인 옵션, 저사양 모드.
3. **칭호·업적**: 진영별 전설, 극전직 증표, 누적 처치, 고난도 웨이브, 공동 보스 기록, 장기 육성 시간 표시. 유저 프로필 클릭으로 성장 기록 확인.
4. **진형 존재감**: 초보를 쫓아내지 않고 고레벨이 전열에서 적 대열을 정리하거나 보스의 거대한 공격을 막는 순간이 자연스럽게 나오도록 적 위협도/스킬 타깃 설계.
5. **희귀 장비 획득 소셜 연출**: 개인 빛기둥과 채널 알림은 켜기/끄기 가능. 모두에게 실시간 아이템 수치와 운빨을 강요하는 노출은 피함.
6. **동료 돕기 업적**: 일정 시간 동안 실제 초보 유저와 같은 채널에 있으며 함께 적정 전투를 수행한 경우 '수호자/동행' 등 **사회적 업적과 칭호**. 과도한 재화 파밍 가능한 반복 퀘스트로 만들지 않음.

## 5. 초보의 만족: 정당한 성장, 기여, 관찰

- **레벨이 보이는 비교**: 고레벨의 이름/레벨/전직 단계/칭호/스킬 이펙트는 공개 프로필에서 확인 가능. 초보는 자신의 다음 성장 단계까지 남은 목표를 명확히 알 수 있음.
- **자기 성장의 체감**: Lv.1부터 몬스터 처치·EXP·골드·장비 자동 착용·스킬 자동 습득의 짧은 성취 주기 제공. 고렙이 들어왔다는 이유로 사냥 효율 급락 금지.
- **초보 고유 기여**: 게이트 약체 처치/적정 난이도 적 공격/진형 보호/버프 등 시너지 스택을 **레벨과 무관하게 유저 1명당 1인분** 계산.
- **신규 유저만의 파밍 보너스 남용 금지**: 계정당 활성 1캐릭터이고 부캐는 Lv.1부터 시작하지만 반복 신규 부캐를 만들어 재화/시너지를 반복 수확하는 악용 가능성을 제한.
- **초보 전용 스테이지를 다른 맵에서 돌리지 않음**. 게이트에서 몬스터 종류가 뒤섞이고 자신의 적정 대상/기여로 성장.
- 초보는 '강한 선배 덕분에 공짜로 레벨1000'이 아니라 **함께 싸워도 나의 성장 속도가 유지되고 가끔 도움받는 경험**을 해야 함.

## 6. 1시간 수동 공동 보스와 레벨 차이

- 유저가 채널에 입장한 후 1시간 요건, 수동 소환, 처치한 순간부터 다시 1시간 쿨다운이라는 기존 룰 유지. 같은 하나의 게이트/전장 사용.
- **실제 체력 한 개**의 공동 보스, 실시간 전투력에 따른 체력/패턴 스케일링. 한 명의 Lv.1000 때문에 모든 초보를 즉사시키는 광역 패턴만 쓰게 만들지 않음.
- 보스는 고레벨의 실제 DPS와 상위 스킬에 의미 있는 위협이 되는 단계적 방어/기믹 보유. 여러 명이 모이면 잡는 속도와 희귀 보상 달성률이 개선될 수 있음.
- 딜 기여만 보지 않고 힐·보호막·도발·실제 공격 버프/약화·참전 시간 기반 유효 기여 포함. 단순 대기/가짜 오버힐로 보스 고급 보상 획득 금지.
- **개인 보상은 자신의 진척/참여 자격으로 결정**. 고렙은 현재 단계 희귀 장비/고급 보상, 초보는 자신에게 도움이 되는 장비·EXP·골드/기초 업적. 같은 보스를 잡아도 개인 보상 테이블을 다르게 설계.
- 고레벨이 보스를 단독 순삭해 역할 균형이 완전히 사라지지 않도록 **공동 보스에만** 짧은 페이즈/위협 스킬/피해 처리의 소프트 캡을 검토(실제 성장 체감이 훼손되지 않게 시험). 일반 웨이브에서는 고레벨 광역 원킬의 쾌감 유지.
- 보스 기여가 적은 유저의 기본 소액 참여 보상과 고급 기여 보상을 분리. 초보자 배제, 고레벨 딜 독식, 잠수 유저의 자동 고급 보상 모두 방지.

## 7. 소셜 시너지와 레벨격차 연결

- 기존 **32진영 고유 인원 중첩 + 192기초 클래스 패시브 중첩 + 상위 전직 시너지 + 실제 유저 인원 보너스** 유지. **3명의 도우미 NPC는 시너지/랭킹 인원에 포함하지 않음**.
- 기본 종족·클래스 인원 스택의 가치는 초보/고렙 **1인 = 1인**으로 유지. 고레벨일수록 더 많은 인원 스택을 제공하는 방식은 사용하지 않음.
- 고레벨 전용 효과는 **새 상위 전직의 별도 전문 패시브**를 추가하는 방식으로 보상; 기본 스택만으로 초보를 퇴출시키지 않음.
- 조합 예시: Lv.1000 용족 전열 + Lv.20 조선 궁수 후열 + Lv.80 무당 지원 + 3 NPC. 같은 공간에서 각각 고위 정예 딜/기본 적 처치/힐·버프 담당. 셋 다 인원·종족·클래스 시너지 정상 집계.
- **사회적 동행 보너스**는 소액의 공동 효율/업적 중심, 초보에게도 레벨 차이 없는 '존재 가치'를 제공. 고레벨이 초보를 많이 데려올수록 무제한 골드 생산하는 설계 금지.

## 8. 오프라인·경제

- 계정당 마지막 **활성 캐릭터 1명만** 오프라인 시간 기반 자동 사냥 정산, 나머지 부캐는 완전 정지.
- 오프라인 정산은 본인 **마지막 확정 안정 사냥 단계와 직업/전투력 기준**. 온라인 고렙과 동행 시 증폭된 채널 시너지/보스 고급 보상을 오프라인에도 영구 고정해 복제하지 않음.
- 장비는 드롭 즉시 등급 우선/동급 성능 우선 자동 교체, 기존·열등품 자동 판매/골드화. 슬롯 제한/거래 없음.
- 초보가 고렙과 한 화면에 있기만 해도 중복/부정 보상을 얻는 자동 버스 메타 방지. 참여 인정은 실제 자동 스킬의 서버 실행/지원 기여를 증명.

### 수락 기준

1. Lv.1+Lv.1000 동일 채널 및 같은 화면, **실제 게이트 하나**에서 혼합 티어 몬스터 스폰, 중복 게이트 없음.
2. 고렙 광역기 원킬/막타 독점이 발생해도 참전 중인 저렙이 0 EXP/장비 지속 상태로 방치되지 않음(서버 유효 기여 확인).
3. 고레벨이 실제로 더 높은 DPS·범위기·상위 전직 연출을 보여줌. 단순 강제 레벨 평준화 적용하지 않음.
4. 정예/보스는 고레벨 도전 가치가 있고, 초보/힐러/탱커의 유효 역할은 남음.
5. 봇 3명은 초보를 보호하지만 무제한 보스 캐리/경험치 파밍/시너지 중복을 만들지 않음.
6. 초보의 인원·종족·기초 클래스 시너지 1스택은 고렙 1명과 동일하게 인정.
7. 높은 레벨 유저가 채널을 바꾸거나 로그아웃해도 초보의 서버 안정 단계 수익이 유지됨. 오프라인에서는 활성 1캐릭터만 정산.
8. 공동 보스는 기존 **60분 입장/60분 처치 후 쿨다운**, 수동 소환/개인 별 단계·기여에 따른 보상 유지.
9. 극단 케이스: Lv.1×49명+Lv.1000×1명, Lv.1000×49명+Lv.1×1명, Lv.1 힐러 1명+NPC3명, Lv.1000 솔로+NPC3명을 전부 시뮬레이션.
10. 1계정 1활성/부캐 중복 참여 불가, 대규모 광역기로 몹 즉사해도 보상 원장 중복 지급/누락 없음.

> **미확정 시험값**: 기여 유효 예약 윈도 2초, 각 티어 비율, 공동 보스 소프트 캡, 신규 업적 표시와 추가 사회 보너스, 데미지/체력 수치. 실제 시뮬레이션으로 정한다.
