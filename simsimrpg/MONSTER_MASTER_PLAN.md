## 5. 2만 팔레트 외형을 만드는 법

| 팔레트 ID | 변형 | 시각 목적 |
|---|---|---|
| P01 | 기본 | 원본 캐릭터 실루엣·본연 색 |
| P02 | 창백 | 고대·희귀 정령 느낌 |
| P03 | 서리 | 동색계·청색 재질 |
| P04 | 황토 | 사막·사구·먼지 |
| P05 | 잿빛 | 폐허·석탄·기계 |
| P06 | 홍염 | 붉은 열기·야간경고 |
| P07 | 독녹 | 오염·역병·균사 |
| P08 | 황금 | 드롭 연출·정예 축제 |
| P09 | 흑요 | 흑자색 흑요석 피부 |
| P10 | 심연 | 어두운 남색 빛의 흡수 |

- **10개 팔레트는 10개 독립 공격 패턴이 아니라 외형 변종**. 원본 셰이더/팔레트 테이블을 통해 재생 중에 색상 변경. 오리지널 본체 원화·FX는 원본 1세트만 제작한다.
- 금속/뼈/슬라임/머리카락의 밝기·눈·위험한 장판 경고 색은 **공통 RGBA 틴트가 아닌 재질 마스크/색 테이블**에 따라 변경. 위험 경고/아군·적 구분에 쓰이는 UI 색은 스왑하지 않는다.
- 색 변종은 플레이어가 다른 몬스터라고 속이려는 수법이 아님. 도감에는 **기본 2000종·외형10종의 상하관계**를 표시하고, 변종이 실제 별도 AI를 갖지 않는 점을 분명히 한다.
- 팔레트 파일 20,000개를 굽지 않음. `visual_id = monster_id + "/P" + palette_number` 같은 확장 키로 계산.

## 6. 신규 몬스터 도트 원화 규모(최소 제작 예산)

| 몬스터 등급 | 개체 수 | 몬스터당 독립 바디 프레임 | 합계 |
|---|---:|---:|---:|
| 일반 | 1,400 | 40 | 56,000 |
| 특수(변칙+지휘관 일부) | 300 | 52 | 15,600 |
| 정예 | 200 | 80 | 16,000 |
| 정식 수동 보스 | 100 | 160 | 16,000 |
| **합계** | **2,000** | | **103,600 고유 그림 프레임** |

- 모두 **1개 기준 방향·몬스터 본체** 기준의 예산 추정. 보스/특수몹 전용 FX·투사체, 게임 내 양방향 비대칭 수정·스킨 추가, 도감 초상화·UI, 사망 잔해·이벤트 전용 아트는 **별도**이다.
- 직업 바디 생성규칙(한 방향/기초 138장·7차 신규 스킬별 12/16/20/24/30/36/48장)과 몬스터 전용 등급별 예산은 다르며, 192개 기본 클래스+여러 전직 분기/상위 프레임 총량을 103,600장에 합산한 것이 아니다.
- 고유 그림은 정지 포즈의 복제·색변환·전체 이동만으로 채우지 않음. 실제 공격·접촉·부상·이동·주문/회복·사망/보스 페이즈의 새 그림을 그려야 카운트.
- **현재 원화/프레임 실제 생성 수=0**, 픽셀 시트·애니메이션·실전 몬스터 패턴 코드는 미완료.

## 7. 해병 음식은 적 전체 약화 / 해병만 버프

- 해병짜장·해병수육·짬밥·진떡팔 요리·마철두 짜장탄막의 **음식 속성 디버프**는 **같은 채널에 살아 있는 모든 적**(상기 2000종 중 실제 스폰한 개체 전원, 정식 보스 포함)에게 적용. 보스도 적용 대상이나 지속시간/계수는 저항 및 상한.
- 음식에서 파생된 **아군 버프는 해병 진영(F29)의 활성 참전자에게만**. **그 외 31개 플레이어 진영/신규자/도우미 NPC에게 음식 버프 0**. 다른 진영이 적 약화를 통한 간접 이득을 얻는 것은 가능.
- 몬스터에게 디버프가 걸려 있다고 전원 처치 보상·레벨 무관 보상·막타 보상을 자동 생성하지 않음. 한 채널에 한정하며 모두 서버 원장/합산상한. [MARINE_FOOD_TARGETING_RULES.md](./MARINE_FOOD_TARGETING_RULES.md).

## 8. 한 화면 혼합레벨 게임에서 스폰·보스·드롭 규칙

- **한 개 물리 공동 게이트**에서 저레벨 약체·중간 강화·고위 정예가 역할 기반으로 혼합 스폰. 별도 미니 던전·타워 디펜스·소환덱·맵 분할 금지.
- 단일 몬스터 개체는 서버에 **실제 HP 하나**, 약점·공격력·위험도를 갖는다. 신규 Lv1 입장으로 이미 등장한 고위 정예/정식 보스의 현재 HP가 실시간 재증폭되지 않음.
- 신규자는 보호 후열에서 1시간 보스 전투를 관전하며 본인 선택 시 저급 약체/응급 보조만 참여. 고위 적 AI가 신규 Lv1을 즉시 지정해 한 방에 죽이지 않는다. 고위 정예 디버프·폭격도 신규자 안전 예외 적용.
- 100종 정식 보스 풀은 온라인 채널 **입장 후 60분 수동 소환 자격**과 처치 후 60분 쿨타임에 따라 한 개의 게임 월드에서 1회 출현. 이벤트 정예/특수 지휘관과 시간/보상 원장 완전히 분리.
- 드롭은 개인 기여/적정 단계/희귀도에 따라 서버 자동 판정, 상위 장비 자동착용·열등 장비 자동판매/골드 축적. 특정 계열의 테마 드롭은 **장비 확률과 장비 종류의 기획 태그**지 유저 간 거래 가능 아이템을 뜻하지 않는다.
- 300종 랜덤 이벤트의 적 조합은 2000 몬스터 풀에서 이벤트 테마/전투 역할에 따라 선발하며, E120 **한물간 밈의 습격**은 **별도의 적 전용 이벤트 레코드**로 유지. 밈 플레이어 진영 추가 없음.
- 자동사냥 접속 중 기본 EXP·골드 ×2, 로그아웃 후 활성 1캐릭터 서버 오프라인 자동사냥 ×1, 해병 음식/이벤트는 기본 자동 사냥 배율을 두 번 곱하지 않음.

## 9. 제작/테스트 우선순위

1. **20분류×10계열군×10타입=2000개 ID 검증**. 그룹/모션/반응/약점/보상 프로필 누락·중복 0, 계열군 시그니처 메커니즘/색 변종 10종.
2. **공통 10종 전투 AI 상태기계**와 200가족의 독립 `family_hook` 구현. 모든 가족의 기술 연출이 실제로 반영되는지 테스트; 현재 JSON은 구체 기술의 작동 원리를 설명하지만 **코드는 없음**.
3. 초보~초고렙 섞인 50인 채널 100개 몬스터 역할 혼합전, 프레임/CPU/대역폭·스프라이트 lazy-load 및 힐러/지원/상인 기여 확인.
4. 보스 100개 각각 최소 **2개 이상의 명확히 다른 패턴**, 공용 HP/수동 소환/회복저항/페이즈 전환/초보 안전/보상 기여 전수 검증. 기존 단순 정예와 구분되는 연출을 추가.
5. 1차 아트 제작은 20계열군×10타입 = 200몬스터 디자인을 시각 검증한 뒤, 2000종 전체로 확대. **최종 정식 버전 목표 2000종 유지**, 200종은 품질 점검용 단계이지 영구 축소안이 아님.
6. 10팔레트×2000 몬스터의 실루엣·읽기 쉬운 위험 전조·아군/적 표시·메모리/VRAM·애니메이션 키프레임 검사. 새 프레임 실제 생성/QA/배포 전 ‘2000종 구현’이라고 보고하지 않음.
7. 파일 생성/다음날 작업 시 *기존 Desert Front와 다른 프로젝트 파일 수정 금지*, GitHub `simsimrpg/` 안에서만 작성·커밋.
