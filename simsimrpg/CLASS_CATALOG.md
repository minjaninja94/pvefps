# simsimrpg — 32개 진영 / 전직 계보·클래스 카탈로그

> 2026-11-03 최신 수정. 첫 정식 버전 목표: **32개 진영 모두 + 진영별 6개 기본 직업군 = 192개 진입 계보**, 각 계보 안에서 1~3차 이진 분기, **4~7차 고유 상위 직업과 내부 전문화로 계속 진화하는 트리형 클래스**. 4~7차 추천 구성 및 완만한 성장곡선은 [SEVEN_ADVANCEMENTS.md](./SEVEN_ADVANCEMENTS.md). 현재 기획 단계이며 실제 직업/아트 제작은 시작하지 않음.  
> 2026-11-03 최신 진영 재편: [32진영·해병 인물·경제/예능 직업·7차 스킬 누적](./FACTION_CLASS_REWORK_2026_11_03.md), [기계 판정용 32×6 직업 명단 JSON](./FACTION_ROSTER_32X6.json)이 현재 32×6 이름/특성의 우선 기준. 
> 중요: **생성 시 계보(진영·초기 클래스·기본 외형) 고정**과 **같은 계보 안에서 상위 클래스로 전직·분기 가능**은 동시에 성립한다.

## 1. 직업 시스템 원칙 — 마비노기 숙련 + 메이플식 전직 + 트리 오브 세이비어급 다양성

- **절대 다른 초기 직업군으로 갈아탈 수 없다.** 예: 조선 검객으로 태어났으면 조총수나 용족으로 변경 불가. 다른 계보는 Lv.1 부캐를 생성한다.
- **하지만 상위 전직은 가능하고 반드시 여러 갈래로 깊게 분기한다.** '클래스 고정'이란 첫 직업군 계보 고정을 말한다. 상위 직업명/스킬이 레벨에 따라 진화하는 것은 허용·핵심 콘텐츠.
- 직업 선택 시 처음부터 모든 최종 트리를 미리 보기 가능. 각 상위 전직 시 **최소 2개 서로 다른 전문 경로** 중 영구 선택. 선택하지 않은 상위 직업으로 갈아탈 수 없음. 스킬 레벨·숙련도는 해당 계보에서 유지.
- **마비노기식** 무기 사용·전투 활동에 따른 스킬 숙련도/랭크(예: F→E→…→A→9→…→1)와 **메이플식** 일정 레벨의 1차/2차/3차/4차 전직 및 대표기술의 개화를 참고한 **독창적 시스템**. 실제 게임의 명칭·고유 설정·스킬/에셋 복제 금지.
- 스킬은 자동사냥 AI가 자동 사용한다. 숙련도도 자동사냥으로 오르며, 적극적인 플레이 시 소폭 보너스는 가능하나 필수 조작으로 만들지 않는다.
- 단계마다 스킬과 전투 **성격 자체**가 분리되어야 한다. 공격력 계수만 다른 클래스, 색만 다른 클래스, 이름만 다른 클래스로 양산하지 않는다.
- 새 직업명을 고르는 '전직'은 특정 레벨 이상에서 진행. 캐릭터 계정·레벨·장비·골드는 초기화하지 않는다. 별도의 '부캐 생성'만 Lv.1 시작.
- 32진영 전부 정식 버전 포함. 개발 중 내부 테스트는 단계별로 가능하지만 일부 진영만 포함한 상태를 정식 완성이라고 하지 않는다.

## 2. 계보 깊이(설계 기준)

```text
진영 선택 (32종)
└── 기본 클래스 계보 선택 (진영별 6종, 총 192개) ← 생성 시 영구 고정
    ├── 1차 상위전직 A (Lv.30 목표값)
    │   ├── 2차 심화전직 A1 (Lv.100 목표값)
    │   │   ├── 3차 극전직 A1a (Lv.250 목표값)
    │   │   └── 3차 극전직 A1b
    │   └── 2차 심화전직 A2
    │       ├── 3차 극전직 A2a
    │       └── 3차 극전직 A2b
    └── 1차 상위전직 B
        ├── 2차 심화전직 B1
        │   ├── 3차 극전직 B1a
        │   └── 3차 극전직 B1b
        └── 2차 심화전직 B2
            ├── 3차 극전직 B2a
            └── 3차 극전직 B2b
```

- 클래스 하나에 **3번의 이진 분기**: 기본 1종 → 상위 2종 → 심화 4종 → 극전직 8종.
- 32 진영 × 6 계보 = **192개 뿌리**.
- 상위전직 노드 384종 + 심화전직 노드 768종 + 극전직 노드 1,536종.
- **기초~3차 직업 계보 노드 2,880개, 3차 도달 직업 1,536개**이며, 4~7차 고유 진화를 포함하는 **7차 전체 직업 노드 9,024개/끝단 직업 1,536개**가 현재 권장 목표. 이 수치는 *계보/분기 슬롯 수*이며 2,880개 개별 엔진 구현을 각각 완전히 다른 코드로 작성한다는 뜻은 아님. 스킬 메커니즘 엔진 공용화 + 전직별 특성/스킬/시각 연출 차별화.
- 분기별 상위 직업 이름, 고유 스킬, 플레이 성격, 이펙트를 모두 별도 데이터로 정의. **아래 192개 기본 클래스 명단은 확정 초안이고, 전 진영 2,688개 상위 전직의 개별 정식 명칭은 향후 세부 설정 단계에서 채워야 하며 아직 작성 완료된 것이 아님**. 확정되지 않은 세부 이름을 구현 완료라고 주장하지 않는다.
- **현재 성장 마일스톤 Lv.30/100/250**을 기준으로 1/2/3차 전직 이벤트를 같은 공동 게이트에서 수행. Lv.250까지 오프라인 기본 ×1 **7일**, 온라인 기본 ×2 **3.5일**의 기준 성장곡선을 검증한다. 자세한 성장·전직 시련은 [GROWTH_REWARDS_AND_GATE_EVENTS.md](./GROWTH_REWARDS_AND_GATE_EVENTS.md). 초기 직업 계보는 고정하고 상위 전직은 2→4→8로 심화. 극전직 후에도 숙련·초월 강화·시각 성장 지속.
- 분기 선택에 따라 개인 자동사냥의 범위, 주기, 상태이상, 생존, 보스 기여 등 실제 전투 패턴이 달라지게 할 것.

## 3-A. 진영 32의 최종 변경: 밈은 몬스터 이벤트로 이동 (2026-11-03)

- **초현실 밈연합 플레이어 진영은 폐기**. 32번째 슬롯은 **시간관리국**으로 대체. 6기초계보는 시간수사관/연대감찰관/시계기술관/역행의무관/시대밀수단속관/미래예보관.
- 세계관에서 버려진 유행 밈은 **적 전용 희귀 게이트 사건 E120 '한물간 밈의 습격'**에만 등장. 밈 캐릭터를 고를 수 없고 전직/부캐/채널 시너지 등록에도 넣지 않음. [MEME_INVASION_EVENT.md](./MEME_INVASION_EVENT.md) 참고.
- 시간관리국의 대표 고유 7차 계보는 **시간세관장**(시대밀수단속관)으로, 밀수 적 탐지·시대 착오 보급·사건 통제 등 시간단속/지원 플레이를 담당. 예능·요리·경제형 직업 다양성은 기존 진영에서 유지.

## 3-A. 재편 추가 규칙: 이름과 직업 역할이 진영 정체성의 핵심

- 기존 신화의 신들/오리왕국/음식왕국/차원 오류족 4개 슬롯은 폐기. 해당 콘셉트를 단순 다른 이름으로 재현하지 않는다. 16 고대 학술원(연구·기록), 30 유랑예술단(예술·공연), 31 대도시 상단(경제·요리), 32 시간관리국(시간 수사·단속·회복·예보)으로 정확히 대체하여 **32개 진영 수 유지**.
- 오리와 음식은 독립 진영이 아니라 **직업·전직·연출 요소**. 오리광대에서 물갈퀴 광대/황금알 사제 등으로, 전투요리사에서 햄버거기사/김치술사/냄비치유사 등으로 분화. 초기 192개 루트 밖에 루트를 추가하는 것이 아니라 1~3차 분기로 배치.
- **해병 기본 계보는 인물 이름**: 손수잘(의무), 황근출(도끼), 황룡(수육·각성 공군), 진떡팔(요리), 마철두(일반 원거리), 곽말풍 중령(마법). 기초 루트 6개 모두 다른 플레이와 독자 모션.
- 모든 **1~7차 전직에서 신규 고유 액티브 스킬 1개씩 추가**하고 하위 스킬 영구 보존. 기본 고유 스킬 1개와 별도로 7차 시 최소 8개 액티브. 해당 전직 경로의 새로운 스킬 수는 7개이며, 일반 공격 A·B/패시브/장비 효과는 계산에서 제외. 스킬과 캐릭터 이름만 바뀌어서는 안 됨.
- 32개 모든 진영에 **최소 1개의 유일한 고유 상위 직업군**이 있어야 함. 독특한 계보·1~7차 대표 스킬이 담긴 [진영 재편·32개 대표 전직군 문서](./FACTION_CLASS_REWORK_2026_11_03.md)에서 검증.
- 신규 스킬 제작 시 초기 기본기 10, 1차12, 2차16, 3차20, 4차24, 5차30, 6차36, 7차48개 **서로 다른 실제 바디 그림**을 최소. 도트 리터치/프레임 이벤트/FX 분리/성능 정책: [PIXEL_ANIMATION_PRODUCTION_RULES.md](./PIXEL_ANIMATION_PRODUCTION_RULES.md).
- 기초·상위직업 스킬의 역할은 공격뿐 아니라 **치유, 자동보급, 장비 감정, 팀 골드 보조, 수비, 요리, 공연/사기, 정찰/약점 파악, 사망→부활 시 한시 버프**를 포함. 공격력/회복량 단순 수치 변경만 192개 계보에 반복하지 않는다.
- 기존 32진영×6루트×1~7차 전직 **9,024 직업 노드 기획 목표** 유지. 현재 표는 192개 진입 클래스의 이름/대표 경로 설계이고, 모든 9,024개 상위 직업명/기술 데이터가 완성된 상태는 아님.

## 7. 다른 진영도 전부 같은 깊이로 전직해야 한다

- 조선·현대군·슬라임족 세 샘플만 깊게 만들고 나머지 진영을 직업 하나로 끝내면 **정식 버전 완성 아님**.
- 32개 진영 모두 6개 시작 계보에 대해 상위 A/B, 심화 A1/A2/B1/B2, 극전직 8개를 정의·구현한다.
- 클래스별 설계표 필수 필드: faction_id, root_class_id, job_id, parent_job_id, tier, branch_choice, display_name, archetype, targeting, range, attack_cycle, skill_ids, skill_weights, passive_ids, auto_ai_policy, vfx_id, sprite_id, mastery_rule, unlock_level.
- 각 상위 전직은 기존 스킬 일부 계승 + **상위 전직 전용 스킬 최소 1개**, 상위 직업의 고유 전투 메커니즘 **최소 1개** 보유.
- 도트 기본 실루엣은 캐릭터 생성 시 고정한 외형을 기준으로 유지. 전직별 갑옷/이펙트/자세/무기/오라 등 진화 연출은 허용하되 다른 종족·전혀 다른 캐릭터로 교체되지 않음.
- 스킬 연출의 분신·드론·벌레 떼·지휘 사격·정령은 **본체의 스킬 효과**로 취급하여 원랜디식 독립 육성/유닛 조합 시스템으로 변질되지 않게 한다.
- **최신 규칙 우선**: 힐러/지원직이 혼자 몬스터를 잡을 필요는 없다. 개인 **게이트 OFF** 상태에서도 공용 공간의 실제 힐·보호막·버프·디버프 지원으로 정상 성장 보상. 혼자 있을 때는 안전 수련/오프라인 지원 수련으로 성장이 막히지 않아야 한다. 자세한 시너지/몹 게이트/보스 정책은 [SOCIAL_IDLE_SYSTEM.md](./SOCIAL_IDLE_SYSTEM.md) 참조.
- 전직을 잘못 선택한 플레이어도 해당 노선에서 장기 성장 가능하도록 밸런스. 분기 되돌리기/직업 변경권은 기본 규칙상 제공하지 않는다.

## 8. 클래스 전직/숙련도 데이터 무결성

- 캐릭터 생성 이후 `faction_id`, `root_class_id`, `base_appearance_id` **불변**.
- `current_job_id`는 해당 캐릭터 고정 직업 계보의 자손만 허용. `career_path`에 불가역 분기 선택 기록.
- 특정 전직을 선택하면 서버 트랜잭션으로 반영, 두 기기 동시 요청 중복/불일치 방지.
- 숙련도는 스킬별로 누적하고 하위 랭크 계승. 온라인/오프라인 자동 사냥 양쪽에서 동일 정산 엔진 이용.
- 직업군 전환을 위한 결제·이벤트·관리자 예외는 기본 범위에서 제외. 진영/클래스 변경은 신규 Lv.1 부캐만 가능.

## 9. 개발 전에 추가 구체화할 데이터

- 2,688개 상위 노드의 개별 직업명/메커니즘/연출/밸런스 작성 및 검사.
- 각 1,536개 말단 경로가 유사한 클래스와 구분되는 최소 핵심 패턴 1개 정의.
- **도트 스프라이트 생산 파이프라인은 상세 확정:** [고밀도 프레임 제작 규칙](./PIXEL_ANIMATION_PRODUCTION_RULES.md) · [192개 기초 클래스 전용 대기/기본공격 A·B/시그니처 제작 카드](./CLASS_ANIMATION_192.md) · [기계판정 JSON](./ANIMATION_GENERATION_POLICY.json) 참조. 기존 Desert Front의 8포즈 반복을 완성용으로 허용하지 않는다. 각 기초 직업 고유 모션과 1~7차 전직별 기술/고급 궁극기 포즈를 각기 제작·검증한다.
- 공통 스킬 연산 빌딩블록(연쇄·관통·범위·오라·분신 이펙트·드론 이펙트·지속피해·방어반격 등)으로 대규모 데이터 구동형 시스템.
- 전직 UI는 게임의 메인 공간을 떠나지 않는 **팝업 트리** 형태.

*주의: 이 문서는 기획 범위와 예시를 정의하는 문서이며, 현재 목표인 9,024개 직업 노드와 7차 전직 전체가 실제 구현되었다거나 개별 상위 직업명이 모두 완성됐다는 뜻은 아니다.*
