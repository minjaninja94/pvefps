# simsimrpg — 해병 푸드 10종: 적 전체 디버프 / 해병에게만 음식 버프

> 2026-11-04 KST 사용자 최종 지시 우선. **해병 유니버스 음식 스킬의 적 디버프는 '채널에 살아 있는 모든 적'**, 음식에서 발생하는 아군 버프는 **'해병 유니버스 실제 활성 캐릭터'만** 대상. **일반 플레이어·타 진영 플레이어는 직접 음식 버프 0**. 기획 단계, 미구현. 연결 정본: [해병 48개 스킬](./MARINE_SKILLS_6X8.json), [해병문학 스킬 기획](./MARINE_MEME_LORE_SKILLS.md), [2000종 몬스터 마스터](./MONSTER_MASTER_PLAN.md).

## 1. 엔진 규칙: 기본 타깃 표적은 섞지 않는다

1. `effect_food_enemy_debuff.target = channel.alive_enemies_all`: **한 개 공동 게이트·현재 채널에 살아 있는 모든 적**. 잡몹·정예·특수·정식 수동 보스까지 모두 `food_enemy_debuff` 태그를 수신. 도트/이펙트를 1마리씩 2000회 전송하지 말고 서버가 배치 정산·클라이언트 집계 VFX. 채널 밖·아직 스폰하지 않은 적은 대상 아님. 새 스폰은 잔여시간이 있는 **전장형 음식 효과**에 한해서만 남은 시간 효과 적용; 즉발 타격형은 새 스폰에 소급 적용 안 함.
2. `effect_food_ally_buff.target = current_channel.active_player_characters WHERE faction_id == F29`: 해병 진영의 실제 **플레이 중 활성 1캐릭터**, 유효 참여 중인 대상에게만 부여. 같은 채널의 조선·중세·현대군·궤도개척군 포함 **해병이 아닌 모든 사용자**는 직접 음식버프 **0**, NPC 도우미3명도 0. 해병이 아닌 캐릭터의 일반 버프·힐은 별도 시스템이므로 막지 않음.
3. 타 진영은 **적이 약해지는 간접 이익은 공유**하되 음식 때문에 자신에게 공격/방어/HP/골드/회복 속도 버프 스택이 생겨선 안 된다.
4. 개인별 보상/골드/온라인 배율은 기존 규칙. 푸드 디버프를 전 적에게 걸었다고 **모든 몬스터에게 풀 처치 기여/보스 전리품을 자동 지급하지 않는다**. 실제 유효약화·기여와 시간/참여 상한 별도.
5. **정식 보스도 음식 디버프 대상**이지만 보스의 강제경직/기절·회복불가 같은 밸런스 파괴는 피해감소·약화량 상한/상태저항으로 제한. 음식 디버프를 완전히 '면역'시키면 적 전체 원칙과 충돌하므로 **일부 효력의 감쇠·표식은 유지**. 보스 공용 HP 한 줄/타이머에 영향 없음.
6. 채널에 해병이 여러 명이면 적 디버프는 시전자가 많아도 **상태이상 ID별 합산/갱신 상한**을 적용하며 음식별 강도 상한을 넘지 않는다. 초보/고렙 섞여도 기초 DPS를 강제로 전멸시키는 중독 무한스택 금지.
7. 해병이 전직해도 음식 스킬의 표적은 `F29` 고정. 황룡의 **기열 징발(해병 아군 디버프) 동의 규칙**은 음식 버프 규칙과 별개이고 음식으로 다른 팀원 디버프/강제 버프 트롤링 금지.
8. 전투가 아닌 음식 이모트·보급 손동작도 대상 판정 정책은 같으며, 소환된 오도봉고/솥/식판은 지속 소환 유닛이 아닌 단발 애니메이션.

## 3. 실제 해병 스킬/애니메이션 적용 범위

- 진떡팔: 초기 '해병짬밥 배급', 1차 '오늘의 해병짜장', 2차 '해병수육 한솥', 3차 '무톤요일 특식', 4차 '전우애 진수성찬', 5차 '해병짜장 리필', 6차 '해병기합 무한급식', 7차 '6974 해병대연회'. **전부 적 전체 디버프 + 해병끼리만 음식 버프**.
- 마철두: '해병짜장 직사포', 2차 '해병짜장 고압탄', 7차 '6974식 해병짜장 탄막'의 **음식 속성 발동 부분**도 동일 타깃 규칙. 단순 총탄 물리 피해는 실제 맞은 몬스터에게만; 탄약에 포함된 **공용 음식 상태이상/해병 식품 버프**는 전장 범위 규칙 적용.
- 황룡: '해병수육'의 **음식 계열 보조 효과**가 발동하면 위 타깃 정책. 반면 죽고 되살아날 때의 직업 고유 부활 패시브는 기획상 **해병푸드라고 명시한 부분만 제한**, 기존 아군 부활 버프/적 약화 자체를 음식과 혼동 금지.
- 공격·회복 연출: 오리지널 도트 솥·음식·식판/검은 소스 탄막 + 적 머리 위 디버프 표식 + 해병 머리 위 버프 표식. **비해병 사용자에게는 음식 버프 아이콘조차 표시하지 않음.**
- 50명 채널에서 음식 스킬을 동시에 연달아 사용하면 소스 입자/안개가 화면을 가리지 않도록 범위 이벤트는 **버프 아이콘 공유·최대 파티클 제한**으로 표시.
