## 1. 절대 변경하면 안 되는 확정 핵심 (최근 수정 의견 우선)

1. **게임 전체가 한 화면**이다. 산사 같은 공동 채널에서 채팅·친목과 자동사냥을 **동시에** 한다. 별도 마을·사냥맵·던전 화면으로 나누지 않는다. 도감/장비/프로필/캐릭터선택은 현재 화면 위 팝업으로만 표시한다.
2. 원랜디·메랜디에서 참고하는 것은 **끝없이 밀려오는 웨이브·공동 전장·랜덤 보상·진행 체감**이다. 유닛 소환, 조합, 배치, 타워, 덱, 매판 리셋, 패배 후 재시작은 **절대 넣지 않는다**.
3. **RPG의 주체는 플레이어 캐릭터 1명**. 캐릭터 생성 시 진영·초기 직업 계보·기본 외형이 영구 고정된다. **그 계보 내에서는 단계별 상위 직업으로 깊이 있게 분기 전직**할 수 있다. 선택한 상위 전직 경로는 되돌리거나 다른 계보로 변경할 수 없다. 부캐를 새로 만들면 다른 계보를 Lv.1부터 키울 수 있다.
4. 부캐 여러 개 생성 가능. 새 부캐는 Lv.1부터 독립 성장하고 골드·장비·진행도도 별개. 거래, 캐릭터 간 아이템/골드 이전 없음.
5. **계정당 활성 캐릭터 최대 1명**. 이 한 명만 (a) 채널에 나타나고 (b) 자동 사냥하여 경험치·골드·아이템을 얻는다. **온라인/오프라인 모두 동일**. 다른 모든 부캐는 표시도 사냥도 중단된 대기 상태. 부캐 수십 개 동시 사냥 허용이라는 과거 발상은 **폐기**.
6. 활성 캐릭터 변경 시 기존 캐릭터 보상을 원자적으로 정산하고 사냥 중지 → 채널 표시 해제 → 새 캐릭터 활성/표시/사냥 시작. 두 기기가 동시에 접속해도 계정당 활성 캐릭터는 단 한 명이다.
7. 게임오버·영구 사망·강제 초기화 없음. 채널의 무한 웨이브 진행이 막히면 안전 구간으로 후퇴/정체할 수 있으나 보유 성장/장비는 유지한다.
8. **디아블로식 랜덤 드롭의 기대감**(희귀도, 강한 장비, 특별한 시각 연출)은 살리되 장비 비교 고민을 없앤다. **장비는 부위별로 상위 등급 획득 시 즉시 자동 착용**, 같은 등급에서는 전투력 우수 장비 자동 착용. 구형 장비·낮거나 같은 등급의 열등한 드롭은 **즉시 자동 판매하여 골드 지급**. 높은 등급이 낮은 등급보다 반드시 우수하도록 능력치 구간 설계. 사용자가 장비를 수동 관리할 필요가 없다.
9. **인벤토리 슬롯 제한 없음**. 보관 가능한 특수 수집품/재료/업적 기록은 슬롯 확장 과금 없이 보관. 일반 장비 드롭은 자동 착용 또는 자동 판매되어 쌓이지 않음.
10. 골드는 캐릭터 전용 영구 성장(공격력, 체력, 공격속도, 클래스 특성, 사냥 효율 등)에 사용. 자동 추천 강화 구매 지원.
11. 게임이 꺼져도/로그아웃해도/세션이 끊겨도 **마지막 활성 캐릭터 한 명만** 서버 기준으로 자동 사냥·경험치·아이템 보상 누적. PC나 모바일의 백그라운드 실행 상태에 의존하지 않는다.
12. **32개 진영 전체 + 192개 기초 계보 + 각 계보의 다단계 상위전직 전체**가 첫 정식 공개 버전의 완료 범위. 루트마다 2→4→8로 총 14개 상위 노드를 갖는 **총 2,880직업 노드 / 1,536 최종 경로** 구조다. 내부 테스트는 부분 구현해도 정식 출시 판정에 일부 진영/직업만 포함하는 축소안은 없다. 상세 명세는 CLASS_CATALOG.md.
13. 기존 `pvefps/desert-strike/`, `goablo/` 등과 코드·배포·데이터베이스를 분리한다. 당장은 **기획 Markdown만 새 폴더에 기록**, 게임 파일이나 기존 배포는 수정하지 않는다.

## 2. 핵심 판타지·플레이 경험

- 조선 무사, 중세 기사, 마법사, 랩터, 현대군, 해병 유니버스, 곤충, 슬라임, 용족, 닌자 등이 **동일한 도트 전장**에 등장한다.
- 유저들은 채널별로 모여 머리 위 말풍선·채팅창으로 소통하고 서로의 레벨/희귀 장비/고유 이펙트를 본다.
- 캐릭터가 자동으로 몬스터를 잡고 웨이브를 진행. 플레이어가 적극적으로 개입하면 보너스를 받지만 방치만으로도 영구 성장.
- 희귀 장비 획득 시 주변에 빛기둥/간결한 알림을 보여주어 소셜 반응 유도. 저사양/업무용 무음/알림 끄기 제공.
- 어느 진영을 선택했느냐보다 **나만의 클래스 하나를 오래 키웠다는 사실**에 가치를 둔다.

## 3. 한 화면(UI) 사양

- 상단: 채널명, 웨이브, 몬스터/보스 상태, 내 캐릭터 레벨·경험치·골드.
- 중앙: 도트 캐릭터들이 같은 바닥·공용 공간을 걸어 다니며 자동 공격, 몬스터 및 공동 보스가 이 공간에 등장.
- 캐릭터 위: 닉네임/레벨/클래스 아이콘, 선택형 채팅 말풍선 및 전투 이펙트.
- 하단: 채팅창(채널/귓속말/친구 등), 간단한 채널·캐릭터·프로필·골드강화·랭킹 버튼.
- 모든 세부 UI는 모달·슬라이드 패널 형태로 나타남. **맵 로딩으로 다른 전장에 전환하지 않음**.
- 렌더링 최적화: 캐릭터 수/펫/이펙트/몬스터 수가 많을 때 단순화 및 저사양 모드. 클릭한 유저 프로필에서 클래스/레벨/성장 기록 확인.

## 4. 채널·웨이브·소셜

- 공개 채널, 친구 초대 채널, 길드 채널(길드 기능은 정식 공개 범위의 세부 우선순위 추후 조정). 채널은 **공간 분리 단위**이지 별도 사냥터/별도 게임판이 아니다.
- 전 서버 캐릭터 데이터는 영속적. 채널 이동 후에도 레벨, 장비, 자동 성장 상태 유지.
- 채널별 실시간 화면은 유저당 최대 1캐릭터. 실제 오프라인 상태는 온/오프라인 표시로 구분. 오프라인의 대표 캐릭터는 채널에 잔상/방치 표시 가능하나 슬롯과 온라인 접속 인원을 점유하지 않는 정책으로 설계.
- 무한 웨이브. 일반/정예/특수 몬스터는 **유저별 게이트 ON/OFF** 체크에 따라 같은 공용 화면에 등장. 보스는 자동 출현하지 않으며 **채널 입장 후 1시간에 수동 소환**할 수 있고, **처치 시점부터 1시간** 재사용 대기. 공동 채널 이벤트와 최고 웨이브 기록은 유지. 상세: [SOCIAL_IDLE_SYSTEM.md](./SOCIAL_IDLE_SYSTEM.md).
- 게임오버 없음: 전력 부족 시 마지막 안정 단계에서 재시도하거나 몬스터 강도가 정체될 수 있으나 사냥·골드 누적은 지속.
- 신규/고레벨 유저가 같은 화면에 있어도 개인별 적정 보상과 공격 기여도 보정. 낮은 레벨의 편승만으로 최고 장비 획득 불가.
- 채팅, 파티 기여, 좋아요/이모트, 차단/신고/도배 방지/개인정보 보호. 채널 수용 인원은 성능 검증 후 확정(50명은 시험 목표값, 확정 스펙 아님).

## 4-A. 추가 확정: 종족·클래스·인원 중첩 시너지 / 개인 게이트 / 수동 공동 보스

2026-11-02 사용자 추가 요구를 기존의 '주기적 자동 보스' 설계보다 우선한다. 아래 규칙은 **[SOCIAL_IDLE_SYSTEM.md](./SOCIAL_IDLE_SYSTEM.md)** 에 32개 진영 전체 패시브, 192개 기본 클래스 패시브, 공식 시험안, 오프라인 정산과 게이트 세부까지 상세 기록했다.

1. **채널 전체 인원 + 진영별 인원 + 클래스별 인원수**에 비례해 중첩되는 공용 패시브 적용. 같은 진영/클래스가 많을수록 해당 효과가 중첩되며 각기 다른 진영/직업의 효과도 함께 적용. 상위 전직별 전문 패시브 확장. 각 계정은 활성 캐릭터 **1명만** 채널 시너지에 참여.
2. **개인 게이트 ON/OFF 체크**: 유저마다 일반 몬스터 소환을 켜고 끈다. 모든 소환 몬스터는 동일 채널 화면에 등장하며 서로 공격/치료/지원 가능. 게이트 OFF인 힐러도 파티 치유와 버프 기여로 경험치·골드 획득.
3. **개인별 안정 사냥 단계/도전 단계**: 게이트에서 접속 중에 더 높은 몬스터 난이도를 도전해 최고 안정 단계를 갱신할 수 있다. 실패해도 게임오버 없이 기존 안정 사냥으로 복귀.
4. **채널 공동 보스**: 방에 들어온 후 1시간을 채워야 수동으로 소환할 수 있다. 보스 처치 후 **그 처치 시각을 기준으로 다시 1시간** 대기. 자동 소환 금지. 같은 화면에서 모두 협력, 보스는 일반 사냥보다 큰 경험치·골드·희귀 드롭 보상을 제공한다. 실패 시 무한 재도전 악용 방지와 채널 간 호핑 제한 구현.
5. **오프라인 누적**: 게임/앱 종료·세션 종료 후에도 계정당 마지막 활성 1캐릭터만 서버 정산. 일반 장비 드롭은 온라인과 같은 등급표/자동착용·판매 적용. 오프라인은 마지막 안정 단계에서 개인 사냥/지원직 수련을 계산, 온라인의 채널 시너지·단계 도전·수동 공동 보스는 복제하지 않는다.
6. **시너지·스폰·오프라인 세부 수치**는 기획 문서에 *시험용 제안값*으로 구분해 놓았으며 성능·경제 시뮬레이션 전에는 최종 확정하지 않는다.

이 항목은 2026-11-02 최신 사용자 수정안이며, 앞서 말한 **'클래스를 영구 고정한다'**와 모순되지 않게 **초기 직업 계보는 고정, 상위 전직은 그 계보 안에서만 다단계 분기**로 정의한다.

- 참고 방향: 마비노기처럼 스킬별 숙련도/랭크가 사용 경험으로 오르고, 메이플처럼 일정 성장 시 상위 전직으로 강화되며, 트리 오브 세이비어처럼 직업 경로가 풍부해야 함. 실제 타 게임의 고유 직업/스킬/아트 복제 금지.
- 생성: **32진영 선택 → 6개 기초 직업군 중 1개 선택 → 기본 외형 선택 및 생성 확정**. 여기서 선택한 루트 직업군과 외형은 바꾸지 못함.
- 전직 트리: **기초직업(루트) → 1차 상위직업 2갈래 → 2차 심화직업 각 2갈래(4종) → 3차 극전직 각 2갈래(8종)**. 선택할 때마다 해당 계보 하위 분기만 열림. 총 192개 루트와 2,688개 추가 상위 직업 노드 = 2,880개 클래스 노드, 최종 경로 1,536개.
- 전직을 하면 클래스 이름과 능력, 스킬 구성이 상위 단계로 진화하고 레벨/장비/골드를 계승함. 다른 루트로 갈아타거나 이미 버린 분기를 다시 선택하지는 못함.
- 레벨 목표 예시: Lv.30 1차, Lv.100 2차, Lv.250 3차(수치 미확정). 극전직 이후에도 숙련도/스킬랭크와 영구 강화 성장 지속.
- 마비노기식 스킬 숙련은 일반 자동 사냥/오프라인 사냥에서도 누적되도록 동일 서버 정산 엔진에 포함.
- 분기마다 고유 전투 패턴·피격 효과·자동 공격 우선순위·연출이 달라야 하며 공격력 숫자나 명칭만 바꾸는 직업 양산은 금지. **직업별 단독 방치 사냥 가능**해야 함.
- 각 기초 클래스에 기본공격·자동스킬 2·패시브·궁극기 등 최소 5개 핵심 스킬 엔트리를 계획하고, **모든 전직 노드에는 최소 1개 이상의 새로운 고유 전투효과 또는 스킬을 추가**한다. 전직 트리만의 실제 스킬 수는 구현 시 상세 디자인.
- 분신/드론/지원 포격/동물 무리 등은 **본캐릭터 클래스의 전투 스킬**이지 소유하고 육성·조합할 별도 유닛이 아님.
- [32개 진영별 전체 기본 클래스 명단 및 상세 전직 트리 설계](./CLASS_CATALOG.md) 참조.

## 7. 장비·드롭·골드

- 부위별 현재 장비 하나씩 보유. 아이템 등급 순서 예시: 일반 < 마법 < 희귀 < 영웅 < 전설 < 신화 (세트/유니크 고유 효과는 별도 선택 가능한 등급 정의 여부 추후 확정).
- 등급 **우선**: 높은 등급 = 반드시 우수한 기본 전투력 범위. 같은 등급 = 장비 성능 점수 우선. 클래스에 맞는 장비만 드롭.
- 드롭 시 **서버 측에서 즉시 비교**: 더 좋은 장비 자동 장착 및 기존 장비 즉시 판매; 그렇지 않은 드롭은 즉시 판매. 판매액은 해당 캐릭터 골드로 전환. 이 모든 과정은 사용자가 인벤 관리 없이 실행.
- 전설/신화 등 희귀 드롭에 특별한 연출·채널 축하 메시지(개인정보·알림 선택권 제공).
- 무제한 인벤토리 = 슬롯 구매·중량 제한 없음. 장비 자동 정리로 일반 장비 누적이 없고, 수집 기록/재료 등은 검색·페이지네이션과 집계 수량으로 보관. 서버에는 기술적 저장량 제한과 정리/압축 전략 별도 구현하되 플레이 상 임의 삭제 금지.
- 거래소/P2P 교환/타 캐릭터로의 장비·골드 이전 **없음**.
- 판매 골드의 용처: 클래스 고유 공격·체력·공속·효율 영구 강화. 자동 추천 강화 구매 가능. 골드 인플레이션과 성장 비용은 실측 밸런스로 튜닝.
- 무작위 속성 및 고유 효과는 **고민을 요구하는 수동 빌드 선택**이 되지 않도록 자동 종합 전투력 규칙으로 단순화. 디아블로에서 참고하는 것은 획득의 기대감과 아이템의 특별함이지 수많은 수동 장비 옵션 비교는 아니다.

## 8. 자동사냥·오프라인 정산·키보드 연동

- PC·휴대폰에서 게임을 닫아도 **서버 기반 경과 시간 정산**으로 활성 캐릭터의 경험치·골드·개인 드롭을 누적.
- 온라인 캐릭터는 실시간 전투 연출. 오프라인 캐릭터는 클라이언트 타이머에 의존하지 않고 마지막 정산 시점/사냥 상태/서버 승인 전투력을 통해 누적분 계산.
- 동시 세션·캐릭터 전환 시 **유일 활성 캐릭터**를 서버 트랜잭션/버전 키로 보장, 동일 정산 구간 중복 보상 금지, 오래된 세션의 정산 무시.
- 오프라인 사냥도 같은 개인 아이템 등급표를 사용. 실시간 채널 공동 보스 기여 보상은 실제 참여/기여 규칙으로 별도 정산하여 오프라인 계정의 중복 편승 금지.
- 오프라인 효율/누적 시간 상한은 **아직 미확정**. 이전 대화의 24시간 100% 이후 50%, 8시간 제한 등의 수치는 아이디어일 뿐 확정 사양이 아니다. 사용자는 세션 종료 후에도 사냥이 이어지는 것을 요구함.
- 키보드 공격/추가 보상은 봉고캣식 **선택 기능**. 업무 타자를 많이 치는 사람만 압도적으로 유리하지 않게 활동 보너스 상한과 대체 보너스 경로 제공.
- 일반 웹페이지는 다른 앱에서의 키 입력을 읽지 못함. 향후 사용자 동의 기반 PC 보조 앱으로 **입력 내용/암호/클립보드를 저장·전송하지 않고 집계된 이벤트 수만 전달**, 민감 앱 제외와 즉시 중지 제공.
- 모바일 iOS/Android의 실제 백그라운드 실행은 중단될 수 있으므로 **서버 정산이 정답**. PWA로 접속해 잠깐 확인, 종료 중에도 보상 누적. 회사 PC 보안 정책 우회/활동 은폐 기능은 개발 목표가 아니며, 개인 기기에서 무음/미니 UI/저부하 모드 제공.

## 9. 아키텍처 초안 (내일 검토 후 착수)

- Frontend: TypeScript + Phaser(2D 픽셀 렌더링) + 경량 UI(React 여부 선택).
- Hosting: Cloudflare Pages의 **별도 프로젝트**, 기존 게임과 Build/include paths 충돌 방지.
- Realtime: Cloudflare Workers/Durable Objects(채널별 실시간 상태·WebSocket).
- Account & storage: **별도 Supabase 프로젝트**, Auth + PostgreSQL, 서버 측 드롭/자동장비/골드/경과정산.
- PWA: 모바일 접속/홈 화면 추가. PC 전용 보조앱(Tauri 등)은 후속 플랫폼 기능.
- DB 개념: accounts, characters, character_activations(account_id unique), factions, classes, class_skills, character_progression, equipment_slots, loot_log, gold_ledger, hunt_sessions, hunt_settlements, channels, channel_presence, channel_messages, channel_wave_state, achievements.
- 최소 보안: row-level security, 채널 메시지 권한·필터, 서버 권위 전투력·보상·장비 갱신, 정산 idempotency key, 사냥 중단/전환 경계 시간, 유저 입력 보너스 상한, 데이터 백업 및 감사 로그.
- 서버비: 오프라인 모든 캐릭터의 매 프레임 몬스터 AI 실행 금지. **계정당 1 활성 캐릭터의 시간 기반 정산** 중심. 실시간 채널은 현재 접속자에 대해서만 전투/위치 최적화.

## 10. 정식 공개 완료 조건(범위 축소 금지)

- **32개 진영 모두 선택 가능**, 각 진영 기초 클래스 6개로 **총 192개 변경 불가능한 직업 계보**, 계보 내 2→4→8 심화 상위직업 전체(총 2,880개 직업 노드, 1,536개 최종 성장 경로).
- 모든 기본 직업군에 고유 실루엣·픽셀 스프라이트와 기본 공격/자동스킬/패시브/궁극기 구성. 각 상위직업 전직 때마다 **차별화된 전용 스킬과 전투 효과**를 추가하여 단순 수치차이로 채우지 않는다. 계보·분기 조합 2,880개 노드와 1,536개 최종 경로를 검증한다.
- 클래스별 성장·전투·자동 드롭의 최소 스모크 테스트 및 진영별 밸런스 시뮬레이션 통과.
- 한 화면의 채팅·자동사냥, 채널 멀티, 게임오버 없는 웨이브, 골드 영구 강화, 자동 장비교체·판매, 서버 오프라인 정산 완성.
- 캐릭터 생성 고정, 부캐 생성 시 Lv.1, **1계정 1활성 캐릭터**, 2기기 중복 접속/전환에서도 중복 보상 없음.
- 웹/PWA 화면 지원, 채팅 안전 기능, DB 복구 시나리오 테스트.
- **게임 코드/아트/서버는 지금 구현한 것이 아니다**. 이 문서는 향후 개발시 첫 정식 버전의 범위를 확정·보존하기 위한 기획서이다.
