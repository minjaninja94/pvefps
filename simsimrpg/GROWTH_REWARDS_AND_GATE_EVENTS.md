## 0. 최신 사용자 요구의 요약 (설계에 반드시 보존)

1. 옛날 메이플 같은 **오랜 클래스 육성·전직·기술 습득의 성취감**, 단계마다 전투 방식과 연출이 실제로 발전.
2. **오프라인 종료 후에도** 계정당 마지막 활성 캐릭터 1명 서버 자동 사냥(성장 멈춤 없음). **온라인 접속 유지 시 기본 보상 2배**.
3. **1차 상위 전직 Lv.30, 2차 심화 전직 Lv.100, 3차 극전직 Lv.250**을 현 기획의 레벨 기준으로 유지. **Lv.250 전직 조건을 달성할 때까지 기본 사냥 기준 오프라인 168시간, 온라인 84시간**을 캘리브레이션.
4. 일반 몬스터·정예·유저별 적정 티어는 **채널당 단 하나의 물리 공동 게이트**에서 출현. 랜덤 이벤트도 같은 공동 게이트를 사용; 별도 화면/던전/개인 게이트 금지.
5. 유저는 **포지션별 진형**에서 함께 싸우고, **채널 3명의 기본 NPC 탱커/힐러/공격 봇**을 보조로 얻는다. 봇은 시너지 스택에서 제외. 고레벨은 강력한 기술과 전직 이펙트를 과시, 초보는 적정 기여 보상 획득.
6. **1시간 수동 공동 보스** 규칙 유지: 채널/방 입장 후 60분 조건, 처치 시점부터 다시 60분 쿨. **게이트 랜덤 이벤트가 보스를 자동 소환하거나 그 타이머를 건드리면 안 됨**.
7. 새로운 전직 이벤트는 **개인의 직업 계보/선택 경로에 맞는 이야기·몬스터·이펙트·보상**이 있고, 완료 시 상위 직업 2개 중 하나를 **영구적으로 선택**. 다른 계보·종족·기본 외형 변경 불가.
8. 장비 수동 정리는 없음: 우월한 등급/동급 상위 장비 즉시 자동 착용, 나머지·구형 장비 즉시 판매 후 골드화, 거래/인벤 슬롯 제한 없음.
9. 정확한 드롭률/적 HP/공격력/시너지 버프/이벤트 발생률은 최종 확정 아님. **아래 수치는 게임 플레이·경제 시뮬레이션을 위한 초안**.

## 1. 2배 보상 정의

| 기본 보상원 | 세션 종료/오프라인 | 채널 온라인 자동사냥 유지 | 비고 |
|---|---:|---:|---|
| 일반 사냥 EXP | ×1.00 | **×2.00** | Lv.250 소요시간 캘리브레이션의 기준 |
| 일반 사냥 골드 | ×1.00 | **×2.00** | 자동 판매 골드는 별도의 아이템 정산을 따름 |
| 일반 장비 드롭 추첨 **기회 수** | ×1.00 | **×2.00** | 희귀/신화 **개별 확률을 2배로 바꾸지 않음** |
| 직업/스킬 숙련도 누적 | ×1.00 | **×2.00** | 오프라인도 숙련 누적 |
| 1시간 수동 보스 특수 보상 | 참여 불가 | 기여도에 따른 1회 별도 지급 | 보스 지급액까지 접속 2배 중복 적용하지 않음 |
| 랜덤 게이트 이벤트 별도 상자/기여 보상 | 오프라인 기본정산에 자동 포함 안 함 | 별도 규칙 | 일반 사냥 2배 후 이벤트 보상을 무한 배증하지 않음 |
| 채널 시너지 | 오프라인 산정에 고정하지 않음 | 실제 접속 중 계정 수·종족·클래스 중첩 | NPC 3명 스택 제외 |

- **온라인** = 서버에서 특정 계정의 **현재 유일한 활성 캐릭터**가 채널에 정상 연결된 것으로 확인되는 상태. 단지 클라이언트가 '켜져 있다'는 자기 보고를 신뢰하지 않고, 서버 수신 WebSocket 상태·제한된 heartbeat·연결 버전으로 확인.
- 창을 클릭하거나 키를 누를 필요는 없다. 다른 개인용 프로그램을 이용하는 동안에도 네트워크/OS가 연결을 유지하면 ×2. 브라우저 백그라운드, 모바일 화면 꺼짐, 절전 등으로 연결이 끊기면 **자동으로 ×1 오프라인** 전환; 이미 얻은 보상/아이템은 보존.
- 잠깐 통신이 끊겨서 잦은 상태 진동이 생기지 않도록 **예시 유예 30~90초** 후 서버가 시간 구간별 online/offline 상태를 마감. 유예 시간의 중복 2배 보상 방지.
- **부캐를 수십 개 보유해도** 채널 표시·전투·온/오프라인 보상은 **계정당 활성 1캐릭터**만.
- 무음·저부하·미니모드는 접속 인정과 무관. 회사 보안 정책 우회나 사용자 몰래 키 입력 수집은 개발하지 않음.

## 2. 3차 전직까지의 기본 성장 목표(누적 시간표)

이 표는 **같은 기본 사냥 효율의 1캐릭터**, 영구 전직/캐릭터 변경 없음, 보스·랜덤 이벤트·채널 시너지 제외, 같은 기준 성장 속도를 가정한 **사냥 누적 시간 목표**이다. 실제 플레이 시간은 변동 가능.

| 레벨 | 진행 단계 | 오프라인만 ×1 | 온라인 상시 ×2 |
|---:|---|---:|---:|
| 1 | 캐릭터 생성 | 0분 | 0분 |
| 10 | 초보기 벗어나기 | 30분 | 15분 |
| **30** | **1차 상위 전직 자격** | **2시간** | **1시간** |
| 60 | 첫 직업 중반 숙련 | 8시간 | 4시간 |
| **100** | **2차 심화 전직 자격** | **24시간** | **12시간** |
| 150 | 전문 직업 성장 | 60시간 | 30시간 |
| 200 | 극전직 준비 | 108시간 | 54시간 |
| **250** | **3차 극전직 자격** | **168시간(7일)** | **84시간(3.5일)** |

- 하루 온라인 8시간+오프라인 16시간이라면 하루 기준 사냥시간 등가량은 `8×2+16×1=32시간`. 누적 `168 / 32 = 5.25일`로 Lv.250 자격에 도달하는 **이상적 예시**.
- 온라인을 매일 4시간만 유지하고 오프라인 20시간이라면 `168/(4×2+20)=6일` (같은 기준). 이용자가 잘 시간/일 때문에 성장이 완전히 끊기지 않는다.
- **전직 '자격'과 '전직 이벤트를 완료해 직업을 획득'은 구분**. 이벤트를 미뤄도 XP와 레벨 누적이 멈추지 않으며, 복귀하면 언제든 한 화면에서 전직 이벤트를 진행할 수 있다.
- Lv.250에 도달하더라도 3차 상위 직업 분기 선택과 시련을 완료하지 않으면 상위 스킬은 개방되지 않는다. 다만 전직을 아직 완료하지 않았다는 이유로 기준 EXP 레벨업 속도를 0으로 막지 않음.
- 긴 오프라인 시간에 기본 레벨업이 불가능해지지 않도록 **레벨에 따라 자동 상승하는 최소 '기본 수련 EXP'**, 마지막 안정 단계 파밍 추가 보상으로 설계한다. 단계 도전·희귀 장비·상위 전직 이벤트는 접속 후 수행하고 기본 자동성장은 계속된다.

### 2-1. 수치 산출 모델(개발용)

- 레벨 `L`의 누적 '기준 오프라인 사냥 시간'을 `H(L)` (단위: 시간)으로 두고 위 **8개 체크포인트를 정확히 통과**하도록 단조 증가 곡선을 구성한다(단순 선형 구간도 가능하지만 양 끝에서 경험치 점프가 적도록 monotone cubic interpolation 권장).
- 기준 레벨 `L`의 예상 기본 EXP/분을 `R(L)`로 둔다. 안전 사냥·자동 장착 기준 스펙·NPC 기본 보조를 반영하는 **서버 수치 보정 대상**이다. 예시 `R(L)=600×1.015^(L−1)` EXP/분; 실제 게임 경제와 숫자 가독성에 맞게 조정.
- 다음 레벨 요구량: `XP_to_next(L)=round(max(1, [H(L+1)−H(L)]×60×R(L)))`. 오프라인 최저 기준 수익이 `R(L)`이면 체크포인트 누적 시간이 일치하고, 온라인 `2×R(L)`이면 절반.
- 진영/클래스별 실제 플레이 효율 차이와 단계/채널/이벤트 보너스가 추가되면 **기본선보다 앞당겨질 수 있다**. 기본선은 **지원형/혼자/방치 모두 공통으로 도달 가능**해야 한다.
- 레벨 250 이후는 **4~7차 장기 성장곡선**과 7차 후 무한 성장으로 연결. 최신 목표는 4차 Lv.400(21일/10.5일), 5차 Lv.600(55일/27.5일), 6차 Lv.850(120일/60일), 7차 Lv.1100(240일/120일), 오프라인/온라인 누적 사냥시간 기준. [SEVEN_ADVANCEMENTS.md](./SEVEN_ADVANCEMENTS.md) 참고. 상위 웨이브·숙련·골드강화는 계속되고, 급격한 숫자 폭발 및 JS 정밀도 한계는 서버 bigint/decimal 또는 단계별 단위 환산으로 처리.
- 전직/아이템/난이도가 바뀌어도 플레이어 계정의 누적 EXP는 소급 차감하지 않는다. 파라미터 버전과 정산 원장을 기록.

## 3. '테크 올리는 맛'을 만드는 성장 보상 간격

| 성장 계기 | 제공하는 즉각 보상 | 플레이 체감 |
|---|---|---|
| 레벨업 매회 | 기본 스탯 자동 증가, EXP 바/사운드 | 매일 지속 상승 |
| 5레벨 단위 | 자동 전투 효과/골드 소액 보너스, 새 UI 배지 | 짧은 간격의 성취 |
| 10레벨 단위 | 고유 스킬 숙련 랭크 체크, 외형 작은 변화/공격 모션 파츠 | 분명한 성장 |
| **Lv.30 (1차)** | 2개 상위직업 중 영구 선택, 고유 자동 스킬·패시브, 외형 진화 | 첫 큰 전직 성취 |
| **Lv.100 (2차)** | 선택 경로 안 2개 심화 직업 중 영구 선택, 광역/관통/방어 등 메커니즘 변화 | 클래스 개성 확립 |
| **Lv.250 (3차)** | 다시 2개 극전직 중 영구 선택, 대표 궁극기·특별 오라·칭호 | 장기 육성의 정점 |
| 250 이후 | 스킬 마스터리/계보별 초월 단계/전설 칭호 | 무한 RPG의 지속 목표 |
| 채널 협동 | 실제 유저 인원/종족/직업 중첩 시너지 | 친구들이 있으면 강해지는 경험 |
| 일반 아이템 드롭 | 등급 상위 자동 장착, 교체·열등 장비 자동판매 골드 | 조작 없이 파밍 체감 |
| 수동 보스 | 큰 EXP/골드·고급 장비 획득 기회, 사회적 연출 | 1시간 단위 대형 성취 |

- 스킬 숙련 랭크(마비노기 참고)는 자동 공격·힐·보호막·버프의 실제 유효 기여도와 경과 정산으로 상승. 힐러는 실제 치유/지원만으로도 육성 가능, 혼자 있을 때 봇 3명과 전투 가능.
- 성장 이펙트는 **같은 캐릭터의 진영/기본 외형 고정**을 위반하지 않고 새로운 갑옷 파츠·무기 궤적·자세·오라/궁극기 이펙트만 변화.
- '레벨업 외형 보상'은 도감에 수집되되 캐릭터 기본 외형 재선택/클래스 변경 기능이 아니다.
- 과도한 체크인/일일 퀘스트 숙제, 미접속 시 재화 상실, 놓치면 전직 실패하는 기간 제한 이벤트는 피한다.

## 4. 게이트 랜덤 이벤트 — 같은 화면에서 반복적으로 다른 재미

일반 웨이브와 이벤트 모두 **공동 게이트 1개**에서 출현. **수동 1시간 보스는 별개**이므로 랜덤 이벤트에서 정식 보스를 스폰하지 않는다.

**발생 빈도 시험안**: 채널당 평균 12~18분 간격(서버 시간 기준), 동시 이벤트 1종, 지속 30초~3분. 정식 보스가 소환되면 이벤트 진행을 잠시 보류/이동해 중복 연출을 피한다. 악용 방지를 위해 연속 중복 종류 방지·서버 seed/로그 저장.

| 이벤트 | 게이트에서 벌어지는 일 | 특화 역할 | 보상(시험안) |
|---|---|---|---|
| 황금 몬스터 떼 | 낮은 HP의 금빛 잡몹 다수 | 저레벨·다단히트 | 일반 골드 추가 묶음 |
| 검은 안개 | 몬스터 약화/암습, 명중 감소 | 정찰·닌자·힐러 해제 | 개인 EXP 추가 소액 |
| 강화 개체 난입 | 정예 여러 기가 일반 몬스터와 섞여 출현 | 고레벨·탱커 | 상위 단계 장비 추첨 |
| 포탈 폭주 | 짧은 동안 몬스터 웨이브 밀도 증가 | 광역 딜러·방패 탱커 | 일반 처치 보너스 |
| 마력 폭풍 | 속성 상태이상·마법 공격 패턴 변화 | 마법사·상태이상 해제 | 숙련도 추가 |
| 유물 상자 도주 | 몬스터가 상자를 빼앗아 달아나는 연출 | 측면 닌자·원거리 | 개인 추가 장비 추첨 |
| 용혈의 균열 | 비행/강화 적과 보호해야 할 약체 등장 | 용족·원거리·힐러 | 직업별 골드·EXP |
| 소환된 행상 | 몬스터 대신 NPC가 짧게 등장, 전투를 가리지 않음 | 전체 | 골드로 자동 강화 보조/장비 보상 |
| 희망의 방벽 | 공동 보호막 대상이 나타나 위기 웨이브 지원 | 힐러·지원·탱커 | 실질 지원 기여 보상 |
| 시대착오 균열 | 조선+현대+랩터 등 두 진영 몬스터 테마가 충돌 | 혼합 팀 | 채널 공통 작은 보너스 + 업적 |
| 거울 환영 | 유저 클래스 특성을 흉내 내는 정예(정식 보스 아님) | 해당 계열 카운터/지원 | 숙련·희귀 장비 추첨 |
| 럭키 점액비 | 약한 슬라임이 쏟아지는 짧은 축제 | 초보자·광역·힐러 | 일반 재화/경험치 |

- 이벤트는 **공개 채널의 공동 콘텐츠**이지만 보상은 **개인별**. 실제 레벨·진행 단계·기여도에 맞는 드롭 테이블, 킬스틸/막타 독식 금지.
- **힐러/탱커도 처치 딜량 없이 참여 가능**: 유효 힐·보호막·도발·버프/해제·전선유지 점수 인정. NPC 3명은 보상 획득/시너지 스택 불가.
- 초고렙은 정예를 쓸어버리고 크고 화려한 스킬 연출, 초보는 약체 몬스터·지원 이벤트로 기여. 다른 물리 게이트 또는 별도 저렙 방을 만들지 않는다.
- 이벤트 추가 보상의 기대값은 **온라인 기본 사냥 수익 대비 시간당 +5~10%**부터 시험. ×2 기본 보상과 중첩 시 무제한 배율이 폭증하지 않도록 이벤트 고유 보상은 **기준 산정 후 별도 가산**하고 서버가 제한.
- 이벤트 미참여/잠자는 시간으로 희귀 장비 영구 획득 기회가 사라지지 않음. 기본 일반 사냥/오프라인에도 같은 아이템 등급 드롭 가능, 이벤트는 추가 시도만 제공.

## 5. 직업별 전직 이벤트 — 계보 고정 + 분기 선택 + 개인 시험

### 5-1. 단일 화면에서 진행

- Lv.30/100/250 달성 → **'전직 가능' 상태**와 나에게만 보이는 알림/퀘스트 기록. 기한 제한 없음.
- 채팅/전투 화면을 떠나지 않고 **직업 트리 팝업**에서 현재 루트 아래의 **2개 상위 선택지**를 미리 열람. 선택 전 스킬·공격 연출·장래 분기 8개까지 예측 가능.
- 후보 확정 → 같은 공동 게이트에서 **전직 시련 일반/정예 몬스터 혹은 개인 목표 효과**가 발동(정식 1시간 보스 소환이 아니므로 타이머 간섭 금지). 다른 유저들은 **같은 화면**에서 시련자를 응원하거나 실제 힐·보호막으로 도울 수 있음.
- 전직 시험이 여러 명에서 동시에 시작해 화면을 가리는 문제는 **채널 시련 큐/이펙트 상한**으로 제한하고, 불합리한 대기 없이 서버의 개인 미션 타깃을 공유 몬스터에 부여하는 방식을 우선. 시련 대상은 다른 방/맵을 만들지 않는다.
- 시험 실패해도 게임오버/레벨/장비 손실 없이 재도전. 레벨 달성 후 미진행 중에도 기본 EXP/골드/오프라인 누적은 정지하지 않는다.
- 시험 성공 시 최종 분기 선택을 **재확인**(되돌릴 수 없는 직업 계보 선택), 서버 트랜잭션으로 반영하고 고유 스킬·시각 효과·명칭/패시브 해금.
- 온라인 접속 2배는 **전직에 필요한 기본 사냥 시간**만 줄인다. 개인 이벤트 성공을 자동으로 대신하지는 않는다. 이벤트는 짧고 재도전 가능해 3.5일 목표를 쓸데없이 막지 않게.

### 5-2. 전직 3단계별 '감정적 보상' (모두 초안)

| 단계 | 요구 예시 | 시험(같은 공동 게이트) | 완수 보상 |
|---|---|---|---|
| 1차 Lv.30 | 해당 직업 계보 기본 숙련 | 자신의 직업 역할로 처치·지원 목표 달성(약 2~5분) | 2개 상위 노선 중 1개, 클래스 전용 새 스킬, 전직 이펙트 |
| 2차 Lv.100 | 기존 계보 1차 분기의 숙련 | 정예의 역할별 카운터 패턴, 동료 도움 가능(약 3~6분) | 상위 2개 중 택1, 기존 기술 진화, 고유 이동/범위기·방어기 |
| 3차 Lv.250 | 2차 계보 숙련 + Lv 조건 | 직업별 시그니처 시련(약 5~10분), 대형/힐러 지원 가능 | 최종 2개 중 택1, 극전직 궁극기, 영구 고유 오라·칭호·채널 축하 |

- **진영별 테마 및 192개 루트 직업별 시험 타입**은 다르게: 조선(무예·신기전·어검), 현대군(전술 표식·정찰·집중 저격), 해병 유니버스(전우 보호/기합), 슬라임(분열·흡수·회복), 용족(브레스/비늘 방어/공중 이동), 닌자(은신·분신·표창), 힐러(실질 유효 치유·버프), 탱커(보호/막아낸 피해).
- 192개 기초 직업 + 상위 2→4→8 분기를 **첫 정식 버전 필수 범위**로 유지. 모든 2,688 상위 노드에 독립된 시그니처 전투 기술/패시브와 적절한 시험 조건이 필요; 공통 전직 시련 엔진은 재사용하되 **이름만 바꾼 이벤트로 대체하지 않는다**.
- 전직 이벤트는 운영자가 일정 시간마다 누르면 진행되는 **정식 공동 보스와 별도**이며, 주기 랜덤 이벤트·보스가 없는 시간에도 플레이어가 직접 시작할 수 있다.
- 전직을 미뤄도 시간이 낭비됐다는 느낌을 줄이기 위해 그간 쌓은 **초과 EXP·골드·스킬 숙련**은 그대로 유지.

## 6. 시간대별 보상 루프 — 숙제 대신 자연스러운 이벤트

| 사이클 | 접속 시 보이는 변화 | 과도한 숙제 방지 |
|---|---|---|
| 매 10~30초 | 골드·경험치, 기본 자동 공격, 자동 착용/판매 | 수동 버튼 클릭 없이 지급 |
| 매 5~10분 | 몬스터 구성 변화, 스킬 숙련도/강화 성과 | 일부 놓쳐도 일반 자동성장 지속 |
| 평균 12~18분 | 게이트 랜덤 이벤트 | 이벤트는 선택적, 기본 성장 차단 없음 |
| 방 입장 후 1시간 | **수동 공동 보스 소환 가능** | 처치 후 정확히 1시간 쿨, 미처치 별도 규칙 |
| Lv.30·100·250 | **영구 직업 분기/시그니처 전직 이벤트** | 계보 고정, 기한 없음, 경험치 정지 없음 |
| 게임 종료 중 | 마지막 활성 캐릭터의 오프라인 ×1 경험치·골드·일반 장비 추첨 | 저장 공간/보상 수령 버튼으로 성장을 끊지 않음 |
| 재접속 시 | 오프라인 누적 결과, 자동 장비 교체·판매 골드, 지난 성장, 새로 가능한 전직/도전 안내 | 수령 버튼 누르지 않아도 서버 정산 확정 |

### '접속할수록 보상감' 연출

- 시작 후 1분/10분/1시간/3시간에 **보상의 성격**이 달라져 보이도록 실시간 EXP 증가·직업 숙련 랭크·희귀 드롭·게이트 이벤트·수동 보스 기회를 화면에 순서대로 보여준다.
- **접속 중 상시 ×2**이므로 별도로 길게 버티는 '연속 출석 스택'을 만들어 접속 끊김에 벌점 주지 않는다.
- 초보는 30/100 전직의 다음 목표가 명확하고, 고레벨은 극전직·전설 장비·시너지·수동 보스에서 지속 성장.
- 친구가 많은 채널은 실제 종족·클래스 패시브와 대형 보너스로 더 강해지지만, 솔로+NPC3명도 목표 기본 곡선에서 이탈하지 않도록 시험.
- 높은 레벨의 캐릭터와 비교·채팅 중에 내 장비가 자동 교체되고 레벨이 오르는 것을 보여주는 **강한 소셜 시각화**에 집중한다.

## 7. 밸런스 경계: 두 배 보상이 게임 경제를 터뜨리지 않게

1. 온라인 기본 ×2가 **경험치/골드/장비 추첨 기회/스킬 숙련**에 적용되나, **수동 보스 1회 보상/이벤트 상자/전직 최초 보상에는 다시 ×2 적용하지 않음**.
2. 같은 시간당 드롭 추첨 기회를 두 배로 주더라도 **전설/신화 한 번 추첨의 확률 자체는 그대로**, 중복 장비는 자동 골드화. 장비는 고유 클래스별 한 가지 최적 선택 자동 적용.
3. 채널 시너지·혼합 레벨 보정·게이트 도전 보너스가 온라인 ×2와 중첩될 때 최종 성장은 시험용 상한/완만한 수익 체감 법칙을 검토. 특히 골드 인플레이션과 랭킹 선점 방지.
4. **고레벨 DPS 하향 평준화 금지**. 고레벨은 화려하고 강하게 보이고 초보는 기본 EXP/장비 기회가 고렙 막타에 지워지지 않음. 개인별 등급/자격을 초과하는 장비는 지급 안 함.
5. 힐러는 실제 지원 기여 또는 3 NPC의 보조가 있는 기본 파밍 기준으로 오프라인에서도 성장. 기본 7d/3.5d 목표를 딜러만 충족하고 힐러가 계속 지연되지 않도록 역할별 기준 EXP 바닥값.
6. 게이트 이벤트 추첨·정식 보스·직업 시험은 모두 **서버 권위 상태/원장**으로 중복 실행 차단. 두 계정/두 브라우저 탭의 동시 이벤트 중복 보상 금지.
7. 가장 높은 난이도에서 1분에 한 마리를 잡는 경우보다 안정 난이도에서 몬스터를 많이 처치하는 편이 유리할 수 있다. **추천 안전 단계**를 UI에 명확히 표기.
8. 레벨·스킬·장비 수치 증가로 장기적으로 클라이언트 안전 정수 범위를 넘지 않도록 서버 저장 자료형/대규모 수치 단위 설계.

## 9. 구현 수락 테스트 (게임 완성 전 필수)

1. 동일 기준 캐릭터 1명 Lv.1부터, **오프라인 ×1 연속 168시간**으로 Lv.250 '3차 전직 자격', **온라인 ×2 연속 84시간**으로 동일 레벨 도달. 1차 Lv.30, 2차 Lv.100 시간 체크포인트도 검사. 오차는 레벨 보정/시뮬레이션 허용 범위 내에서 원인 기록.
2. 하루 온라인 8시간+오프라인 16시간 혼합 누적 시 기본 기준 **5.25일**에 Lv.250 자격. 하루 온라인 4시간이면 **6일**. 프레임별/세션별 보상 중복 없이 시간 통합.
3. 브라우저/모바일 잠자기/접속 끊김: 즉시 보상 날아가지 않고 온라인 인정 종료 후 오프라인 정산으로 계속 성장. PC 완전 종료/7일 이후 재접속에도 보상 소실/인벤 슬롯 제한 없음.
4. 직업 192루트와 2→4→8 분기 트리에서 Lv.30/100/250 이벤트 활성화·미완료 시 EXP 누적·성공 시 독립 고유 상위 직업 선택·잘못된 계보 전직 거부.
5. 랜덤 게이트 이벤트 12종 각 100회 이상 시뮬레이션: 발생 분포, 동시 이벤트 최대1, 보스와 충돌/타이머 조작 없음, 저레벨/힐러도 보상 가능, NPC가 보상 획득하지 않음.
6. 사람이 많은 채널과 1인+도우미3명 채널의 동일 레벨 기준 경험치 편차, 힐러/딜러/탱커 온라인·오프라인 XP 속도 비교.
7. Lv.1×49+Lv.1000×1 혼합채널에서 고렙 광역 원킬이어도 저렙의 유효 기여가 인정되고 시간당 수익이 0이 아님.
8. 같은 기간 온라인 두 기기/부캐 2명 활성화 시도 → **한 계정의 한 캐릭터에만** 연결/사냥·×2 적용, 나머지는 정지.
9. 초고레벨 장비 자동 교체/일반 드롭 2배 추첨/구장비 즉시 매각/전직 성공·아이템 재화/보스 1회 지급 중복 없음.
10. 시뮬레이션 리포트는 분포(최소/중앙값/상위10%), 성장 경계, 배율이 실제 몇 배인지, 서버 계산 비용을 기록하고 그 결과에 따라 **시험값**을 조정할 것.

## 10. 참고 원칙

- 메이플스토리의 단계별 전직과 스킬 진화 구조는 **성취감의 디자인 참고**일 뿐 기존 캐릭터명/퀘스트/아트를 복제하지 않는다.
- 방치형 게임의 오프라인 보상과 진행 단계에 따른 수익 상승 구조는 **성장 루프 참고**. 외부 게임의 과금/오프라인 보관 상한/보상 확률을 그대로 가져오지 않는다.
- 회사 정책 회피/프로그램 숨김이 아니라 PC 저부하 모드 및 서버 오프라인 지속 성장으로 실사용 편의를 제공한다.
