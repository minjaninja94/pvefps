## 3. 이 카드를 실제 이미지 생성 작업으로 바꾸는 절차

1. 시작할 직업 카드 `Fxx-Cy` 선택 → 해당 진영 공통 `idle/walk/run` 규칙 및 **본인 클래스 특유 무기/신체** 마스터 고정.
2. A/B/기본 고유 스킬 스토리보드 각각 **6–8개의 강한 키포즈** 선정. 세 동작은 발 디딤/무기 궤적/중심 이동에서 실제로 다르게 설계.
3. 1모션 4–8컷씩 분할 생성 → 사이를 고유 중간컷으로 리터치·완성 → `A10 + B10 + root_skill10` **최소 30개의 별도 유효 원화**(한 방향) 확보. 이때 body 고유컷/FX컷 별도 계산.
4. 몸/무기/의상/종족 특수 파츠는 동일 `frame_index`와 앵커를 가진 레이어. 원거리면 `projectile_spawn`, 근접이면 `hit_frame`, 지원이면 `heal_applied/buff_applied`를 반드시 지정.
5. idle·walk·run·guard·hurt·knockdown·death·revive·social 등 나머지 공통모션을 제작 규격 하한 이상 완성. **전 모션 합계 프레임이 많다는 이유로 시그니처 A/B를 1~2장으로 축소하면 불합격**.
6. 기초 직업 스프라이트 QA 합격 후만 1차 전직 스킬 생성. 분기별 팔/무기/발접지/타격 연출이 구별되어야 하며 2~7차 모든 상위 직업마다 새 시그니처/상위 기술 추가.
7. 32진영·192 기본클래스 전체와 7차 계보별 매니페스트/원본 해시를 검증하는 자동 CI 검증기를 만든 뒤에만 '모든 클래스 이미지 완성' 보고.

## 4. 고유성 자동검사의 명시적 규칙

- 각 192개 행의 `signature` 설명을 애니메이션 manifest의 `concept_key`/스토리보드/해당 모션 프레임에 연결.
- **동일 클래스 A vs B**: 앞·뒤 키포즈가 같아도 10장 중 전체가 동일한 파일 해시 또는 거의 동일한 실루엣이면 실패. 타격 궤적/정면 실루엣/회복 자세 최소 2종의 명확한 차이를 요구.
- **다른 클래스와 비교**: 예를 들어 조선 궁수·엘프 궁수·유랑예술단의 오리광대는 활을 쓰더라도 손/몸통/발 디딤/활·화살 발동 방식과 시그니처 효과가 분명히 다름. 같은 PNG에 옷만 교체한 경우에는 직업 고유 애니메이션이 아님.
- 똑같은 이펙트, 범용 반복 본모션을 192개 직업 템플릿에 그대로 적용하는 것은 내부 테스트 예외로만 허용. 정식 게임에서는 각 직업의 대표 실루엣과 시그니처 기술이 구분되어야 함.
- **'고유 그림 프레임 수'와 '재생 파일 셀/동일 이미지 반복 수'를 각각 기록**. 시퀀스를 반복해 열두 셀로 늘렸다는 사유로 작업을 완성했다고 보고하지 않는다.

## 5. 신규 1~7차의 누적 고유스킬 애니메이션 규칙

- 기본 클래스 192개는 **A10+B10+기본 액티브10**부터 시작. 초기 모션의 그림 수를 조금 줄이지만 기본 캐릭터 고유성/실루엣/타격 시각은 유지. 나머지 일상 모션도 [제작 규격](./PIXEL_ANIMATION_PRODUCTION_RULES.md)의 최신 하한을 따른다.
- **전직 시마다 고유 액티브 +1개**: 1차12 → 2차16 → 3차20 → 4차24 → 5차30 → 6차36 → 7차48개 *실제 서로 다른 바디 원화*. 총 7개의 새 스킬 그림을 누적 보존하며 초급 기술도 사용 가능.
- 예시: 황룡의 1차 해병수육 `수육 잔향`은 사망→국물 연기→부활 직후의 별도 스킬이며, 부활 패시브는 액티브 1개로 잘못 집계하지 않는다. 2차 각성 공군 `기열 징발`의 동의받은 아군 디버프 표식과 자기 버프 이펙트는 분리.
- 경제·보급·요리 직업도 공격 대신 **계산·조리·감정·체력회복·상품 운반·계약/주판·축제** 모션에 동등한 프레임 수를 적용, 직업별 개성 유지.
- 과거 18/18/30/202 고정치 및 3/5/7차 모두 48장 궁극기 요구는 이제 초기/중기 *일괄 필수*가 아님. 초반 리소스를 절약해 32종×6계보 전체 제작에 집중하고 고차 기술에 더 높은 프레임 예산을 사용한다.
- 이 문서는 **기초 192개 클래스의 설계 카드**다. 1~7차 모든 개별 스킬 ID/최종 9,024계보의 원화 제작 완료를 의미하지 않는다. 스킬 테마/진영별 대표 기술: [FACTION_CLASS_REWORK_2026_11_03.md](./FACTION_CLASS_REWORK_2026_11_03.md).

현재 목표: **192/192 클래스 기획 카드 작성**, 고유 도트 실제 이미지 파일 0/192(아직 미생성).
