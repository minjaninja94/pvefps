## 1. 6개 해병의 기본 고유 액티브 + 1~7차 신규 액티브 총 48개

- 기본 고유 액티브 6개 + (7차×6=42개) = **총 48개 고유 액티브**를 **서로 다른 스킬 ID**로 정의. 모든 캐릭터는 자기 계보에서 초기 1개+전직마다 신규 1개씩 **총 8개 유지**, 기본 공격 A/B·상시 패시브는 별도.
- 각 직업의 **1~3차에 다른 이진 분기 직업도 추가할 수 있는 구조**와 4~7차 내부 전문화 선택 유지. 아래 **6개는 각 루트의 대표 7차 경로**이며 9,024개 직업노드 전수 정의 완료를 의미하지 않는다.
- `기초10→1차12→2차16→3차20→4차24→5차30→6차36→7차48` = **각 신규 스킬의 실제 바디 원화 하한(재생용 복제 제외)**. 공격/검술/요리/회복/마법진과 별도 차량·탄환·FX 모두 독립 레이어. 7차 각 루트별 바디 총 원화는 스킬 단위로 누적됨.
- 특별한 소환물/오도봉고/무톤듀오/전우 카메오는 모두 일회성 화면 효과. **채널 영구 NPC는 기존 필수 도우미3명뿐**. 추가 배치·타워방어·병력 생산·상인 거래는 없다.

- 다크코미디 밈의 배경 설정은 그대로 발췌하지 않고 제작용 독립 설정·자체 도트 실루엣·자체 애니메이션·효과음으로 구현한다.

## 9. 특수 기믹 구현 제약 / UI

### 포신검술·포신포격의 애니메이션

```text
황근출 2차 포신검술 일문자: (기초 바디 16+)
  0~3  무기 장치 전개·몸 중심 낮춤(무장 외형만 보임)
  4~6  오른쪽 횡베기 예고·몸통 회전
  7~8  금속 포신 검날이 타깃과 맞닿음 (server hit marker)
  9~11 관성/옷자락·금속의 반동
  12~15 원위치·무장 접기

황근출 4차 포신포격: (기초 바디 24+)
  준비·총구 전개→3번 발사→탄피·연기·포신 방열→복귀
  projectile_spawn는 각 발사 프레임에 서버 전투 이벤트를 연결

황근출 7차 대기합 포신검무: (기초 바디 48+)
  도끼 예비자세→도끼 내려찍기→포신검 X자 교차→3연 포신발사→돌격 복귀
  3타 단계의 타겟 히트박스·FX/투사체를 별도 트랙으로 처리
```

- **은유적 포신의 원전 의미는 원전 문서로 따로 확인**하되 게임 표현은 **기계식 착탈 확장포/검**, 노출 신체부위/성행위/성적 침해 영상이 아님.
- 포신검술은 단순 타격검 광원과 무기 끝의 정확한 접촉 애니메이션을 담고, 사용자 시점 한 화면의 초급 유저·고급 보스·채팅을 가리면 실패.
- **오도봉고·해병짜장·해병수육**은 실제 소환물·재화 거래·임의 죽음 유발 없이 실루엣/아이템/치유/공격/부활 상태를 바꾸는 **전투 애니메이션 및 서버 유효 효과**.
- 황룡의 부활 조건: `hp==0 && server_respawn_confirmed` 단 한 번만, `cooldown_utc` 필수. **1차 '해병수육' 패시브**와 **신규 액티브 '수육 잔향'** 별개. 2차 각성 공군의 아군 해병 약화 효과는 **명시적 동의 대상에게만** 한시 적용·동의취소 즉시 종료하며, 황룡 자기버프는 상한 적용.
- 정식 1시간 수동 보스/300종 랜덤 게이트/혼합레벨 초보자 보호 시스템과 충돌하지 않음.
- 야전손수잘의 유효 회복/진떡팔의 요리·버프/곽말풍의 상황제어/마철두의 장거리 사격/황근출 전열 보호/황룡 부활 후 반격 모두 **혼자 안전 자동사냥 가능**해야 하며 고위 레이드에서는 서로 다른 기여도가 있어야 한다.

## 10. 검증·레퍼런스 관리

1. 각 6기초루트에서 1~7차 신규 스킬 7개씩 + 기초1개: **총 48/48 고유 스킬ID·실제 효과·도트 모션 정의**, 중복·폐기 없이 서버 성장·스킬 AI 연결.
2. 각 해병 이름·계보/기술 명칭을 [FACTION_ROSTER_32X6.json](./FACTION_ROSTER_32X6.json), [FACTION_CLASS_REWORK_2026_11_03.md](./FACTION_CLASS_REWORK_2026_11_03.md), [CLASS_ANIMATION_192.md](./CLASS_ANIMATION_192.md), [SOCIAL_IDLE_SYSTEM.md](./SOCIAL_IDLE_SYSTEM.md), [PLAN.md](./PLAN.md)와 일치.
