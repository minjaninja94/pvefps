# simsimrpg / Pixel Factory v0.1 — 실행 가능한 도트 자동화 시제품

> **실행 코드 및 기초 5개 유닛테스트 통과. 실제 게임 아트 2,000종이나 던파 수준 고유 원화를 만든 것은 아닙니다.** 이 스크립트는 *간단한 기하학적 절차 생성 픽셀 몬스터*를 출력하는 프로토타입입니다. '서로 다른 PNG 래스터 프레임'과 '작가가 실제 별도 작화한 고유 키포즈'를 절대 혼동하지 마세요.

## 무엇이 자동화되는가

- 기획 파일 `MONSTERS_01_05.json`, `MONSTERS_06_10.json`, `MONSTERS_11_15.json`, `MONSTERS_16_20.json`에서 ID·종족(리그)·등급 읽기.
- 도트 종족 그룹(야수/용/해양, 슬라임/식물/악몽, 곤충/외계, 로봇/증기/유적, 일반 인간형)을 바탕으로 **기하학적인 기본 실루엣과 관절 움직임** 생성.
- 등급별 전체 모션 프레임 생성: 일반 **40** / 특수 **52** / 정예 **80** / 정식 보스 **160**. 한 방향. 원본 기획의 103,600 출력 프레임에 대응.
- PNG 시트 `idle.png`, `walk.png`, `attack_a.png`, `death.png` 등과 `animations.json`, `motion_preview.png` 출력.
- 동일 몬스터·모션·프레임에서 항상 같은 결과가 나오는 SHA256 기반 시드. 10종 팔레트 테스트. **정식 게임에서는 10배 PNG 파일을 만들지 않고 실시간 팔레트 교체** 권장.
- 외부 아티스트/이미지 생성 모델이 만든 **기존 시트 PNG** 가져오기, 그리드 분할, 완전히 동일한 프레임 수/투명도 검사.

## 설치

Python 3.10+ / Pillow 10+:

```sh
python -m pip install Pillow
```

프로젝트 루트가 `pvefps`일 때 다음 예시를 실행합니다.

### 몬스터 하나 생성

```sh
python simsimrpg/art-tools/pixel_factory.py --root simsimrpg --id M01-01-01 --out sprite-preview
```

### 20개 생성, 10번째 팔레트 시험

```sh
python simsimrpg/art-tools/pixel_factory.py --root simsimrpg --limit 20 --palette 10 --out sprite-preview
```

### 2,000개 전체 시제품 생성 (주의: 디스크·시간 사용)

```sh
python simsimrpg/art-tools/pixel_factory.py --root simsimrpg --limit 0 --out sprite-preview
```

**전부 생성한다는 것은 103,600개 절차 포즈를 PNG 시트로 출력한다는 뜻이고, 원화 작가 수준의 103,600컷이 생성된다는 뜻이 아닙니다.** `--limit`를 작은 수로 시험하고 외형/동작/파일 크기를 확인한 후 확장하세요.

### 기존 그림 시트 가져오기

8열×5행의 PNG 예시:

```sh
python simsimrpg/art-tools/pixel_factory.py --import-sheet my-spritesheet.png --cols 8 --rows 5 --out imported-frames
```

각 프레임 PNG와 `qa_report.json` 생성: 전체 셀 수·동일 프레임 수·알파 포함 여부. '원화 고유성'의 의미 있는 동작 차이/무기 정확도/관절·앵커 안정성은 **아직 이 검증기에서 확인하지 못합니다.**

### 자동 테스트

```sh
python -m unittest discover -s simsimrpg/art-tools -p 'test_*.py' -v
```

테스트 대상: 등급별 프레임 예산, 시드 결정성, 모션 차이·팔레트 차이, 등급별 아틀라스 생성, 시트 중복 프레임 인식, 몬스터 ID 중복 감지.

## 실제 고급 도트로 이어질 다음 개발 단계

1. **200개 몬스터 계열 대표 이미지**를 고유 실루엣으로 실제 작화/이미지 생성하여 기준 원화 확정. 현재 프로시저럴 도형을 그대로 정식 2,000종이라고 출시하면 품질이 부족합니다.
2. 종족별 본체·머리·팔·다리·무기·망토·지느러미·촉수와 타격 이펙트 분리 레이어. **공격 4~8개 키포즈를 실제 이미지로 고정**하고 움직임 그래프 구성.
3. 파츠 리그/픽셀 스냅/포즈 보간으로 많은 중간 **재생 프레임을 자동 생성**하되 '직접 그린 독립 고유 원화 수'는 원본 키포즈만 집계. 보간 프레임을 독립 키포즈로 위장하지 않음.
4. 모션별 서버 `hit_frame`/`projectile_spawn`/`heal_applied`/상태이상 발생시점 계약과 화면의 히트박스 동기화.
5. 프레임 유사도·발 접지 흔들림·손/무기 부착점·머리 실루엣·비대칭 반전·몸체 변형 자동검사. 실패 프레임은 **아티스트 리터치/이미지 생성 배치**로 돌림.
6. 런타임 팔레트 10종×기초 몬스터 2,000종 = 표시 외형 20,000종. 실제 인게임 데이터/네트워크가 연결되는 것은 별도 구현.
7. 50인 공동 게이트에서 드로우콜·텍스처 lazy-load·모바일 기기·스킬 VFX·채팅 가독성 검증, 보스/정예/약체 혼합레벨 테스트.

## 변경 범위

`simsimrpg/art-tools/`에만 시제품 소스·테스트·사용법을 추가. **다른 게임(desert-strike 등), Supabase, 배포 사이트, 실제 게임 전투 코드는 변경하지 않았습니다.** 자동 생성 이미지가 Git 저장소에 저장되거나 푸시되지 않습니다. 별도의 `--out` 폴더에 저장되며, 품질 검수 후 승인된 아트만 따로 커밋할 계획입니다.
