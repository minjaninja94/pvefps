**문서상 E001–E300 전부 다른 이름과 일차 메커니즘/목표를 기재**한다. 단순 색깔 변경 300개나 프로그래밍상 같은 보상상자를 300번 반복한 목록으로 쓰지 않는다. 종족별 스킬/피해계수/몬스터 AI/VFX까지 진짜 완전히 다른 이벤트로 실행하려면 별도의 구현과 밸런스 검증이 필요하며, **현재는 기획 데이터의 전수 작성 단계**다.

## 1-A. 희귀 이벤트 E120: 한물간 밈의 습격

- **밈연합은 플레이어 진영에서 삭제**하고, 32번째 플레이어 진영을 **시간관리국**으로 대체. 밈·트랄랄레로·사후르·크로코딜로 유형은 적 전용 이벤트 NPC로만 제작.
- 원래 E120의 '고장 난 타임라인'을 삭제하고 **E120 이벤트 한 종을 교체**했으므로 **300종 유지(301종 아님)**. 희귀도 가중치를 낮게 설정하여 아주 가끔 등장하는 코믹 전투로 운영.
- 단계: **잊힌 밈 약체 습격 → 박자 공격/악어 비행 폭격 정예 → 전원 처치 또는 제한시간 후 퇴장**. 한 물리 게이트/개별 몬스터 공격 전조/후열 신입 안전/유효 역할 기여 보상.
- 이벤트 정예는 1시간 수동 보스가 아니며 보스 쿨/HP/특별 보상을 건드리지 않는다. 진행 중 수동 보스가 소환되면 이벤트 일시 중단 및 보상 진행도 보존.
- 상세 스폰·적 AI·보상·애니메이션·권리 검토: [MEME_INVASION_EVENT.md](./MEME_INVASION_EVENT.md).

## 2. 이벤트 시간·등장·희소성 제어(시험값)

- 채널 평균 이벤트 간격 **12–18분**, 채널당 동시 위험 이벤트 최대 **1개**. 이벤트 진행 약 30초~3분. 많은 사람이 함께 보는 소셜 연출이라 과도하게 빠른 이벤트 교체를 피한다.
- 이벤트 발생은 실제 방/서버타임 기준이며 접속자마다 다른 게이트/다른 이벤트가 보이는 **개별 인스턴스 금지**. 서버에서 동일 이벤트 ID, 스폰 패턴, 남은 시간을 전원에게 전파.
- 300개를 모두 균등확률로 매번 추첨하는 방식 지양. **20계열 먼저 선택 → 계열 내 아직 덜 본 이벤트에 가중치 → 유저 역할/진영/안정 사냥 단계에 맞는 안전 대체형 선택**.
- 분포 시험안: 일반 55%, 특수 30%, 희귀 12%, 초희귀 3% (이 값은 **이벤트 등급 빈도**로, 장비 획득 확률이 아님). 같은 이벤트는 최소 최근 **20회 동안 재등장 가중치 0~낮음**, 같은 계열 3연속 금지.
- 채널이 1명뿐이거나 초보/힐러만 있는 경우 치유/기초 방어/약체/축제 이벤트 우선. 고렙이 대거 모이면 정예/대형 협력 이벤트 비중을 높이되 새로 합류한 초보에게 고급 적 어그로를 허용하지 않는다.
- 3막 연속 사건(E286~E300)은 이전 장면을 본 유저에겐 연속 진행으로 보상 기록을 주되 **도중 입장한 유저도 중간 막에서 참여 가능**하고 절대 과거 막을 놓쳤다는 이유로 영구 성장 손실이 발생하지 않음.
- 보상은 개인 최고 적정 난이도·유효 공격/방어/치유/버프 기여에 따라 지급. **막타 독식 금지, 고레벨 버스 보상 제한, 초급 안전참여 보상 제공**.
- 이벤트 보상은 **서버 추가 보상 원장**으로 지급하여 일반 온라인 기본 사냥 ×2가 이벤트 상자/보스/전직에 두 번 적용되지 않도록 한다.
- 정식 1시간 수동 보스와 다르게 **이벤트 정예**는 별도 전직/보스 쿨다운·정식 보스 HP/특별 보상 자격을 소모하지 않는다.

## 3. 정식 보스·전직 시련·이벤트 겹침

| 겹친 상황 | 서버 우선순위 | 초보자·보상 처리 |
|---|---|---|
| 일반 웨이브 중 무작위 이벤트 | 위험 이벤트 1종 동작 | 기존 초급·고급 몬스터 혼합에서 안전 후열 유지 |
| 위험 이벤트 진행 중 수동 공동 보스 소환 | **수동 보스 우선**. 이벤트의 적 스폰 멈춤, 진척 저장 | 보스 종료 후 이벤트 재개 또는 기여도만큼 기본 보상, 손실 없음 |
| 이미 진행 중인 보스에 신규 Lv.1 입장 | 보스 진행은 그대로, 입장자 후열 보호관전 | 보스 HP 실시간 재계산 없음, 강제 사망 없음, 기본 온라인 ×2 정산 |
| 보스전에서 Lv.1이 견습 참전 선택 | 같은 화면의 약체 보조/치유만 가능 | 개인 단계 초급 보상, 고위 보스 장비/보상 0 |
| 전직 시련 중 수동 보스 소환 | 개인 전직 진척 저장·일시중단, 보스 종료 후 재개 | 계보/분기 선택 초기화 금지, XP·장비 소실 없음 |
| 정식 보스 처치 시 랜덤 이벤트 예비 예약 | 보스 처치시간+60분의 정식 쿨만 갱신 | 랜덤 이벤트 큐는 독립, 개인/채널 누적 수익 중복 없음 |
| 이벤트 도중 50번째 신규유저 입장 | 이벤트 시작 스냅샷으로 적 HP/공격력 유지 | 새 유저의 적정 보조 역할만 추가, 난이도 즉시 재증폭 금지 |

**중요**: 보스는 방 입장 후 60분 조건을 충족한 온라인 유저가 수동으로 소환하고, 처치 이후부터 다시 60분 대기한다. 이벤트를 300종 늘렸다는 이유로 보스가 자동으로 나오거나 이벤트 정예가 정식 보스 자격을 강제로 소모하지 않는다.

## 4. 방치형 RPG답게 기본 보상은 끊기지 않는다

- 실접속 온라인이면 일반 자동사냥 EXP·골드·기본 장비 추첨·스킬 숙련 **×2**. 오프라인/앱 종료 시 마지막 활성 1캐릭터만 계속 **×1**, 기간 경과에 따른 감쇠 없음.
- 랜덤 이벤트 300종 가운데 일부는 선택형 위험/희귀 이벤트지만 **정기적 터치/대기 화면/강제 선택**으로 기본 자동 사냥이나 전직 XP를 멈추지 않는다.
- 채널 위험 이벤트가 평상시 사냥보다 많이 비효율적이면 기본 수익을 보장해 불운한 이벤트 출현이 실질 패널티가 되지 않도록 한다. 이벤트는 **기본 보상 + 추가 재미/도전/소액 수익**.
- 초보+고렙 혼합 채널에서 일반몹/강화몹/정예몹은 **동일 게이트 하나**에서 구간별로 혼합 등장; 고레벨은 정예/보스 캐리, 초보는 적정 약체 몬스터/지원으로 자신의 성장 유지.
- 지원 힐러·탱커는 방어/치유/실질 버프 기여로 이벤트 보상을 얻고, 3명의 봇은 시너지/개인 랭킹/아이템 보상에서 제외한다.
- 이벤트로 무기·갑옷·장신구가 쏟아져도 **등급 우선 + 동급 더 강한 장비 자동 착용**, 교체·열등 장비 자동 골드화. 수동 장비 정리/거래 강요 금지.
- 특별 이벤트가 주는 단일 보상은 최초 시도 후 시간당 기준 사냥 수익 약 **+5~10% 기대값**부터 시험. 과도한 희귀 골드 뻥튀기/채널 호핑 반복수익을 서버 원장으로 차단.
- 1~7차 전직 계보/스킬 숙련·7차 완만한 성장곡선(7차 온라인기본120일/오프라인기본240일)을 이벤트 참여 여부로 필수 잠금하지 않는다.

## 5. 실제 게임 데이터화에 필요한 300종 공통 필드

- event_id (E001~E300), event_name, category, rarity, risk_tier, mechanic_id, trigger_weight, role_tags, faction_theme_tags, eligibility_stage, allowed_newcomer_mode, novice_variant_id
- spawn_profile, monster_archetype_ids, duration_sec, telegraph_sec, objective_type, objective_target, state_transition, reward_profile_id, gold_cap, xp_cap, item_roll_tier
- visual_effect_refs, audio_refs (직접 제작), server_seed, reward_settlement_id, on_boss_interrupt=pause_and_resume, on_new_player_join=snapshot_preserved, cooldown_id, anti_repeat_window
- 300개를 다른 이벤트로 인정하려면 각 이벤트는 **메커니즘/적 공격 행동/유효 역할/승리 조건 중 최소 하나가 명확히 달라야 함**; 이름과 색만 다르면 구현 검증에서 실패 처리.
- 이번 목록은 최초 등록용 UX/행동 디자인이다. 실제 수치/스폰 테이블/애니메이션/일정 확정과 테스트 후 **실행 가능한 이벤트**가 된다.

## 6. 구현 검증/품질 게이트

1. E001–E300 누락 없음, 중복 이벤트 ID/이름 없음, ID당 역할·위험도·자체 기믹·개인 보상 계열 존재.
2. 초보·힐러·탱커·고렙으로 각 300개 이벤트를 한 번 이상 시뮬레이션하여 자동 참전/사망 방지/보상 판정을 점검.
3. 1레벨 초보가 고렙 49명 보스 중 입장해도 처음 1분 강제 사망 0, 같은 화면에서 3봇 및 고렙 기술 관전, 개인 ×2 기본 정산 정상.
4. 이벤트 중 보스 수동 소환/처치, 채널 이동/게임 종료, 캐릭터 교체/네트워크 재접속으로 타이머/보상 중복·손실 없음.
5. 정예/혼합웨이브/랜덤 이벤트 공격력은 초보 관전자까지 무조건 1타 킬할 수 없는 타깃 로직.
6. 직업 32진영·192루트·1~7차 상위 직업의 적정 스킬/마스터리/유효 기여 차등 반영.
7. 1~50명 동시 플레이 시 렌더링 스폰 상한, 이벤트 평균 빈도, 서버 이벤트당 CPU/DB 쓰기/보상 원장 비용 측정.
8. 전종류가 **정식 공동 보스가 아니라는 점**, 일반 게이트 몬스터와 보상을 섞어 중복 지급하지 않는 점 확인.
