- 외부 게임 수치나 소환 확률을 그대로 베끼지 않는다.

## 2. 불변 공간 조건

- 채널당 **공동 물리 게이트 하나**. 몬스터·이벤트·수동 공동 보스 모두 그곳에서 나온다. 별도 저렙 인스턴스, 개인 게이트/사냥터, 별도 보스방 없음.
- 유저들은 전열 탱커, 중열 근접·원거리, 후열 마법·힐러, 측면 기동 진형. NPC 도우미 탱커/힐러/딜러 **항상 3명** 존재하나 유저수/종족/클래스 시너지에는 추가하지 않음.
- 같은 채널에 Lv.1 신참과 Lv.1100 전설직업이 함께 있어도 고렙의 전투력/오라/궁극기는 유지. 저렙은 출현한 모든 고렙 몬스터의 타깃이 되지 않음.
- 보스는 **실제 HP 한 줄/본체 한 개**, 채널의 몬스터 스폰도 하나의 서버 큐. 각 유저에게 별도의 보스 HP를 숨겨 제공하면 안 된다.

## 3. 체력·자동부활·보호 포지션

| 상황 | HP 및 피격 규칙 | 실패 처리 |
|---|---|---|
| 일반 적정 몬스터 | 모든 클래스 실제 HP·피해·방어·자연 회복 | HP 0 → 자동부활(시험값 5초), EXP/골드/장비 손실 없음 |
| 강화 정예 | 전열 고렙·탱커 우선 어그로, 초보 후열은 공격 대상 우선순위 하향 | 반복 쓰러지면 후열 안전 위치로 자동 후퇴 |
| 이벤트 강적 | 처음 입장 보호/관전 상태는 공격 타깃 제외 | 해당 이벤트에서 강제 사망 없음 |
| 정식 공동 보스 | 기존 참전자는 실제 강력한 패턴·피해를 받음, **새 참가자 안전 관전은 본체 공격/피격 대상 제외** | 보스 실패해도 게임오버 없고 안정 웨이브 복귀 |
| 입장 직후 | **후열 안전구역**, 진입 보호 시험 90초 | 보호 해제 전에 전열 강제 배치 금지 |
| 반복 사망 | 예시: 90초 이내 세 번 쓰러지면 자동 보호 포지션 후퇴 | 장비와 경험치·골드 잃지 않음 |

- 보스/정예 시각 효과는 모든 유저에게 보이지만 보호 위치의 방벽이 실제 범위 공격을 막는다. 동일 화면의 실제 공간 보호 장치다.
- 초보가 입장 직후 공격/힐 애니메이션을 체험할 수 있도록 안전 구역의 일반 적정 약체 몬스터를 우선 타깃으로 삼는다.
- 관전 보호는 보스 전열 무적탱킹을 의미하지 않는다. 보호 상태는 보스에게 어그로/강력 CC/대미지 기여를 적용할 수 없음.

## 4. 초고렙 보스가 이미 떠 있을 때 Lv.1의 구체적인 처리

1. 서버가 Lv.1의 채널 진입을 수락하자 **뒷줄 신규자 보호 상태**로 등장. 보스의 광역기/돌진/즉사 타깃에서 제외. 현재 보스 레벨, HP, 전투 연출은 그대로 보임.
2. 첫 화면에는 **보스 전투 중 / 안전 관전 / 견습 지원하기** 표시. 초보자 기본 채팅·프로필·자기 적정 성장 보상은 정상.
3. 초보가 선택하지 않으면 관전 유지. 고렙이 정예/보스를 처치하는 모습을 보아도 특별 보스 보상은 받지 않음. 대신 온라인 기본 사냥 정산 ×2는 유지하고 보스 시간대에 같은 보상을 중복 지급하지 않음.
4. 초보가 **견습 지원**을 누르면 동일한 전장 후열에서 약체 보조적·실제 유효 힐/버프·방벽 수리에 참여. 이 행동은 보스의 본체 고급 DPS/어그로 계산에 포함되지 않아 보스에게 혼자서 고위 디버프를 중첩할 수 없음.
5. 견습 참전자의 보상은 자기 적정 스테이지의 EXP/골드/초급 장비와 소액 참여 보상. 고급 보스 신화 장비·최고 티어 골드는 불가능.
6. 입장과 동시에 보스 체력/스케일 **재계산 금지**. 소환 순간 참가자 전력 분포 스냅샷을 사용하여 한 HP를 끝까지 유지. 보스 이후 일반 웨이브에서는 새 인원을 다음 스폰 사이클부터 반영.
7. **보스 소환 버튼**은 입장 60분을 채운 온라인 유저에게만 활성. 기존 보스를 구경하거나 견습 지원하는 것은 즉시 가능. 이미 잡은 공동 보스는 처치한 시각부터 채널 전체 60분 쿨. 이탈/다른 채널 호핑으로 개인 보상 반복 획득 금지.
8. 견습 보호 단계에서 의도적으로 체력을 소모하여 무한 힐 점수를 수확하거나 기본 종족·클래스 시너지를 여러 계정으로 부풀리지 못하도록 실제 활동·계정당 활성 1명·유효 기여 검증.

## 5. 하나의 게이트에서 혼합 적 스폰

- 참가자 전투력(기초 레벨만이 아니라 장비/직업/스킬/개인 도달 단계) 분포를 **초급·중급·고급 밴드**로 분류하여 채널 일반/강화/정예 몬스터 비율을 결정. 채널 최고레벨 1명만으로 모든 몹 공격력/HP를 정하지 않음.
- 약체는 저·중렙을 대상으로 적정 HP/공격력을 사용, 정예는 고렙 전열·탱커를 우선 공략한다. 물리 몬스터는 같은 공간에 공존하고 서로 공격할 수 있음.
- **3도우미**는 최소 안전망: 방패봇이 전열 어그로 일부를 받고 치유봇이 가벼운 회복, 공격봇이 적정 일반 몹을 처치. 보스가 강해지면 실제 유저 힐러/탱커의 필요성이 높아짐.
- 고렙의 광역기가 약체를 원킬할 수 있어도 저렙이 의도한 유효 공격/치유가 선처리됐으면 막타 독점으로 기본 EXP가 0이 되지 않도록 서버 크레딧 예약/개인 안전 사냥 보장.
- 고렙이 초급 몹만 때려 최고 티어 장비를 파밍하는 것도 막는다. 같은 적을 잡더라도 개인 도달단계와 유효 행동에 맞춘 별도 추첨 테이블을 사용한다.
- 일부 신참/힐러가 관전하더라도 채널 시너지 유령 인원으로 계산하지 않음. **실제 참전자만** 1계정 1스택, NPC/부캐/관전자 제외.

## 6. 보스 실제 HP·피해·보상 설계

- **보스 소환 시** 서버가 현재 실제 참전자 유효 화력·탱킹·지원·현재 게이트 티어를 스냅샷해 보스 HP와 패턴 난이도를 결정. 뒤늦게 들어온 Lv.1이 HP를 바꾸지 않는다.
- 시험 목표 전투시간 **60~120초**. 고레벨 유저의 강한 딜과 화려한 공격을 숨기지 않되, 페이즈 전환에는 보이는 방패 게이지·짧은 연출(시험 6~8초)을 두어 초보도 보스를 보는 시간이 있고 반격/힐러 타이밍이 생긴다.
- HP는 진짜로 하나이며 레벨별 **다른 본체 HP 바를 숨겨 렌더링하지 않는다**. 과잉 피해를 처리할 때 몰래 숫자를 잘라내지 말고 명시적인 실드/페이즈 기믹으로 표시한다.
- 전열 공격/후열 견제/광역기의 역할은 존재하지만 신규 관전자는 피격 대상이 아님. 견습 참전자는 보스 본체 직접 어그로를 거의 만들 수 없으며, 위험 부수 적의 피해에는 초보 보호막(시험: 한 타 최대HP 12%, 10초 누적 최대HP 25%)을 표시 적용. 봇 치유와 같이 보호를 거듭해 고위 보스 보상을 얻을 수는 없다.
- 개인 보상 = **개인 레벨/최고 적정 단계/보스 기여(딜·방어·유효 힐·유효 버프·참전 시간)** 기반. 관전은 특별보상 0, 견습은 적정 초급 보상, 고급 보상은 개인 적정 티어와 유효 기여를 모두 충족해야 함.
- 수동 보스의 큰 EXP/골드/고급 장비 특별 보상은 일반 온라인 ×2 배율을 **다시 곱하지 않음**. 중복 지급 방지 원장 사용.
- 채널 이동 반복으로 한 시간 내 여러 보스 특별 보상을 얻지 못하도록 **개인 글로벌 보상 쿨다운**도 별도로 설계한다.
- 혼합 레벨 유저에 상관없이 입장/게임오버로 레벨·아이템/숙련도가 초기화되지 않는다.

## 7. 300종 게이트 이벤트와 보스 이벤트 충돌 방지

**이벤트 우선순위**: 정식 공동 보스(수동) > 진행 중인 전직 시련의 기록 보존(전투 소환은 연기) > 위험 랜덤 이벤트 > 비전투 축제 > 일반 웨이브.

- 300종에는 일반·강화·정예·경보·보호·미니 정예·보물·수수께끼 등 다양한 게이트 사건을 넣지만, **정식 1시간 보스는 300종 중 하나로 뽑지 않는다**.
- 위험 랜덤 이벤트 도중 유저가 정식 보스를 수동 소환하면 이벤트 소환 중단 → 시각적인 게이트 봉인 → 참가자 이벤트 진척도/추첨 횟수/소액 보상 저장 → 보스 종료 후 안전하게 재개 또는 동등한 기본 보상 자동정산.
- 전직 시련 중 수동 보스가 시작하면 개인 시련 상태는 저장/일시 중단. 시련은 보스 후 같은 화면에서 재개하며 실패나 분기 선택 취소로 처리하지 않음.
- **이벤트와 정식 보스가 같은 순간 처음 입장한 Lv.1을 공격하지 않음**. 후열 보호/안전 관전 우선, 위험 이벤트의 상급 공격과 보스 본체 어그로에서 제외.
- 평균 12~18분에 1회 이벤트 발생 시험안. 채널별 위험 이벤트는 **동시 1개**. 전직 등 특수 연출/비전투 안내는 작은 UI만 겹칠 수 있으나 몬스터 스폰은 중첩 금지.
- 위험 이벤트 시작 후 입장한 유저 때문에 이벤트 몬스터 HP를 실시간 증폭하지 않음. 이벤트마다 시작 순간 참가자 구성 스냅샷 고정.
- **전직 이벤트와 랜덤 이벤트가 정식 공동 보스의 입장 60분/처치 후 60분 타이머를 조작하지 못하게** 서버 상태 머신 분리.
- 이벤트 발생 후 신규유저에게는 초보자용 보상/참여 선택을 제공하지만 고급 이벤트 보상·최상위 장비 편승은 불가.

## 8. 온라인 ×2, 오프라인 ×1과 기여의 결합

- 모든 캐릭터가 자신만의 **안전 사냥 단계(이력)**를 갖되 *물리 게이트는 하나*, 적정 몬스터는 함께 나온다. 서버의 기본 사냥 보상은 개인의 기준 진행도·안전 난이도·장비 성장에 따라 계산.
- 실제 온라인 연결 상태에만 기본 EXP·골드·일반 장비 추첨 기회·숙련도 ×2, 접속 종료시 활성 캐릭터 한 명만 오프라인 ×1 정산. 모바일 절전 시 정상 연결이 끊기면 ×1로 전환.
- 안전 관전자나 초보 보호 입장자는 기본 ×2 정산을 유지하되 **정식 보스 특별보상/랜덤 고급 보상은 받지 못함**. 같은 시간 일반 사냥 기본 보상을 두 번 주지 않는다.
- 1~7차 성장 시험 기준은 3차 Lv.250 오프라인7일/온라인3.5일, 7차 Lv.1100 오프라인240일/온라인120일. 실제 시너지/게이트 단계/이벤트 보너스가 추가되면 단축 가능하므로 기본선/실전 중앙값 별도 확인.
- 힐러/탱커는 실질 보호/회복/방어·상태해제 등의 효과로 실제 기여 인정, 혼자 있을 때는 봇3명의 일반 전투/지원 수련으로 기본 성장 정지 없음.

## 9. 서버 데이터와 수락 테스트

데이터 예시: channel_gate(채널별 1게이트/웨이브), actor_combat_band(유저별 위험도), channel_formation(전·중·후열/안전구역), join_protection(캐릭터별 입장 시각/상태), raid_boss_snapshot(한 HP/참가자 전력/소환 시각), raid_contribution(딜/유효힐/방어/버프), event_instance(300 ID/스냅샷/상태/진척), reward_ledger(원천 별 단일 지급 ID), active_character_per_account(계정당 1명).

### 구현 수락 테스트

1. **49명 Lv.1100의 보스전 중 Lv.1 첫 입장**: 같은 화면 후열 안전 등장, 강제 사망 0, 보스 HP 갑자기 증감 0, 소환/보상 쿨 리셋 0.
2. Lv.1은 실제 고렙의 기술을 관전하고, 선택적으로 견습 임무를 수행해 자기 레벨에 맞는 초급 보상 획득. **신화 장비 버스 0**.
3. 49명 Lv.1에 Lv.1100 1명 입장, 반대 구성 모두 테스트: 저렙 몹과 정예 몹 혼합, 고렙 시각적 캐리, 초보의 기본 EXP/아이템 기회 소멸 0.
4. 채널 1인 힐러+NPC3명, 혼합 클래스 50인, 고렙 단독+NPC3명에서 HP/부활 시간·탱커/힐러 효과 테스트.
5. 채널 입장 60분 후 수동 소환, **보스를 처치한 순간부터** 60분 잠금. 미처치/랜덤 이벤트/전직 시련은 해당 타이머 재시작 금지.
6. 300종 이벤트와 진행 중 보스가 부딪히면 이벤트 보상·개인 전직 진척·시너지 적립이 중복/소실되지 않음.

8. 튜토리얼 신참은 **입장 30초 내 기본 보상**, 2분 내 자기 몬스터 처치/지원, 원하지 않는 강제 보스 참전/즉사 0을 목표로 설계.
9. 고렙 DPS를 임의로 레벨 평준화하지 않고 정식 보스의 공유 한 HP·단일 서버 스폰을 유지.
