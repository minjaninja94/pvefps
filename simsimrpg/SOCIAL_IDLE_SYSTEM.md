## 1. 한 채널 = 친목방 + 개인 게이트별 몬스터 + 공동 보스

- **확정 요구**: 유저들은 동일 채널, 동일 화면에서 채팅·이동·기본 자동 사냥·힐/버프/딜을 수행한다. 개인별 별도 맵/방/던전으로 쪼개지 않는다.
- **확정 요구**: 각 유저는 한 화면의 **게이트** 버튼에서 자신의 **일반 몬스터 소환 ON/OFF 체크**를 선택한다. 이 게이트가 현재 채널에 공급하는 몬스터 수는 각 계정의 '활성 캐릭터 1명'에만 연결된다. *실제 캐릭터/유닛을 소환하거나 합성하는 기능이 아님*.
- **확정 요구**: 힐러/지원 클래스는 자신의 게이트를 OFF로 두고도 다른 유저가 소환한 몬스터와 싸우는 동료를 지원하며 성장 가능해야 한다. 지원 클래스가 반드시 혼자 솔로 몬스터를 처치해야 보상을 받도록 만들지 않는다.
- 모든 게이트의 몹은 **한 공간에 가시적으로 합쳐져 출현**하고 다른 유저도 공격할 수 있다. 특정 유저의 '개인 몹'은 다른 방에 따로 있는 것이 아니라, **생성 기여자/난이도/보상 계산 출처를 식별하는 태그가 붙은 공용 몬스터**다.
- 게이트 OFF는 자신의 일반 몬스터 **추가 공급만 중단**한다. 자신의 클래스 자동 공격·힐·버프·시너지·공동 보스 지원은 계속된다.
- **게이트 패널(화면을 떠나지 않는 팝업)**: [ ] 내 일반 몬스터 소환, [현재 개인 안전 단계], [도전 단계 선택], [도전 시작/중단], [몬스터 미리보기], [보스 소환 가능/남은 시간]. 채널/채팅창은 계속 표시.
- **설계 제안값**: 개인 게이트당 8초마다 몬스터 최대 3기 공급, 공용 화면에는 총 80마리 상한/클러스터 렌더(부하에 따른 수치 조절). 유저 50명이 모두 ON이라도 150마리를 한꺼번에 렌더링하지 않도록 스폰 속도·생존 수를 동적으로 제한한다. 스폰 처리량만 낮추고 해당 유저의 사냥 기회/보상률을 불리하게 하지 않는다.
- 채널 자동 매칭은 취향·레벨 범위와 친구 우선, 단 **고렙과 저렙이 같은 화면에 공존할 수 있어야 함**.

## 2. 전체 종족별 + 클래스별 + 인원별 **중첩 패시브 시너지**

### 2-1. 확정 규칙

1. 채널 내 서로 다른 **활성 계정 수**에 비례하는 **채널 인원 시너지**.
2. 각 **32개 진영(종족)별**로 현재 채널에 속한 해당 진영 인원 수를 세어 **종족 고유 패시브 중첩**.
3. 각 **192개 루트 클래스별**로 해당 계보 선택 인원 수를 세어 **클래스 고유 패시브 중첩**; 상위 전직은 루트 클래스 패시브를 계승하고 **현재 전직 경로 전용 패시브를 추가**해 세부 전문직의 존재감도 드러낸다.
4. 같은 진영/같은 클래스 유저가 여러 명 모이면 실제 중첩된다. 서로 다른 진영·클래스 시너지 역시 동시에 발동한다. **소환 OFF 힐러도 멤버로 계산**하고 이들의 치유/버프 기여를 보상 인정한다.
5. **계정당 오직 1명**만 시너지 인원수에 반영한다. 한 사람이 부캐를 수십 개 만들거나 둘 이상의 탭을 켜도 인원 중복 불가.
6. 세부 시너지 내용은 채널 패널의 **'현재 시너지'** 탭에서 종족/직업별 인원수, 중첩 횟수, 현재 배율, 본인이 제공하는 버프를 투명하게 확인.
7. 잠수 유령으로 시너지를 부풀리지 않도록 채널 실시간 접속자에 대한 계수는 **실제 연결 중인 서로 다른 계정** 중심으로 계산한다. **설계 제안값**: 일시적 네트워크 끊김 90초 유예. 그 이후 오프라인으로 전환되면 시너지 인원에는 포함하지 않으나 캐릭터 서버 사냥은 계속 정산한다. 오프라인 잔상/대표 표시 여부와 시너지 계산은 구분.

### 2-2. 시험용 수치: 중첩되지만 무한 폭증 방지

| 카테고리 | 예시 공식 | 비고 |
|---|---|---|
| 채널 인원 공통 | `+0.5% × min(N-1, 20)` | 1인 0%, 21인 이상 +10%; 같은 계정 중복 없음 |
| 각 진영 고유 시너지 | 해당 진영 1~5인 각 +0.6%, 6~15인 각 +0.2% | 같은 진영 15인 이상 +5% 상한; 다른 종족 효과와 동시에 활성 |
| 각 기본 클래스 고유 시너지 | 해당 클래스 1~5인 각 +0.35%, 6~15인 각 +0.1% | 같은 루트 15인 이상 +2.75%; 진영 패시브와 중첩 |
| 상위 전직 전문 패시브 | 같은 **현재 전직 노드** 당 0.15%, 10인 상한 | 상위전직 개성/해당 파티 전문화 보너스 |
| 전체 공격·성장 보너스 | 각종 출처 중첩 후 카테고리별 감쇠 및 **유효 사냥 보상 상한 검증** | 임시 목표: 동등 전투력 비교 시 소셜 추가 수익 +0~30% 내외 |

- 표의 +%는 해당 패시브가 지정한 **효과 지표**에 적용. 회복/방어 버프와 공격/골드 버프의 수치는 동일 가치가 아니므로 실제 밸런스는 효과별 가중치로 조정.
- 여러 종류를 중첩하되 고정된 버프순서, 라운딩, 최종 배율 상한 정의. 공격 스킬이 연쇄로 계속 소환되어 처리량 폭증하지 않도록 타격 이벤트 상한/쿨타임/확률 적용.
- **인원 시너지에 출석만으로 무한 골드를 지급하지 않는다.** 경험치·골드는 실제 공용 사냥·지원 행동/오프라인 정산에서 별도 산정.
- 혼자 있으면 소셜 시너지 보너스 0이지만, 힐러를 포함해 **기본 성장 루프 자체는 막히지 않게** 설계.

## 3. 힐러·지원 직업의 경험치/전리품 인정

- 자신의 게이트 OFF인 성직자·무당·치유천사·의무병·치유 슬라임 등도 타인 몬스터에게 **힐·보호막·해제·버프·약화·전투 지원**을 제공하면 지원 기여도 획득.
- 지원 기여 지표: 실제 잃은 HP를 회복한 유효 치유량(과잉힐 제외), 막은 유효 피해량, 타인의 공격 성공에 기여한 버프의 추가 피해, 적에게 적용한 디버프에 따른 피해 증가, 적 처치에 연결된 유효 지원 시간.
- 사냥 보상은 `개인 게이트 전투 기여 + 공용 지원 기여`에 따라 산정하되 **동등 시간대에 적정 난이도에서 기여한 힐러와 딜러의 목표 보상 차이를 ±10% 안에서 맞추는 시험안**으로 시작한다.
- 힐/버프 스킬을 목표물 없이 난사해 보상을 받는 농사(무의미 힐 반복)를 방지하기 위해 **유효 전투 행동만 기여로 인정**.
- 빈 채널에 힐러 혼자 있고 게이트 OFF인 경우: 온라인에서는 **안전 수련** 모드로 최소 기본 성장(제안 50~70% 효율)을 제공, 또는 선택적으로 자기 게이트 ON/저난도 연습 몹으로 성장 가능. **협동 파티원이 없어서 영구 성장 자체가 막히지 않아야 함**.
- 오프라인 힐러는 실시간 채널의 실제 다른 플레이어 체력을 계산하지 않고, 해당 클래스에 마련한 **개인 사냥/지원 수련 기준 수익**으로 서버 정산한다. 이를 통해 '타인 의존형 클래스라 로그아웃하면 0 성장' 상황을 방지.
- 지원직은 필요한 레벨에서 협동에 확실한 기여(보호막/생존/전투 효율) 가능하게 설계하되, 몬스터 수익을 부풀리는 무한 생존/무적 루프는 막는다.

## 4. 개인 게이트의 사냥 난이도 올리기(접속 중)

- 각 캐릭터에 `highest_cleared_stage`, `stable_farm_stage`, `challenge_stage` 보관. **채널 공통 웨이브와 개인 도전 난이도는 서로 다른 값**이고 맵은 여전히 하나다.
- 기본 상태: 마지막 안정 단계 몬스터를 일반 자동 사냥. 게이트에서 **'상위 단계 도전'** 선택 시 몬스터의 HP·공격력·패턴이 강해진다. 성공하면 개인 최고 난이도/안정 사냥 단계가 상승한다.
- 다른 사람도 같은 공간에서 도우며 공격 가능하지만 난이도 도전 판정에는 대상 유저의 유효 기여/지원 보정이 필요. 고렙 친구가 초보자 스테이지를 순간이동식으로 최고 구간까지 밀어주는 악용 방지.
- 도전에 실패해도 **게임오버나 사냥 종료 없음**. 마지막 안정 단계의 개인 게이트로 돌아와 계속 사냥하고 다시 도전 가능.
- 자기 게이트 OFF인 힐러도 **협동 지원 도전**으로 개인 최고 단계 승급 가능(클래스별 유효 지원 기준 달성). 혼자 있을 때는 저난도 수련 단계 도전 가능. 소환 OFF 자체는 개인 자동사냥을 OFF하는 기능이 아님.
- **시험용 스케일** (구간별 로그/곡선 및 장기 인플레이션 검사 필요):
  - 일반 몬스터 HP: `HP0 × 1.12^(stage-1)`
  - 몬스터 공격력: `ATK0 × 1.09^(stage-1)`
  - 획득 경험치: `EXP0 × 1.06^(stage-1)`
  - 일반 골드: `GOLD0 × 1.06^(stage-1)`
  - 전설 이상 확률: 스테이지마다 고정 배율 폭증 금지; 구간별 제한적인 난이도/보상 테이블 해금.
  - 기준: 레벨·장비·상위전직 성장으로 안정적으로 스테이지를 조금씩 밀지만, 고난도 무한 러시의 효율은 오히려 떨어질 수 있으므로 **시간당 유효 사냥 수익**으로 최적 구간 산정.
- '내 게이트 몹 소환' 체크와 '도전' 버튼은 다른 기능: OFF 상태에서 보스/지원과 채팅만 즐기거나, ON 상태에서 자신의 안정 사냥 몬스터를 공급함.
- 각 게이트의 몬스터에는 `owner_account_id`, `owner_character_id`, `stage`, `spawn_id`, `reward_profile` 태그를 두고 화면에서는 하나의 풀에 렌더한다.
- 균형: 모두 소환 ON일 때 몬스터 수와 HP가 지나치게 늘어나 공동 전투가 파괴되지 않도록 **개인별 몬스터 생성량 제한 + 채널 전체 가시 오브젝트 제한**을 병용. 성능이 부족해 드롭/경험치를 임의로 깎지 않게 서버 계산과 시각 표현 분리.

## 5. 수동 소환 공동 보스 — 입장 1시간, 처치 후 다시 1시간

### 5-1. 사용자가 확정한 규칙

1. **방/채널에 들어온 뒤 1시간을 채워야** 수동 소환할 수 있다.
2. 보스는 절대 자동으로 출현하지 않음. '보스 소환' 버튼을 누른 경우에만 그 채널의 같은 화면에 나타난다.
3. 보스를 **처치한 시점부터 다시 1시간 쿨다운**이 시작한다. 1시간 경과 후 다음 수동 소환 가능.
4. 보스는 일반 몬스터보다 **훨씬 많은 보상**을 지급한다. 드롭·골드·경험치·희귀 장비 보상이 핵심.
5. 보스 도전으로 별도 맵을 로딩하지 않으며, 실패해도 게임오버 없음.

### 5-2. 여러 사용자가 방을 공유할 때의 구체 운영안

- **공동 채널 단위 시계**: 채널 생성/최초 유저 입장 때 `room_first_entered_at`을 기록. 첫 소환 가능 시각 = 그 시점 + 60분. 한 번 클리어한 뒤부터는 **`last_boss_defeated_at + 60분`**이 다음 최소 가능 시각.
- **소환을 누르는 유저 자격**: 해당 채널에 유효하게 60분 이상 머문 온라인 유저 중 1명이 수동으로 누르면 소환. 일시적 연결 끊김에 대한 90초 유예를 둘 수 있지만 채널 호핑으로 지난 1시간을 재활용하지 못하게 `channel_joined_at` 기록을 따로 관리.
- **보스 1마리만**: `room_boss_state = waiting | summoned | defeated | retry_wait`; 중복 버튼/동시 클릭에 서버 원자적 잠금.
- 처치 → `last_boss_defeated_at = 서버시간`, 전체 채널 버튼 60분 잠금. **소환 시점이 아니라 처치 시점부터 쿨 시작**.
- 미처치/전멸 시: 게임오버는 없고 시간 초과 시 보스 퇴장. **설계 제안값** 5분 재도전 대기(처치하지 않았으므로 1시간 처치 쿨다운 시작하지 않음). 연속 소환 도배 방지.
- 늦게 입장한 유저도 전투 지원은 할 수 있으나 고급 보상은 **기여 조건 + 방 참여시간 조건**이 필요. 시험값: 소환 이전 10분 참가 혹은 전투 중 유의미 기여 + 개인별 글로벌 보스 보상 쿨타임 60분. 정확한 임계값은 테스트로 조정.
- 새로운 채널로 옮겨도 보스 **개인 고급 보상**을 매번 다시 받을 수 없도록 `account_last_boss_reward_at` / `character_last_boss_reward_at` 등을 서버에서 검사.
- 보스 난이도: 현재 채널에서 실시간 참여 중인 **고유 계정의 유효 전투력과 지원 역할**을 기준으로 체력·위험도를 단계별 조정. 힐러가 많으면 보스가 불사신이 되지 않게 실질 처치 속도에 상한.
- **보스 소환은 수동**, 자동 사냥으로 일반 몬스터만 잡다가 본인이 보스를 놓쳐도 자동 소환/자동 입장은 없음.

### 5-3. 큰 보상에 대한 시험 밸런스

| 보상 | 시작 시험안 | 악용 방지 |
|---|---|---|
| 개인 기본 경험치 | 같은 시간대 일반 자동 사냥 30~60분치 | 최소 기여 인정·보상 쿨 검증 |
| 개인 기본 골드 | 일반 사냥 30~60분치 | 동일 보상 원장 트랜잭션 |
| 장비 드롭 | 동일 난이도 일반 몬스터보다 희귀/상급 장비 확률 높음 | 반드시 클래스 맞춤 자동 착용/자동판매 |
| 보스 첫 처치 | 업적/칭호/최초 1회 특별 보상 | 계정·캐릭터 중복 지급 방지 |
| 힐러·지원 기여 | 실제 치유·버프·방어 등 기여로 딜러와 동등하게 지급 | 오버힐/허위 버프 파밍 방지 |

- 30~60분치, 5분 대기 등은 **확정 수치가 아닌 시험값**. 보스의 크고 뚜렷한 보상은 확정 요구.
- 보상 계산은 개인별 사냥 단계/캐릭터 레벨에 맞춰 과한 초보자 버스 수익·고렙 쏠림 방지.

### 6-2. 모드별 보상 원칙

| 상황 | 서버 처리 | 성장 방식 |
|---|---|---|
| 온라인, 게이트 ON | 공용 화면 몹 생성 + 현재 개인 안전 단계 수익 | 본인 전투 기여 + 채널 시너지 + 실시간 난이도 도전 |
| 온라인, 게이트 OFF | 본인 몹 공급 없음, 공용 전투/힐·버프 참여 | 지원 기여로 보상, 빈 채널일 경우 수련 최저 보상 |
| 온라인, 도전 단계 | 다음 난이도 수동 도전, 성공하면 개인 최고/안정 단계 상승 | 접속한 사람의 적극적인 실력·협력 반영 |
| 오프라인/앱 종료/세션 끊김 | 마지막 **활성 캐릭터** 1명만 서버 경과 시간 정산 | 마지막 확정 **개인 안전 단계**에서 사냥 수익·일반 드롭 누적 |
| 오프라인 힐러, 게이트 OFF | 지원 클래스 개인 수련 정산 테이블 적용 | 파티가 없어도 서버에서 일정 경험치·골드·드롭 획득 |
| 수동 공동 보스 | 온라인 수동 소환·공동 전투 | 큰 특별 보상; 오프라인 보상에 자동 포함되지 않음 |

- **중요**: 온라인/오프라인 모두 **일반 장비 드롭 테이블과 자동 교체/판매 규칙은 동일**. 오프라인이라고 전설/신화 드롭을 불가능하게 만들지 않는다.
- 오프라인에서는 보스 소환이나 상위 단계 도전이 자동으로 수행되지 않음. 최고 진행 안정 단계를 기반으로 성장.
- 오프라인 시너지: 로그아웃 이후 실시간 유저가 만든 강력한 채널 시너지 수치를 그대로 고정하면 무한 버프 농장이 되므로, **개인 단계 기본 수익으로 정산**, 임의로 채널 시너지 스냅샷을 영구 고정하지 않는다.
- 자동장비로 전투력 상승해도 **오프라인 도전 단계 자동 돌파는 하지 않음**. 재접속하면 개인의 현재 전투력으로 더 높은 난이도에 도전 가능.

### 6-3. 오프라인 누적 시간·효율 시험안 (아직 확정 아님)

- 기본 취지는 **접속을 종료하더라도 마지막 활성 캐릭터의 사냥이 끊기지 않게** 하는 것. 8/12/24시간 후 보상이 완전히 사라지도록 하는 하드캡은 피하는 방향.
- 시험안 A(권장): 첫 24시간은 개인 안정 단계의 기본 경험치·골드·드롭 **100%**, 이후 24~72시간 **70%**, 72시간 이후 **50%로 계속 누적**. 유저가 며칠 후 복귀해도 성장이 0이 되지 않게 하되 장기 부재와 실시간 소셜의 가치 구분.
- 시험안 B: 온라인과 오프라인 모두 기본 **100%** 유지, 접속 중에는 **채널 시너지·상위 단계 도전·공동 보스**로만 추가 이득. 더 관대한 방식으로, 게임 운영 목표에 따라 선택 가능.
- **A/B 중 최종 효율은 아직 미확정**. 사용자 지정 없이는 플레이 테스트에서 온라인 1시간/오프라인 24시간/7일 수익을 비교해 결정.
- 오프라인 장비 드롭은 모든 처치를 프레임별 실행하지 않고 **서버 시간 구간별 기대 사냥 횟수 + 검증 가능한 난수**로 계산. 긴 기간일수록 대량 개별 잡템 대신 골드와 희귀 장비 후보만 처리.
- 캐릭터 전환할 때 이전 캐릭터의 정산을 즉시 닫고 다음 캐릭터의 활성 시간을 시작한다. 중간 중복 시간은 없는 **원자적 단일 활성화** 처리.
- 같은 레벨/장비에서 접속 중 일반 사냥 기본 보상과 오프라인 기본 보상은 부동소수점 반올림 외에는 같은 공식으로 시작하고, 게이트/지원직/보스/채널 보너스를 분리해서 추가.

## 7. 서버 데이터 및 동시성·공정성

기존 [IMPLEMENTATION.md](./IMPLEMENTATION.md)의 DB 초안에 아래 필드를 더한다.

```text
channel_members(account_id, channel_id, active_character_id, joined_at, connected_at,
                disconnected_at, connected_grace_until, is_online)
channel_synergy_snapshot(channel_id, version, faction_count_json, root_class_count_json,
                         current_job_count_json, party_count, calculated_at)
gate_settings(character_id UNIQUE, channel_id, spawn_enabled, stable_stage,
              challenge_stage, highest_cleared_stage, spawn_epoch)
gate_mobs(mob_id, channel_id, owner_account_id, owner_character_id, stage,
          reward_profile, spawned_at, defeated_at)
boss_channel_state(channel_id UNIQUE, room_first_entered_at, last_boss_defeated_at,
                   next_available_at, status, boss_instance_id, version)
boss_attempts(attempt_id, channel_id, summon_by_account_id, summoned_at,
              defeated_at, failed_at, reward_settlement_id)
boss_reward_claims(account_id, character_id, attempt_id, reward_id,
                   rewarded_at, UNIQUE(account_id, attempt_id))
combat_contributions(character_id, encounter_id, damage_effective, heal_effective,
                     shielding_effective, buff_added_damage, support_uptime)
hunt_rates(character_id, stable_stage, class_root_id, current_job_id, rate_version)
hunt_settlements(character_id, activation_generation, start_at, end_at,
                 base_exp, base_gold, loot_seed, online_bonus, offline_factor,
                 UNIQUE(character_id, activation_generation, start_at))
```

- `channels` 별 실시간 보스 상태/동시 소환 경쟁은 Durable Object 권위 처리 + DB 원자적 잠금/정산 ID를 사용. 두 사람이 같은 틱에 보스 소환 눌러도 **1마리만** 생성.
- 시너지 스냅샷은 계정당 1명만 세고 연결/이탈/전직/부캐 변경마다 이벤트 기반 갱신. 오래된 세션 이벤트 무시.
- 장비 교체/판매, 경험치, 보스 배포는 서버 트랜잭션으로 수행; 오프라인 보상 정산은 중복 실행해도 결과 1회만 기록.
- 데이터/시너지 프로토콜은 32개 진영 및 192개 루트 직업 전부 지원하고, 2,688개 심화 상위 노드는 `current_job_id`별로 추가 가능해야 함.

## 8. 테스트 수락 기준(추가)

1. 조선 검객 2명 + 조선 무당(게이트 OFF) 1명 + 슬라임 분열술사 2명 같은 채널: **5인 공통·조선3·슬라임2·검객2·무당1·분열2 + 전직 시너지** 계산 정확.
2. 무당(힐러) 게이트 OFF: 몹 소환 0, 채널 시너지 제공, 힐·보호막/버프 후 유효 기여 보상 수령. 딜러보다 보상 부당하게 낮아지지 않는지 검증.
3. 1인 채널 힐러 게이트 OFF: 온라인 안전 수련/오프라인 지원 정산으로 성장 정지되지 않음.
4. 같은 계정 2기기 접속·부캐 전환: 시너지 인원 1명, 게이트 몬스터 생성권 1개, 오프라인 자동사냥 1명, 중복 보스 수익 없음.
5. 채널 생성 직후/입장 직후 보스 버튼 잠금 → 60분 경과 시 수동 소환 가능 → 처치 순간부터 정확히 다음 60분 쿨다운. 입장 호핑/동시 클릭 악용 실패.
6. 보스 미처치 시 1시간 처치 쿨다운을 잘못 시작하지 않음; 짧은 재도전 대기는 별도 정책으로 적용.
7. 보스 보상 지급 중 네트워크 끊김·두 유저 동시 처치: 보스 1회 처치, 개인별 보상 1회, 적정 기여도 인정.
8. 온라인 도전 실패해도 개인 안전 단계 사냥 복귀, 보유 레벨/장비/웨이브 기록 초기화 없음.
9. 오프라인 1시간/24시간/7일: 마지막 활성 캐릭터만 시간 정산, 로그인 반복/상태 스냅샷 중복에도 드롭·골드·EXP 1회 지급.
10. 온라인/오프라인 동일 등급표 사용, 상위 장비 자동 장착·낮은 장비 자동 판매, 무제한 슬롯 정책 위반 없음.
11. 유저 50명이 게이트 ON 상태일 때 클라이언트 렌더 몬스터 수 상한 준수, 실제 개인 사냥 수익은 정원·그리기 최적화의 영향을 불합리하게 받지 않음.
12. 시너지 강한 방과 1인방 간 장기 성장을 비교해 **친구와 모일 이익은 분명하지만, 혼자/오프라인 유저의 성장이 막히지 않는 균형** 검증.

## 9. 미확정 세부와 구현 우선순위

**확정 요구**: 방 전체 종족/클래스/인원 중첩 시너지; 유저별 게이트 몬스터 소환 체크; 같은 한 화면; 소환 OFF 힐러도 기여·성장; 입장 후 1시간 보스 수동 소환/처치 후 1시간 쿨; 보스 큰 보상; 오프라인 보상; 접속 중 더 높은 개인 사냥 난이도에 도전.

**시험/추가 확인 대상**: 시너지 단위 수치, 몹 생성 주기·총량, 힐러 빈 방 기본 보상률, 보스 실패/재도전 대기, 소환 자격의 연속 체류 판정, 보스 보상 개인 보유 제한, 오프라인 A/B 효율, 최고 난이도 난이도 배율. 사용자 요구를 위배하지 않는 범위에서 시험값을 튜닝한다.

**개발 순서**: 단일화면 → 채널·활성 1캐릭터 → 개인 게이트+공유 스폰 → 32진영/192기초 클래스 시너지 데이터 → 상위전직 시너지 → 실시간/오프라인 통합 보상·힐러 수련 → 개인 상위 난이도 도전 → 1시간 수동 보스 → 대규모 밸런스 시뮬레이션. 정식 공개 범위에는 32진영×6기초 계보 및 각 상위 전직 전체가 포함된다.
