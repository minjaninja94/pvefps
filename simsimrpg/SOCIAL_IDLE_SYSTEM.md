## 1. 한 채널 = 친목방 + 공동 게이트 1개 + 역할 진형 + 도우미 NPC 3명

- **확정**: 한 채널의 모든 유저가 하나의 물리 게이트를 바라보고 직업 역할별 포지션 대형을 형성한다. 웨이브 일반/정예 몬스터는 **하나의 게이트**에서 쏟아진다.
- **확정**: 도우미 NPC 3명은 채널마다 항상 존재. 기본 역할 제안은 방패 탱커 1명, 회복·지원 1명, 공격 1명. NPC에게 개인 성장·골드·장비·소환/합성/배치 권한 없음.
- **확정**: 타인과 싸우는 같은 화면에서 채팅·클래스 성장·소셜 시너지 모두 적용하며, 보스 역시 별도 전장 없이 공동 게이트에서 수동 소환.
- **이전 명세 폐기**: 개인별 물리 게이트 및 개인별 몬스터 소환·개인 게이트당 스폰 수. 이 문서 후반부에 나오는 이전 용어는 최신 규칙 기준으로 해석할 것.
- 개인 게이트 ON/OFF → **개인 [참전]/[휴식] 체크**. 힐러는 참전 상태에서 후열 힐·버프/보호막 행동으로 경험치를 얻으며 개인 몬스터 소환은 필요 없다. '휴식' 보상 효율은 아직 미확정.
- **채널 공동 웨이브 1개**: 난이도 상향도 같은 채널 게이트에 적용하며 개인별 사냥 기록/적정 보상 자격을 별도로 기록. 개인별 물리 몬스터 무리를 분리하지 않는다.
- 봇은 **실제 유저/계정 인원 수·진영·직업 시너지** 스택에서 제외. 플레이어 힐러를 대체할 정도로 강력하지 않아야 하며, 유저 힐러 1명+탱커·공격봇 조합에서도 기본 사냥 진행 가능.
- 상세 전투/UI, 포지션, 봇 역할, 시너지 연동, 오프라인 처리, DB 변경 및 테스트는 [FORMATION_AND_GATE.md](./FORMATION_AND_GATE.md) 참조.

## 2. 전체 종족별 + 클래스별 + 인원별 **중첩 패시브 시너지**

### 2-1. 확정 규칙

1. 채널 내 서로 다른 **활성 계정 수**에 비례하는 **채널 인원 시너지**.
2. 각 **32개 진영(종족)별**로 현재 채널에 속한 해당 진영 인원 수를 세어 **종족 고유 패시브 중첩**.
3. 각 **192개 루트 클래스별**로 해당 계보 선택 인원 수를 세어 **클래스 고유 패시브 중첩**; 상위 전직은 루트 클래스 패시브를 계승하고 **현재 전직 경로 전용 패시브를 추가**해 세부 전문직의 존재감도 드러낸다.
4. 같은 진영/같은 클래스 유저가 여러 명 모이면 실제 중첩된다. 서로 다른 진영·클래스 시너지 역시 동시에 발동한다. **공동 게이트 전투에 참전한 힐러도 멤버로 계산**하고 이들의 치유/버프 기여를 보상 인정한다.
5. **계정당 오직 1명**만 시너지 인원수에 반영한다. 한 사람이 부캐를 수십 개 만들거나 둘 이상의 탭을 켜도 인원 중복 불가.
6. 세부 시너지 내용은 채널 패널의 **'현재 시너지'** 탭에서 종족/직업별 인원수, 중첩 횟수, 현재 배율, 본인이 제공하는 버프를 투명하게 확인.
7. 잠수 유령으로 시너지를 부풀리지 않도록 채널 실시간 접속자에 대한 계수는 **실제 연결 중인 서로 다른 계정** 중심으로 계산한다. **설계 제안값**: 일시적 네트워크 끊김 90초 유예. 그 이후 오프라인으로 전환되면 시너지 인원에는 포함하지 않으나 캐릭터 서버 사냥은 계속 정산한다. 오프라인 잔상/대표 표시 여부와 시너지 계산은 구분.

### 2-2. 시험용 수치: 중첩되지만 무한 폭증 방지

| 카테고리 | 예시 공식 | 비고 |
|---|---|---|
| 채널 인원 공통 | `+0.5% × min(N-1, 20)` | 1인 0%, 21인 이상 +10%; 같은 계정 중복 없음 |
| 각 진영 고유 시너지 | 해당 진영 1~5인 각 +0.6%, 6~15인 각 +0.2% | 같은 진영 15인 이상 +5% 상한; 다른 종족 효과와 동시에 활성 |
| 각 기본 클래스 고유 시너지 | 해당 클래스 1~5인 각 +0.35%, 6~15인 각 +0.1% | 같은 루트 15인 이상 +2.75%; 진영 패시브와 중첩 |
| 상위 전직 전문 패시브 | 같은 **현재 전직 노드** 당 0.15%, 10인 상한 | 상위전직 개성/해당 파티 전문화 보너스 |
| 전체 공격·성장 보너스 | 각종 출처 중첩 후 카테고리별 감쇠 및 **유효 사냥 보상 상한 검증** | 임시 목표: 동등 전투력 비교 시 소셜 추가 수익 +0~30% 내외 |

- 표의 +%는 해당 패시브가 지정한 **효과 지표**에 적용. 회복/방어 버프와 공격/골드 버프의 수치는 동일 가치가 아니므로 실제 밸런스는 효과별 가중치로 조정.
- 여러 종류를 중첩하되 고정된 버프순서, 라운딩, 최종 배율 상한 정의. 공격 스킬이 연쇄로 계속 소환되어 처리량 폭증하지 않도록 타격 이벤트 상한/쿨타임/확률 적용.
- **인원 시너지에 출석만으로 무한 골드를 지급하지 않는다.** 경험치·골드는 실제 공용 사냥·지원 행동/오프라인 정산에서 별도 산정.
- 혼자 있으면 소셜 시너지 보너스 0이지만, 힐러를 포함해 **기본 성장 루프 자체는 막히지 않게** 설계.

- 경제/버프 패시브는 실접속 참전 계정만 1스택, NPC 3인·관전자·방치 중 다른 부캐는 0스택. 예시 1인 골드 +1% 가산, 총 +8~12% 상한 시험(정확한 수치 검증 전).
- 금화상인과 드워프의 골드 패시브·요리/축제의 소액 보상·온라인2배 보상이 곱연산 무한 확장되지 않도록 **기본 골드×온라인 배율 + 유효 공동 보너스(상한)** 순서로 계산하고 서버 원장으로 검증.
- 황룡 2차 '**각성 공군**' 특성은 아군 해병에게 약화 효과를 걸고 자신에게 더 큰 강화 효과를 얻는 **선택 동의형 동맹 기술**. 동의하지 않은 다른 유저를 자동 약화하지 않으며, 사망/부활 반복으로 버프·성장 재화를 무한 획득하지 않는다.
- 각 진영 대표 **한 개 이상 유니크한 상위 직업군**은 [32 진영 대표 계보](./FACTION_CLASS_REWORK_2026_11_03.md) 기준으로 검증하고 공격·치유·경제·대형·공연 등 비전투 계열도 유효 기여도 인정.

## 3. 힐러·지원 직업의 경험치/전리품 인정

- 별도 몹을 소환할 필요가 없는 성직자·무당·치유천사·의무병 등은 **공동 게이트에서 쏟아진 몬스터를 상대하는 유저에게 힐·보호막·해제·버프·약화·전투 지원**을 제공하면 기여도 획득. 채널 NPC 치유봇은 기본 안전망 역할만 하며 유저 힐러의 실제 성장을 대체하지 않는다.
- 지원 기여 지표: 실제 잃은 HP를 회복한 유효 치유량(과잉힐 제외), 막은 유효 피해량, 타인의 공격 성공에 기여한 버프의 추가 피해, 적에게 적용한 디버프에 따른 피해 증가, 적 처치에 연결된 유효 지원 시간.
- 사냥 보상은 `공동 게이트 전투 기여 + 유효 지원 기여`에 따라 산정하되 **동등 시간대에 적정 난이도에서 기여한 힐러와 딜러의 목표 보상 차이를 ±10% 안에서 맞추는 시험안**으로 시작한다.
- 힐/버프 스킬을 목표물 없이 난사해 보상을 받는 농사(무의미 힐 반복)를 방지하기 위해 **유효 전투 행동만 기여로 인정**.
- 실제 유저가 힐러 1명뿐인 채널에서도 **고정 도우미 봇 3명 중 탱커·공격 봇**이 공동 게이트 일반 몬스터를 상대로 기본 전투를 수행한다. 힐러의 지원 기여가 유효 보상으로 환산되어야 하며, 오프라인에는 지원 수련 정산을 제공한다. **동료 유저 부족으로 영구 성장이 막히면 안 됨**.
- 오프라인 힐러는 실시간 채널의 실제 다른 플레이어 체력 또는 NPC 봇 3명을 프레임마다 계산하지 않고, 해당 클래스에 마련한 **개인 사냥/지원 수련 기준 수익**으로 서버 정산한다. 이를 통해 '타인 의존형 클래스라 로그아웃하면 0 성장' 상황을 방지.
- 지원직은 필요한 레벨에서 협동에 확실한 기여(보호막/생존/전투 효율) 가능하게 설계하되, 몬스터 수익을 부풀리는 무한 생존/무적 루프는 막는다.

## 4. 공동 게이트의 난이도 도전 + 개인별 보상/최고기록

- **공동 게이트는 정확히 한 개**. 채널의 일반 몬스터 웨이브가 이곳에서 무한 등장하고, 유저들은 전·중·후열 및 측면에서 함께 자동 공격한다.
- 채널 웨이브 난이도는 **한 단계**를 공유한다. 유저별 `highest_cleared_stage`, `stable_farm_stage`, `reward_eligibility_tier`는 **개인 성장 기록과 보상 자격**으로 보관하지만 실제로 별도의 다른 몬스터가 출현하는 것은 아니다.
- 온라인 도전: 게이트 UI에서 채널 공동 난이도 상승을 제안/선택. 의결권/과반수 같은 세부 운영안은 [FORMATION_AND_GATE.md](./FORMATION_AND_GATE.md)에서 **제안값**으로만 표기. 고레벨 유저가 초보자에게 강제 불리한 사냥을 시키지 않도록 개인 적정 보상·기여와 안전장치 검증.
- 도전에 실패해도 **게임오버 없음**. 채널의 최근 안정 웨이브에서 자동 사냥이 계속됨. 개인 Lv·골드·장비·숙련도 잃지 않음.
- 힐러·지원직은 직업 역할에 맞는 고급 회복/보호막/제어를 사용해 전선 유지와 공동 난이도 상승에 실질 기여. 빈 채널이라면 도우미 NPC 3명과 함께 일반 사냥 가능.
- 일반 몬스터 HP·공격력·골드/EXP 증가율은 기존 **시험값**(HP ×1.12, ATK ×1.09, EXP/GOLD ×1.06 per stage)을 현재 공동 난이도 모델에 그대로 확정 적용하지 않고 성능/밸런스 시뮬레이션 후 조정.
- 기술/데이터 구현: `channel_gates`(채널당 1개), `gate_spawn_events`(채널 전체 몬스터 스폰) 사용. 기존 `gate_settings(character_id,spawn_enabled)`, `gate_mobs(owner_account_id,...)`는 폐기.
- 게이트 [참전/휴식] 체크는 플레이어의 전투 참여 설정. 실시간 휴식 상태와 기존 '활성 캐릭터 1명 서버 자동사냥'의 보상 관계는 별도 확정이 필요한 정책으로 남긴다.

## 5. 수동 소환 공동 보스 — 입장 1시간, 처치 후 다시 1시간

### 5-1. 사용자가 확정한 규칙

1. **방/채널에 들어온 뒤 1시간을 채워야** 수동 소환할 수 있다.
2. 보스는 절대 자동으로 출현하지 않음. '보스 소환' 버튼을 누른 경우에만 그 채널의 같은 화면에 나타난다.
3. 보스를 **처치한 시점부터 다시 1시간 쿨다운**이 시작한다. 1시간 경과 후 다음 수동 소환 가능.
4. 보스는 일반 몬스터보다 **훨씬 많은 보상**을 지급한다. 드롭·골드·경험치·희귀 장비 보상이 핵심.
5. 보스 도전으로 별도 맵을 로딩하지 않으며, 실패해도 게임오버 없음.

### 5-2. 여러 사용자가 방을 공유할 때의 구체 운영안

- **공동 채널 단위 시계**: 채널 생성/최초 유저 입장 때 `room_first_entered_at`을 기록. 첫 소환 가능 시각 = 그 시점 + 60분. 한 번 클리어한 뒤부터는 **`last_boss_defeated_at + 60분`**이 다음 최소 가능 시각.
- **소환을 누르는 유저 자격**: 해당 채널에 유효하게 60분 이상 머문 온라인 유저 중 1명이 수동으로 누르면 소환. 일시적 연결 끊김에 대한 90초 유예를 둘 수 있지만 채널 호핑으로 지난 1시간을 재활용하지 못하게 `channel_joined_at` 기록을 따로 관리.
- **보스 1마리만**: `room_boss_state = waiting | summoned | defeated | retry_wait`; 중복 버튼/동시 클릭에 서버 원자적 잠금.
- 처치 → `last_boss_defeated_at = 서버시간`, 전체 채널 버튼 60분 잠금. **소환 시점이 아니라 처치 시점부터 쿨 시작**.
- 미처치/전멸 시: 게임오버는 없고 시간 초과 시 보스 퇴장. **설계 제안값** 5분 재도전 대기(처치하지 않았으므로 1시간 처치 쿨다운 시작하지 않음). 연속 소환 도배 방지.
- 늦게 입장한 유저도 전투 지원은 할 수 있으나 고급 보상은 **기여 조건 + 방 참여시간 조건**이 필요. 시험값: 소환 이전 10분 참가 혹은 전투 중 유의미 기여 + 개인별 글로벌 보스 보상 쿨타임 60분. 정확한 임계값은 테스트로 조정.
- 새로운 채널로 옮겨도 보스 **개인 고급 보상**을 매번 다시 받을 수 없도록 `account_last_boss_reward_at` / `character_last_boss_reward_at` 등을 서버에서 검사.
- 보스 난이도: 현재 채널에서 실시간 참여 중인 **고유 계정의 유효 전투력과 지원 역할**을 기준으로 체력·위험도를 단계별 조정. 힐러가 많으면 보스가 불사신이 되지 않게 실질 처치 속도에 상한.
- **보스 소환은 수동**, 자동 사냥으로 일반 몬스터만 잡다가 본인이 보스를 놓쳐도 자동 소환/자동 입장은 없음.

### 5-3. 큰 보상에 대한 시험 밸런스

| 보상 | 시작 시험안 | 악용 방지 |
|---|---|---|
| 개인 기본 경험치 | 같은 시간대 일반 자동 사냥 30~60분치 | 최소 기여 인정·보상 쿨 검증 |
| 개인 기본 골드 | 일반 사냥 30~60분치 | 동일 보상 원장 트랜잭션 |
| 장비 드롭 | 동일 난이도 일반 몬스터보다 희귀/상급 장비 확률 높음 | 반드시 클래스 맞춤 자동 착용/자동판매 |
| 보스 첫 처치 | 업적/칭호/최초 1회 특별 보상 | 계정·캐릭터 중복 지급 방지 |
| 힐러·지원 기여 | 실제 치유·버프·방어 등 기여로 딜러와 동등하게 지급 | 오버힐/허위 버프 파밍 방지 |

- 30~60분치, 5분 대기 등은 **확정 수치가 아닌 시험값**. 보스의 크고 뚜렷한 보상은 확정 요구.
- 보상 계산은 개인별 사냥 단계/캐릭터 레벨에 맞춰 과한 초보자 버스 수익·고렙 쏠림 방지.

- **세븐나이츠 키우기**: 공식 소개에서 게임 종료 후에도 누적 보상이 계속된다고 명시. 실제 운영 이벤트에서 '2/4/6시간 오프라인 골드·영웅 경험치' 보상 단위가 사용됨. 참고: https://skidle.netmarble.com/en/game , https://forum.netmarble.com/SevenKnightsidle/view/120/162124
- **AFK Journey**: 최고로 진행한 AFK 스테이지가 방치형 자원 수익에 반영되고 자동 도전으로 상위 단계로 진행. 참고: https://playafkjourney.com/battle-modes/ , https://d2ankz0m1a0dsp.cloudfront.net/afk-journey/guides/game-modes/
- **Legend of Slime**: 오프라인 자동 전투/장기 성장의 플레이 경험 참고. https://play.google.com/store/apps/details?id=com.loadcomplete.slimeidle

### 6-2. 모드별 보상 원칙

| 상황 | 서버 처리 | 성장 방식 |
|---|---|---|
| 온라인, 참전 ON | 공동 게이트 웨이브에 자동 공격·힐·버프 참여 | 본인 실질 기여 + 채널 시너지 + 공동 난이도 도전 |
| 온라인, 휴식/구경 | 공용 게이트 몬스터는 계속 등장하고 본인은 전투 일시 대기 | 보상·시너지 포함 여부는 별도 확정 필요; 온라인 참전 상태의 힐러는 정상 보상 |
| 온라인, 도전 단계 | 다음 난이도 수동 도전, 성공하면 개인 최고/안정 단계 상승 | 접속한 사람의 적극적인 실력·협력 반영 |
| 오프라인/앱 종료/세션 끊김 | 마지막 **활성 캐릭터** 1명만 서버 경과 시간 정산 | 마지막 확정 **개인 안전 단계**에서 사냥 수익·일반 드롭 누적 |
| 오프라인 힐러 | 개인 지원·안전 수련 정산 테이블 적용(도우미 보조는 이중 계산하지 않음) | 유저 접속이 없어도 경험치·골드·드롭 획득 |
| 수동 공동 보스 | 온라인 수동 소환·공동 전투 | 큰 특별 보상; 오프라인 보상에 자동 포함되지 않음 |

- **중요**: 온라인/오프라인 모두 **일반 장비 드롭 테이블과 자동 교체/판매 규칙은 동일**. 오프라인이라고 전설/신화 드롭을 불가능하게 만들지 않는다.
- 오프라인에서는 보스 소환이나 상위 단계 도전이 자동으로 수행되지 않음. 최고 진행 안정 단계를 기반으로 성장.
- 오프라인 시너지: 로그아웃 이후 실시간 유저가 만든 강력한 채널 시너지 수치를 그대로 고정하면 무한 버프 농장이 되므로, **개인 단계 기본 수익으로 정산**, 임의로 채널 시너지 스냅샷을 영구 고정하지 않는다.
- 자동장비로 전투력 상승해도 **오프라인 도전 단계 자동 돌파는 하지 않음**. 재접속하면 개인의 현재 전투력으로 더 높은 난이도에 도전 가능.

### 6-3. 최신 확정: 오프라인 기본 ×1 / 온라인 연결중 기본 ×2

> 2026-11-03 최신 사용자 요구가 과거 **24시간 후 70%, 72시간 후 50%** 시험안을 폐기한다. 공식 성장곡선·랜덤 이벤트·전직 시련 세부는 [GROWTH_REWARDS_AND_GATE_EVENTS.md](./GROWTH_REWARDS_AND_GATE_EVENTS.md).

- 오프라인은 경과시간이 길어도 **100%(×1) 기본 보상 지속**. 종료/모바일 꺼짐/로그아웃 후에도 계정당 마지막 활성 캐릭터 한 명만 서버 정산. 장비 슬롯·보상 수령용량 제한 금지.
- 채널에 실제 연결되어 있는 유일 활성 캐릭터의 일반 자동사냥은 **EXP·기본 골드·일반 장비 추첨 기회·스킬 숙련도 ×2**. 수동 보스와 이벤트 고정 보상은 중복 ×2 제외. 오프라인 장비 드롭은 같은 등급 테이블을 사용.
- 캘리브레이션 목표: **Lv.30 오프라인2h/온라인1h, Lv.100 24h/12h, Lv.250 168h(7일)/84h(3.5일)**. 미전직 상태로도 레벨업 기본 누적은 계속. 채널 시너지·상위 난이도 이벤트를 제외한 기준 성장곡선.
- 온라인 여부는 서버 세션/heartbeat 상태를 기준으로 시간 구간을 분리. 연결 끊김 뒤 온라인 ×2는 끝나고 오프라인 ×1이 시작(기존 획득분 소멸 없음). 동시 접속/캐릭터 전환 중복 보상 불가.
- 장시간 오프라인 정산은 몬스터 프레임 시뮬레이션이 아니라 경과 시간 구간별 기본 수익/드롭 추첨을 계산하고, 장비 자동착용·자동매각 및 숙련도를 누적한다.
- 오프라인 힐러는 세 명의 NPC 도우미를 포함한 개인 기준 지원 수련을 정산하고, 온라인에서도 타인을 지원하며 정상 수익 획득. 실제 백그라운드 동작 불안정은 서버 ×1로 해결.
- 일반 드롭률/게이트 고난도 상승률/경험치 요구량·이벤트 추가 보상 기대값은 실측 시뮬레이션으로 튜닝.

## 9. 미확정 세부와 구현 우선순위

**확정 요구(최신)**: 방 전체 종족/클래스/인원 중첩 시너지; **채널당 하나의 공동 게이트와 역할별 유저 진형, 도우미 NPC 3명 상시 배치**; 같은 한 화면; 별도 몹 소환 없는 힐러도 기여·성장; 입장 후 1시간 보스 수동 소환/처치 후 1시간 쿨; 보스 큰 보상; 오프라인 보상; 접속 중 더 높은 **공동 게이트** 난이도에 도전.

**시험/추가 확인 대상**: 시너지 단위 수치, 몹 생성 주기·총량, 힐러 빈 방 기본 보상률, 보스 실패/재도전 대기, 소환 자격의 연속 체류 판정, 보스 보상 개인 보유 제한, 오프라인 A/B 효율, 최고 난이도 난이도 배율. 사용자 요구를 위배하지 않는 범위에서 시험값을 튜닝한다.

**개발 순서**: 단일화면 → 채널·활성 1캐릭터 → **공동 게이트 1개 + 역할 대형 + NPC 도우미 3명** → 32진영/192기초 클래스 시너지 데이터 → 상위전직 시너지 → 실시간/오프라인 통합 보상·힐러 수련 → 공동 게이트 상위 난이도 도전 → 1시간 수동 보스 → 대규모 밸런스 시뮬레이션. 정식 공개 범위에는 32진영×6기초 계보 및 각 상위 전직 전체가 포함된다.
