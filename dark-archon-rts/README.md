# 마컨 디펜스

`index.html`을 열면 실행되는 독립형 전략 디펜스입니다.

## 현재 게임 규칙

- 디펜스: 적 웨이브 10개를 막고, 다크 아콘으로 적 유닛을 정신 지배합니다.
- 다크 아콘이 죽은 후 넥서스의 `재생산` 버튼을 누르면 60초 뒤 새 다크 아콘이 나옵니다.
- 사이오닉 스톰은 75 에너지, 3.2초 동안 8회에 걸쳐 총 112 피해를 가하며 아군도 맞습니다. 기지는 피해를 받지 않습니다. 원작에서 다크 아콘의 기본 능력은 아니며 이 게임을 위해 추가했습니다.
- 로컬 2인 쟁탈전: 같은 화면에서 `조작` 버튼으로 청록/주홍 플레이어를 전환합니다. 중앙에 8초마다 무작위 유닛이 나오고, 먼저 정신 지배해 상대 기지를 파괴하면 승리합니다. 온라인 연결 기능은 아직 없습니다.
- 화면은 1920×1080에서 상하 여백과 게임 화면 비율을 맞췄습니다.

## 수치와 자료

현재 등장하는 7종의 기본 HP, 보호막, 기본 공격력, 방어력은 Blizzard의 원작 유닛 자료에 맞췄습니다. 속도와 사거리는 이 게임의 캔버스 픽셀로 환산한 값이며, 원작의 모든 업그레이드, 크기별 피해 배율, 공중/지상 구별, 기술 트리는 아직 구현되지 않았습니다. 다크 아콘의 정신 지배는 150 에너지와 보호막 소진, 마엘스트롬은 100 에너지를 반영합니다.

## 이미지

게임에서 쓰는 7종 유닛의 16×16 이미지 시트와 넥서스 이미지는 ImageGen으로 새로 만들었습니다. 각 시트는 행을 방향, 열을 대기/이동/공격/사망 프레임으로 읽습니다. 생성 이미지 특성상 일부 방향·프레임의 모양과 칸 경계는 손질이 필요합니다.

생성 프롬프트의 공통 틀: `투명한 16×16 RTS 스프라이트 시트. 각 행은 22.5도씩 회전한 16방향, 각 열은 대기 4칸·이동 6칸·공격 3칸·사망 3칸. 칸마다 한 유닛을 같은 크기와 중심으로 배치. 글자·숫자·로고·워터마크·테두리 없음.` 대상 설명은 각 유닛의 독자적인 색상, 실루엣, 무장과 동작에 맞춰 따로 작성했습니다. 넥서스는 `투명 배경의 독창적인 청색 수정·금빛 외장 외계 전략 게임 기지, 높은 시점의 단일 건물 스프라이트, 글자 없음`으로 생성했습니다. 생성 방식은 내장 ImageGen입니다.
