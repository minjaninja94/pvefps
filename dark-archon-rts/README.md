# 마컨 디펜스

`index.html`을 열면 실행되는 독립형 전략 디펜스입니다.

## 현재 게임 규칙

- 디펜스: 적 웨이브 10개를 막고, 다크 아콘으로 적 유닛을 정신 지배합니다.
- 다크 아콘이 죽은 후 자기 기지의 `재생산` 버튼을 누르면 60초 뒤 새 다크 아콘이 나옵니다. 로컬 2인 쟁탈전에서는 양쪽 모두 사용할 수 있습니다.
- 사이오닉 스톰은 75 에너지, 3.2초 동안 8회에 걸쳐 총 112 피해를 가하며 아군도 맞습니다. 기지는 피해를 받지 않습니다. 원작에서 다크 아콘의 기본 능력은 아니며 이 게임을 위해 추가했습니다.
- 로컬 2인 쟁탈전: 같은 화면에서 `조작` 버튼으로 청록/주홍 플레이어를 전환합니다. 넓은 전장 아래쪽에 중립 유닛이 등장하고 돌아다니며 양쪽을 공격합니다. 상단 고지대 진격로에는 중립이 출현하거나 진입하지 않습니다. 병력을 선택해 `R` 또는 `상단 우회`를 누르면 그 길을 통해 상대 기지로 이동합니다. 상대 다크 아콘은 정신 지배할 수 없지만 스톰과 피드백으로 공격할 수 있습니다. 온라인 연결 기능은 아직 없습니다.
- 포토 캐논은 디펜스 넥서스 앞에 위아래 두 기, 쟁탈전에서는 양쪽 넥서스 앞에 각각 위아래 두 기가 놓입니다. 고정 방어 시설이며 사거리 내 적을 자동으로 공격하고 수정 발사부가 앞뒤로 움직이며 광탄을 쏩니다. 건물은 정신 지배하거나 스톰으로 파괴할 수 없습니다.
- 화면은 1920×1080에서 상하 여백과 게임 화면 비율을 맞췄습니다.

## 이미지

게임에서 쓰는 7종 유닛의 16×16 이미지 시트, 넥서스, 포토 캐논의 본체와 발사부 이미지는 ImageGen으로 새로 만들었습니다. 각 유닛 시트는 행을 방향, 열을 대기/이동/공격/사망 프레임으로 읽습니다. 생성 이미지 특성상 일부 방향·프레임의 모양과 칸 경계는 손질이 필요합니다.

게임은 생성된 시트의 원본 가로세로 크기(약 1250픽셀)를 유지한 AVIF 파일을 사용합니다. 512픽셀 축소본은 소스에서 제거했습니다. 맨 아래 16번째 방향 행은 생성이 불완전해 사용하지 않고 첫 방향 행로 대체합니다. 각 프레임의 투명 픽셀 중심을 계산해 위치를 맞추며, 별도의 이미지 추출 도구는 포함하지 않습니다. UI 초상화는 게임에서 필요한 작은 미리보기만 즉시 생성합니다.

생성 프롬프트의 공통 틀: `투명한 16×16 RTS 스프라이트 시트. 각 행은 22.5도씩 회전한 16방향, 각 열은 대기 4칸·이동 6칸·공격 3칸·사망 3칸. 칸마다 한 유닛을 같은 크기와 중심으로 배치. 글자·숫자·로고·워터마크·테두리 없음.` 대상 설명은 각 유닛의 독자적인 색상, 실루엣, 무장과 동작에 맞춰 따로 작성했습니다. 넥서스는 `투명 배경의 독창적인 청색 수정·금빛 외장 외계 전략 게임 기지, 높은 시점의 단일 건물 스프라이트, 글자 없음`으로 생성했습니다. 생성 방식은 내장 ImageGen입니다.


## 배경음악 및 유닛 음성

- BGM: `Warping_the_Citadel.mp3`을 첫 사용자 클릭/키 입력 후 반복 재생합니다.
- 상단에서 전체 음소거, 배경음악(BGM), 유닛 음성(VOICE) 음량을 따로 설정할 수 있습니다.
- 7종 유닛(다크 아콘, 아콘, 질럿, 마린, 골리앗, 히드라리스크, 울트라리스크)은 준비(`ready`), 선택(`select`), 이동(`move`), 공격(`attack`), 사망(`death`)에 음성이 연결됩니다.
- 음성 파일 경로는 `voices/<영문유닛명>-<이벤트>.wav`입니다. 7×5=35개 WAV를 `dark-archon-rts/voices/` 폴더에 넣어야 실제 게임에서 들립니다.
- 다수의 유닛이 동시에 전투 중일 때 같은 대사가 과도하게 반복되지 않도록 재생 빈도를 제한합니다. 브라우저 음성 합성(TTS)은 사용하지 않습니다.

- **확장 캠페인:** 기존 1~10웨이브는 영웅 1~4기와 적 병력을 일괄 출현시킵니다. 이후 11~70웨이브는 대규모 선봉 병력이 동시에 출현하고 일부 증원 부대가 11초/19초 후 측면으로 들어옵니다. 영웅은 적 물량과 단계에 따라 최대 8기까지 증가합니다. 70웨이브에는 24종 전체 병종이 등장합니다.

### 스프라이트 현황과 포맷

- **기존 7종**은 `<unit>-atlas.avif`를 사용하며, 프레임 중심을 대기 모션 기준으로 고정해 이미지 흔들림을 줄였습니다.
- **신규 18종**의 16×16 프레임 픽셀 아틀라스를 PNG로 실제 생성·업로드했습니다. 파일 경로는 `<unit>-atlas.png`이며, 원래의 7종 AVIF와 함께 실행 코드에 연결됩니다. 신규 PNG는 절차적으로 제작한 임시 저해상도 픽셀 아트입니다. 고품질 ImageGen 원화로 전량 교체한 상태는 아닙니다.
- 시트는 16방향 × 16프레임이며, 대기 4·이동 6·공격 3·사망 3열 배치를 따릅니다. 18종 PNG 파일은 `dark-archon-rts/<unit>-atlas.png`에 모두 있습니다. 기존 7종은 `-atlas.avif`를 사용합니다.

## 아군 시즈 탱크 포격진지 (2026-11-08)

- **웨이브 3부터** 적 시즈 탱크(퉁퉁포)가 전장에 등장합니다. 등장 병력을 정신 지배해서 모으고, 배치 위치까지 이동시킨 후 **탱크를 선택 → COMMAND CARD의 `O 시즈모드`** 또는 키보드 `O`를 누르세요. 여러 탱크를 동시에 선택하면 한 번에 전개·해제합니다.
- **적군 AI 시즈 탱크는 시즈모드 금지**: 기본 탱크 모드로만 공격합니다. 정신 지배로 아군이 된 탱크는 시즈 전개가 허용됩니다.
- 브루드워 원작: 기본 퉁퉁포 피해 **30**, 사거리 **7**(이 게임에서는 336 px), 37프레임 간격. 시즈 피해 **70**, 사거리 **12**(576 px), 최소 사거리 **2**(96 px), 75프레임 간격. 시즈 준비 79프레임, 해제 75프레임입니다. 변환 중과 시즈 상태에서는 이동할 수 없으며 근접 적은 시즈 최소 사거리로 인해 직접 공격 불가입니다.
- **원작 방사 피해 규칙**: 착탄 중심에서 **0–10 px 100%, 10–25 px 50%, 25–40 px 25%** 피해. 폭발형 피해이므로 소형에 50%, 중형에 75%, 대형에 100%의 HP 피해 보정(실드는 크기 보정 없음). 아군 지상 유닛/포토 캐논도 스플래시 피해를 받습니다. 공중 대상에는 포격하지 않습니다. 실제 게임 물리엔진이나 모든 충돌판정을 완벽히 재현한 것은 아니며, 이 RTS 캔버스의 픽셀 좌표계에 반경을 직접 적용했습니다. 스플래시 반경은 공격 사거리 환산과 별도로 원래대로 유지합니다.
- 탱크를 선택하고 시즈를 완료하면 사거리 외곽과 최소 사거리의 두 개 원이 나타납니다. 시즈 외형·전환 카운트다운·상단 SIEGE 라벨·하단 명령 카드 상태도 변경됩니다.
- 캠페인 웨이브별 적 일반 시즈 탱크 등장 수: **1–2웨이브 0기**, 3·4웨이브 1기, 5·6웨이브 2기, 7웨이브 4기, 8·9웨이브 3기, 10웨이브 4기. 병종별 영웅 출현 수는 기존과 같이 **웨이브당 1–4기만** 유지됩니다. 적 전체 수는 대체로 기존과 비슷하도록 다른 병종 숫자를 조정했습니다.
- 포격 전술: **시즈 탱크 사이와 근접 아군은 간격을 두고**, 포격전선 앞에 근접 유닛을 배치하되 아군 오폭에 주의하세요. 시즈는 지상 전용이므로 비행 적은 드라군·골리앗 등 대공 병종을 함께 확보해야 대응할 수 있습니다.
- 누적 포격 진지를 유지할 수 있도록 **웨이브 클리어 후 살아 있는 아군 시즈 탱크만 최대 체력의 50%를 수리**합니다. 다른 유닛은 기존 회복률입니다. 각 웨이브의 붉은 영웅은 일반 병력보다 약간 앞에서 동시에 출현해 정신 지배할 대상을 찾기 쉽도록 배치합니다.
- 10웨이브는 일반 캐리어/배틀크루저의 중복 출현을 제거하고 저글링으로 대체했습니다. **캐리어·배틀크루저 영웅은 그대로 남습니다.** 시즈 포격진지는 지상 병력에 강하지만 공중 대형 영웅을 혼자 잡을 수 없으므로 대공 지원과 최우선 정신 지배가 필요합니다.
- 모의 전투에서 시즈 전개/해제, 원작 방사 피해 배율과 오폭, 적군 시즈 금지, 웨이브 종료 탱크 수리는 검증했습니다. **10웨이브를 실제 플레이 방식으로 완주하는 밸런스 검증은 아직 통과하지 못했습니다.**

## 70웨이브 장기 캠페인 (2026-11-08 확장)

**실행:** PC `index.html`, 모바일 터치 전용 `mobile.html`. 두 페이지 모두 `campaign-70.js`와 `campaign-70.css`를 공유하므로 게임 규칙과 전술 점수는 동일합니다. 모바일은 터치 선택·카메라 이동·공격 이동 및 시즈 버튼을 지원합니다.

- **10 / 20 / 30 / 40 / 50 / 60 / 70단계 관문**: 10단계마다 더 큰 혼합 부대와 지휘관 영웅 편성이 나옵니다. 11단계 이후는 저그 대군, 테란 기갑전, 프로토스 공세, 공중 침공, 포격 교착전, 혼합 병력전 등 7가지 전술 테마를 순환시킵니다. 70단계는 모든 24종 전투 유닛이 포함된 총공세입니다.
- **적 증원:** 첫 10웨이브의 적은 전원 일괄 출현합니다. 17웨이브부터 일부 일반 병력은 나중에 투입되고, 후반에는 선봉 진입 후 11초/19초에 추가 병력이 투입됩니다. 적 시즈 탱크는 여전히 퉁퉁포만 사용합니다.
- **능력치 동결:** `TYPES`, `HERO_STATS`, 포격 스플래시/아군 피해 및 공중 타격 판정은 변경하지 않았습니다. 후반 난이도는 출현 종족/수량/구성과 증원 타이밍으로 조절합니다. 생존 아군 병력이 거의 없을 때는 일반 적 숫자만 부분적으로 낮춥니다.
- **기초 지원:** 1웨이브 시작 시 기본 마린/질럿 각 1기의 호위 병력이 주어집니다. 원래 HP와 공격력 그대로입니다.
- **전술 점수(TP):** 웨이브 클리어 1TP, 매 5웨이브 추가 1TP, 매 10웨이브 추가 2TP. **PSI 발전**(최대 8단계, 단계마다 PSI 재생 +4/초), **지원 병력**(최대 5단계, 3웨이브마다 최대 5기 합류), **넥서스 보수**(클리어마다 레벨당 40HP 회복), **병력 정비**(클리어마다 살아 있는 아군의 최대 HP 7%씩 추가 회복)를 구매할 수 있습니다. 구매 비용은 레벨마다 증가합니다.
- **긴급 PSI 보급:** 한 웨이브당 한 번 2TP를 소비해 150 마나를 즉시 회복할 수 있습니다.
- **웨이브 체크포인트:** 완료한 웨이브 다음 단계부터 이어하기 위해 브라우저 로컬 저장소에 기지 체력, 마나, 아군 생존 유닛/영웅, 시즈 상태, 전술 포인트/업그레이드가 저장됩니다. 저장 데이터는 같은 브라우저·같은 기기에만 적용되며, GitHub 서버에 저장하지 않습니다.
- **클리어 카드:** 매 10웨이브 격파 시 약 6초간 유닛 아틀라스 기반 기념 카드가 뜹니다. 별도의 성인 캐릭터 일러스트는 아직 제작·연결되지 않았습니다.
- **이동/공격 이동 분리:** `V` 순수 이동은 적의 공격을 받아도 계속 이동하고, `A` 공격 이동은 이동 중 적과 교전합니다. 적의 피격 방향이 번갈아 바뀌어도 근접 병력이 목표를 일정하게 유지합니다.

### 검증 수준

JavaScript 문법 및 동일 게임 코드를 사용한 PC·모바일 모의 실행에서 10, 11, 20, 30, 40, 50, 60, 70웨이브 출현 수·영웅 수·적 시즈 상태·17단계 이후 증원·마나 업그레이드·체크포인트 저장/불러오기·70웨이브 승리 종료 경로를 검사했습니다. **실제 모바일 기기에서의 터치 조작과 1→70웨이브 전체의 인간 플레이 승률·성능은 아직 검증하지 못했습니다.** 70웨이브 승리 상태 검사는 전투를 강제로 클리어한 개발 검증이며 실력 기반 완주를 입증하지 않습니다.

## 마법 조작 개선 — Star식 타겟팅 및 자동 접근 (2026-11-08)

- `mind`(정신 지배)·`feedback`(피드백)은 **대상 유닛을 지정**하는 마법입니다. 시전 모드에서 빈 땅 또는 사용 불가능한 유닛을 클릭하면 **시전 모드만 해제**하고 에너지는 소비하지 않습니다. ESC와 우클릭 이동 등으로도 취소합니다.
- 사거리 밖의 **유효한 적 유닛**을 지정하면 다크 아콘이 해당 유닛을 계속 추적하여 정신 지배 **264 px**, 피드백 **330 px** 범위 안에 들어온 즉시 자동 시전합니다. 유닛이 죽거나 소속이 바뀌면 예약 시전이 취소됩니다. 이동·정지·선택 변경·다른 마법 선택 시 이전 예약도 취소됩니다.
- `mael`(마엘스트롬)과 `storm`(사이오닉 스톰)은 여전히 **지면 위치 지정**입니다. 범위 밖의 지면을 찍으면 다크 아콘이 접근해 마엘스트롬 **330 px**, 스톰 **297 px** 사거리 안에서 해당 위치에 시전합니다. 대상을 추적하는 마법과 달리, 지면 좌표는 이동하지 않습니다.
- **시전 중 시각화**: 다크 아콘 중심에 사거리 원을 표시하고, 마컨·피드백을 걸 수 있는 유닛은 붉은색 테두리로 강조합니다. 지정한 유닛을 추적할 때는 붉은 연결선과 접근 후 자동 시전 안내를 표시합니다. 마엘·스톰은 선택 위치에 피해/기절 범위 원을 표시하며, 스톰에 맞을 수 있는 아군은 다른 색상으로 경고합니다.
- 이동은 기존 유닛 속도로만 수행하며 유닛 HP/공격력·마법 에너지 비용 및 실제 마법 범위 효과는 변경하지 않았습니다. PC/모바일 모두 `spell-controls.js`를 공용으로 사용합니다.

검증: 자동 접근 후 마컨/피드백/스톰/마엘 시전, 사거리 정지, 한 번만 마나 소비, 빈 땅 클릭 취소, 이동 명령 취소, 시전 대상 사망 시 자동 취소, 모바일 터치 조작을 모의 실행했습니다. 실기 브라우저 전체 플레이 검증과 실제 마우스 조작감 테스트는 별도로 필요합니다.


## 모든 전투 유닛 공격 사거리 통합 (2026-11-10)

원래 각 유닛의 사거리는 서로 다른 임의 픽셀 값으로 환산되어 원작의 상대 사거리 비율이 정확하지 않았습니다. **모든 26개 유닛 유형(비공격 마법사인 다크 아콘 포함)**에 대해 브루드워 기본 무기 사거리(1칸 = 원작 32px)를 **이 게임의 48px/칸으로 일괄 환산**합니다. `RANGE_PX_PER_TILE=48`과 `BW_ATTACK_RANGE_TILES`가 단일 원본 규칙이며 PC 및 모바일에 똑같이 적용됩니다. 기본 무기 사거리 연구 업그레이드는 자동 반영하지 않습니다.
