# 마컨 디펜스

`index.html`을 열면 실행되는 독립형 전략 디펜스입니다.

## 현재 게임 규칙

- 디펜스: 적 웨이브 10개를 막고, 다크 아콘으로 적 유닛을 정신 지배합니다.
- 다크 아콘이 죽은 후 자기 기지의 `재생산` 버튼을 누르면 60초 뒤 새 다크 아콘이 나옵니다. 로컬 2인 쟁탈전에서는 양쪽 모두 사용할 수 있습니다.
- 사이오닉 스톰은 75 에너지, 3.2초 동안 8회에 걸쳐 총 112 피해를 가하며 아군도 맞습니다. 기지는 피해를 받지 않습니다. 원작에서 다크 아콘의 기본 능력은 아니며 이 게임을 위해 추가했습니다.
- 로컬 2인 쟁탈전: 같은 화면에서 `조작` 버튼으로 청록/주홍 플레이어를 전환합니다. 넓은 전장 아래쪽에 중립 유닛이 등장하고 돌아다니며 양쪽을 공격합니다. 상단 고지대 진격로에는 중립이 출현하거나 진입하지 않습니다. 병력을 선택해 `R` 또는 `상단 우회`를 누르면 그 길을 통해 상대 기지로 이동합니다. 상대 다크 아콘은 정신 지배할 수 없지만 스톰과 피드백으로 공격할 수 있습니다. 온라인 연결 기능은 아직 없습니다.
- 포토 캐논은 디펜스 넥서스 앞에 위아래 두 기, 쟁탈전에서는 양쪽 넥서스 앞에 각각 위아래 두 기가 놓입니다. 고정 방어 시설이며 사거리 내 적을 자동으로 공격하고 수정 발사부가 앞뒤로 움직이며 광탄을 쏩니다. 건물은 정신 지배하거나 스톰으로 파괴할 수 없습니다.
- 화면은 1920×1080에서 상하 여백과 게임 화면 비율을 맞췄습니다.

## 수치와 자료

현재 등장하는 7종의 기본 HP, 보호막, 기본 공격력, 방어력은 Blizzard의 원작 유닛 자료에 맞췄습니다. 속도와 사거리는 이 게임의 캔버스 픽셀로 환산한 값이며, 원작의 모든 업그레이드, 크기별 피해 배율, 공중/지상 구별, 기술 트리는 아직 구현되지 않았습니다. 다크 아콘의 정신 지배는 150 에너지, 마엘스트롬은 100 에너지를 사용합니다. 정신 지배 시 보호막 소진은 게임 규칙에 따라 제거했습니다.

## 이미지

게임에서 쓰는 7종 유닛의 16×16 이미지 시트, 넥서스, 포토 캐논의 본체와 발사부 이미지는 ImageGen으로 새로 만들었습니다. 각 유닛 시트는 행을 방향, 열을 대기/이동/공격/사망 프레임으로 읽습니다. 생성 이미지 특성상 일부 방향·프레임의 모양과 칸 경계는 손질이 필요합니다.

게임은 생성된 시트의 원본 가로세로 크기(약 1250픽셀)를 유지한 AVIF 파일을 사용합니다. 512픽셀 축소본은 소스에서 제거했습니다. 맨 아래 16번째 방향 행은 생성이 불완전해 사용하지 않고 첫 방향 행로 대체합니다. 각 프레임의 투명 픽셀 중심을 계산해 위치를 맞추며, 별도의 이미지 추출 도구는 포함하지 않습니다. UI 초상화는 게임에서 필요한 작은 미리보기만 즉시 생성합니다.

생성 프롬프트의 공통 틀: `투명한 16×16 RTS 스프라이트 시트. 각 행은 22.5도씩 회전한 16방향, 각 열은 대기 4칸·이동 6칸·공격 3칸·사망 3칸. 칸마다 한 유닛을 같은 크기와 중심으로 배치. 글자·숫자·로고·워터마크·테두리 없음.` 대상 설명은 각 유닛의 독자적인 색상, 실루엣, 무장과 동작에 맞춰 따로 작성했습니다. 넥서스는 `투명 배경의 독창적인 청색 수정·금빛 외장 외계 전략 게임 기지, 높은 시점의 단일 건물 스프라이트, 글자 없음`으로 생성했습니다. 생성 방식은 내장 ImageGen입니다.


## 배경음악 및 유닛 음성

- BGM: `Warping_the_Citadel.mp3`을 첫 사용자 클릭/키 입력 후 반복 재생합니다.
- 상단에서 전체 음소거, 배경음악(BGM), 유닛 음성(VOICE) 음량을 따로 설정할 수 있습니다.
- 7종 유닛(다크 아콘, 아콘, 질럿, 마린, 골리앗, 히드라리스크, 울트라리스크)은 준비(`ready`), 선택(`select`), 이동(`move`), 공격(`attack`), 사망(`death`)에 음성이 연결됩니다.
- 음성 파일 경로는 `voices/<영문유닛명>-<이벤트>.wav`입니다. 7×5=35개 WAV를 `dark-archon-rts/voices/` 폴더에 넣어야 실제 게임에서 들립니다.
- 다수의 유닛이 동시에 전투 중일 때 같은 대사가 과도하게 반복되지 않도록 재생 빈도를 제한합니다. 브라우저 음성 합성(TTS)은 사용하지 않습니다.
